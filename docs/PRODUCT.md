# Riftlet 产品约定

Riftlet 把 macOS 系统截图附加到用户点图时正在编辑的 ChatGPT 网页草稿。正式支持普通 Google Chrome 和 Microsoft Edge。用户自己发送消息。[当前正式版本与工作状态](quality/ITERATION_STATUS.json) · [公开发行](https://github.com/haohongfei2001-png/Riftlet/releases/latest)

## 托盘和最近截图

系统截图进入活动托盘。用户点选后，图片移到最近截图，即使当时没有合适的草稿或附加失败。向上滑动可查看最近截图，其中包括点过或归档的图片，最多显示 20 张。向下滑动返回活动托盘。再次点选历史图片才会发起一次新的附加。失败不会自动生成卡片或重传。[1.0.10（65）交互说明](releases/1.0.10/RELEASE_NOTES.md)

点击时绑定原始进程、窗口、标签、文档和编辑器。Riftlet 保留原文、选区及已有附件，每次选择至多输入一次文件。START 记录原草稿接收了本图，上传进度和消息发送由 ChatGPT 管理。不确定的交接保留原操作和原图。

## 完整截图仓库

最近列表只显示 20 张。用户仍可打开完整截图仓库查找更早的图片。对于一次已经结束、未创建任何附加操作的点选，1.0.11 增加已有「恢复到托盘」入口的适用范围。恢复只改变本地可见性，再点击托盘中的图片才会附加。已有操作、START 或 UNKNOWN 的截图沿用各自的处理规则。归档和移除截图的原有恢复规则继续适用。

## 其他已发布行为

| 范围 | 行为 |
|---|---|
| 系统 | macOS 13 或更新版本，支持 Apple Silicon 与 Intel |
| 桌面 | 微缝、风铃和两行两列托盘共享截图队列 |
| 归档与存储 | 保留现有闲置归档及媒体留存选择，交互期间不归档。移出托盘保留系统原件 |
| 本地仓库 | 提供列表、网格、预览、筛选和分页，截图和历史存于本机 |
| 首用与权限 | 截图目录访问用于收录；浏览器自动化及浏览器的 JavaScript 设置用于网页附加；内置截图沿用原权限 |
| 更新与反馈 | Sparkle 提供签名更新；反馈为用户主动提交的文字，诊断默认关闭 |

产品裁决和旧版原文分别见[当前决策](quality/DECISIONS.md)和[产品文档历史快照](quality/history/docs_PRODUCT.before-20261114.md)。
