## Product decisions that are now fixed

R2.1 retains R2 placement, vertical pagination, original image Fit, original
input islands and strict upload-start ownership. Three free-edge contours and
the neutral number surface meet a fixed seam plane. Decorative padding and
shadows do not enlarge mouse-receiving regions; press feedback is stationary.
The magnetic trajectory retains its original owner/lifetime and clips the full
decorated surface. No new user preference or appearance mode is introduced.

Continuous preview uses 450 ms cold and 90 ms warm dwell, a frozen current-page
canvas, atomic image/UUID/rank presentation, session/request/revision fences,
one active decode and one replaceable pending request. New screenshots outside
the visible page preserve a valid preview; actual page/identity/geometry changes
and foreground-application changes revoke it. The original number hit frame is
preserved even where it is smaller than the design document's assumed minimum.

After this integration's successful standard merge, this phase's functional UI
is frozen. Do not add another layout, microimage style or long-lived design
candidate. Concentrate work on real usability, reliability and first-release
readiness. A blocking defect demonstrated by final acceptance may receive a
minimal reviewed fix on a short-lived PR from actual main, with targeted
reverification and the existing full formal gates. New explicit user direction
can supersede the freeze; an agent must not infer that authorization from a
minor stylistic difference or an old design exploration.
