**暂缓推广。** 候选来源是 `28f4f5979190c0255b97978afdd97c713c39a50b`。通用 App 已由 Developer ID 签名。测试 Mac 锁屏期间，Apple 公证工具无法使用既有凭据，此次没有取得提交号。G1 与 G2 所需的登录草稿逐图实测、正式公证 DMG 和直接升级仍待完成。官网和稳定更新维持 1.0.5（31）。[签名与包内代码身份](evidence/signed-app.json) · [任务与放行条件](https://github.com/haohongfei2001-png/Riftlet/issues/118)

## 修复内容

- 在原 #119 分支继承 #117 的 build 44，以 1.0.6 的回执、历史、资料整理、升级及原图恢复为基础。逐项检查 #69 的 68 个生产源码文件；正式包共用一套网页程序。[筛选清单](EDGE_PORT_AUDIT.md)
- 点击绑定当时的浏览器进程及其启动身份、窗口、标签、文档与编辑器。设置只向当前显示的浏览器检查或申请权限。历史核对通过原操作查找已有通道；恢复焦点前的只读定位与写入权限分开判断。浏览器或原草稿失效时保留截图。
- 普通 Edge 全屏截图暴露原型的 4,194,304 像素限制。实际 Edge 复现了 2560×1664 正确图无法取得接收回执。45 对原文件和草稿中可见、属于本次文件的预览作有上限的精确比较，逐项释放中间数据。对重新编码的预览，PNG/JPEG 像素上限为 16,777,216；无法证明归属的图可保持待核实。真实服务处理完成不能由本地交接推断。
- Edge 的 DIV 图片卡保留原图并出现失败重试时，原实现漏报。45 连续绑定原卡成员，仅认可同一原图卡上可见、指向本文件的明确失败动作。隐藏、禁用、相邻文件、替图、移走再放回及改名复用均已独立检验。全程不自动发送或重传。[独立修前修后对照](evidence/independent-edge.json)
