# Riftlet 1.0.6（41）候选验收

**不放行 build 41。** 独立复核发现 15 个缺少真实接收证据的测试场景中有 11 个错误产生 START。帮助按钮中的图标、隐藏或属于其他文件的预览以及没有推进的进度条均可能使桌面图错误收起。以下记录保留 41 的实测范围。[独立复核结果](evidence/preview-ownership-build41.json)

产品提交为 `bfd043e2af82fbc64e33a1167e7d4f2245aa2b81`，基线是 PR #114 合并后的 main `9fd8ad15fca043915069904113e5fb67d82b4948`。[build 40 的原始报告](https://github.com/haohongfei2001-png/Riftlet/blob/f87add807d666434fc14e778496d646b9465899d/docs/releases/1.0.6/RC_REPORT.md)

## 本轮修复

build 40 只在原生程序读取页面时寻找本次文件的接收证据。受控 Chrome 中，原卡显示匹配预览，20 ms 后变为失败。若期间正好读取页面，40 会看到 START；同样的页面变化落在两次读取之间时，40 会漏掉它。该对照不能重建先前真实草稿的中间状态。[同一用例修复前后对照](evidence/inter-poll-handoff.json)

41 在原草稿编辑区短时间观察页面变化；匹配预览必须可见，进度必须归属当前文件。主动观察最多 10 秒、64 批页面变化，其后沿用原操作的只读核对。已经观察到、尚未持久化的 START 保留原证据身份。当前操作的 START 落库后，下一次只读检查再核对原卡此时是否有错误。一次人工核对若首次补得 START，会在同一次操作中再读取原卡。输入次数、失败后的新授权和自动重试边界沿用原有规则。

## 安装包与验证

正式 DMG 为 13,325,896 字节，SHA-256 为 `fa40e9df09b7e9007aecf802a505ecf21a770fd732b50d16df37c6db77942d6f`。App 和 DMG 均通过 Developer ID 签名、Apple 公证、装订及 Gatekeeper。签名包的 arm64 原生与 x86_64 Rosetta 自检均通过。四组网页测试 213/213，Sparkle 工具测试 11/11。资料故障回归、跨进程清理及恢复均通过。[包回执](evidence/package-build41.json) · [资料测试](evidence/v3-source-build41.json)

41 发行组件对 1,000 份真实 PNG 及外部原件进行了完整校验，并发新增 20 张。摘要首屏 6.82 ms，完整核验与并发工作 0.61 秒；这一组件测量与下述普通 App 负载测试分别计时。[组件测量](evidence/v6-source-build41.json)

## 同一包的真实草稿、资料与更新

**V1 · 已登录 Chrome。** 冷、暖首击及三组连续双图共八张，八次原生鼠标点击各产生一份 START。八张测试图在原未发送草稿中按顺序可见，原文字、非空选区和先前附件均保留。三组按下间隔为 416.3、409.9、398.3 ms；冷/暖点击至观察到收起的上界分别为 1.974/2.706 秒。全部八次的中位数为 2.096 秒，p95 和最大值均为 3.276 秒。切到空白页后可以精确返回原草稿。[逐次实测](evidence/v1-host-build41.json)

另在隔离 Mac 的匿名 Chrome 冷启动中，一次点击使原稿出现一张测试图和一条 START。目标定位耗时 34.07 ms，至观察到收起的上界为 636.08 ms。切走标签、退出重开 App 后仍可核对、准确返回；关闭原标签后如实提示不可核实。[匿名冷首击与原页核对](evidence/guest-a-build41.json)

**V2 · 异常与人工处置。** 在无有效草稿的空白页点击，图仍留在本地，8 个操作、8 份 START 都没有增加。登录草稿出现“上传未成功”的真实红卡后，仓库只读核对及确认重新附加保留 9 个操作、8 份 START；另一次自然点击才建立同一图片的第 2 次操作。原 UNKNOWN 与原红卡保留，新操作单独取得 START。[原操作与新授权对照](evidence/v2-host-build41.json)

**实测中间状态。** 针对一张新的合成测试图，使用专用草稿的 Chrome 网络节流并阻断实际后处理请求。本次 182,745 字节的图在约 +1.5、+2.2、+3、+5、+7 秒显示灰色占位块，约 +10 秒时用对应文件名显示“上传未成功”；到 +90 秒仍无 START，旁边的正常图和原有错误卡仍可辨识。错误出现前的实拍没有可归属当前文件的正面图像预览或定量进度，因此该操作保持 UNKNOWN、无 START。Issue #115 所定义的真实可见异常→核对→人工处置闭环已完成。先取得 START 再由同卡真实失败触发找回仍未在 ChatGPT 上观测到，受控 Chrome 的修前修后对照只证明可观测信号出现时的程序行为。

另一个专用草稿观察到 8 次自动读取，最后一次在点击后约 415 秒。首次人工核对误选了原标签已关闭的旧行，已排除此读数。重启 Riftlet 并选中正确的新图后，在约 600 秒的页面证据寿命结束前仍可核对；超过 613 秒后，同一原页仍在，Riftlet 准确提示无法再核实。两次读取均保留 10 个操作、7 条 START。[八轮读取与到期记录](evidence/guest-a-build41.json)

**V3 · 资料与找回。** 正常管理窗口移出 24 个可管理副本，其中 4 个关联真实附加的 START，6 个没有已验证的外部原件。重启后找回了全部 24 份，30 张图的身份与字节、8 个旧操作及 5 条 START 均保留。旧 UNKNOWN、预输入失败保护及检查/再次附加/主动收起/已处理分别留有记录。[普通 App 资料治理](evidence/guest-a-build41.json)

**V5 · 更新。** 实际从公开 1.0.5（31）以及同营销版本的 35 更新到 41。两次均由 Sparkle 确认并重新启动，运行中主程序 SHA-256 与正式 DMG 内的 App 一致。两个原库的文件、旧操作、START、书签及反馈草稿均保留。[升级回执](evidence/v5-upgrade-build41.json)

**V4/V6。** 41 的真实双语窗口、搜索和 VoiceOver 字幕通过；旧 25 手动升级保留原资料。缺屏录权限时可打开正确的系统设置面板，隔离设备的安全输入未完成授权，本次该设备授权后的捕获和标注为 BLOCKED。千图下两批 20 张全部收录，p95 为 762/315 ms。[普通进程与 UI 回执](evidence/guest-b-build41.json)
