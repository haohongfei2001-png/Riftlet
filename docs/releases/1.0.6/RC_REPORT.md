# Riftlet 1.0.6（40）候选验收

产品提交为 `65398096092e739bb9581244961112b572006465`，基线是 PR #114 合并后的 main `9fd8ad15fca043915069904113e5fb67d82b4948`。本报告仅在明确标注构建号时引用历史结果。[38 的原始报告](https://github.com/haohongfei2001-png/Riftlet/blob/bd839672b06f161aaa05b1cdf45e727792567707/docs/releases/1.0.6/RC_REPORT.md)

## 上一轮问题的修复

- **首击超时。** 38 的匿名测试里，读取窗口与标签耗时 116.94 ms，后续 URL 查询与它共用 150 ms 总预算。40 在鼠标按下时向同一个已固定 Chrome 进程提交两条只读 Apple Event，核对窗口、标签与 URL；后续操作仍按原页面及编辑器复核。两个标签 ID 冲突或窗口身份无法固定就退出。对只缺可选 URL 的回复，只能按已经固定的绝对窗口和标签读取。隔离 Mac 的 12 组交替测量为串行 31–34 ms、新路径 15–17 ms；5 次故意在查询间换标签均正确拒绝。[原生 Chrome 取证](evidence/click-snapshot-native.json)
- **原卡失败。** 保留正面接收事实与当前错误的独立身份。已存在的进度条须在相同量程上实际推进。只在原草稿、原成员与完整文件身份相符时接纳该卡可见的失败状态。原卡出现别张图或被复用时，旧操作继续保留原有事实。39 的完整回归发现旁边出现重复视图时会漏报原预览自己的错误，已在 40 修复。[真实 Chrome 本地双图正反例](evidence/card-identity-chrome.json)
- **窄窗搜索。** 搜索框显示“搜索 / Search”，VoiceOver 使用“搜索截图 / Search screenshots”。在 106 pt 宽度上，文本区实测为 78 pt，两个提示分别宽 25.8 与 42.1 pt。

## 候选包与实测范围

Developer ID 签名的通用安装包为 13,307,101 字节，SHA-256 为 `4de8e2450c0896e922d386353857008b90590f69d11b5a35aa5e9d9ccff6569f`。App 与 DMG 均通过 Apple 公证、装订及 Gatekeeper。arm64 原生、x86_64 经 Rosetta 的签名包自检均通过，声明最低系统为 macOS 13。原生端分别跑过故障夹具以及独立进程中的建立、清理、恢复。网页程序 206 项受控测试及 11 项 Sparkle 工具测试通过。[公证回执](evidence/package-build40.json) · [数据故障回归](evidence/v3-source-build40.json)

40 的发行组件在 1,000 张带外部原件与私有副本的真实 PNG 上运行。摘要首屏 24.20 ms，完整核验与并发工作 4.10 秒，新增 20 张收录 p50/p95 为 32.45/49.82 ms。[组件原始数据](evidence/v6-source-build40.json)

本次重新通过官网下载按钮取得的公开 1.0.5（31）DMG 与 Release 及签名 stable feed 一致，SHA-256 为 `99276347932e231adf743664a54cfc782d8e345d89221587d54b7299a5c9f315`。[线上核验](evidence/public-v1.0.5.json)
