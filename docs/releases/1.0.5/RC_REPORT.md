## 产品变化和已知边界

| 审计项 | 候选实际行为 |
|---|---|
| R105-01、02、03、10 | 保留四页设置。离散选择适配托盘四槽，旧自定义值仍生效，可撤销推荐外观。菜单只在异常时增加原因和对应动作。屏幕录制修复入口随实际拒绝出现。 |
| R105-04、05 | 产品沿用收到新附件即收起的规则。对原操作的只读观察最多八次；匹配同一卡片、文件名和草稿的错误会进入「需要处理」。可核实原对话时，历史提供打开入口。导航、无关卡片错误、观察超时均不授权重传。已移出项目保留用户意图。真实服务端永久终止证据仍缺，生产重试能力保持关闭。 |
| R105-06、07 | 「截图 → 管理」可核对数量、空间、仅存副本数，将符合条件的私有副本移至废纸篓、找回，或补收录中断的内置截图。撤销后重新计算留存期。新档案默认 30 天，升级档案继续原策略；自动整理须实核外部原件、来源身份及 SHA。外部原图只读。首次移动私有副本时数据库格式升至 5，旧程序将拒绝打开，避免旧恢复逻辑复建已清理项目。 |
| R105-08、09 | 两种截图入口共用 importer。正常返回设置只刷新系统事实；原草稿状态不变时免写，后台逐张校验冷历史，优先可见截图。100 张、1.106 GB 的隔离库中，3 张可见/97 张冷图的前台恢复为 48 ms，后台校验期间新增一张 11 MB 图片耗时 159 ms。[原始测量](evidence/cold-history.json) |
| R105-11 | #111 和本目录为唯一活动入口。#107/#108 的托盘外观与全库搜索继承自 #110。#95 的清理、#93 的历史成本已进入候选；#82 真实服务、#92 辅助功能、#97 支持矩阵、#83 远端保护分别保留。官网公开下载为 1.0.3，仓库 stable feed 为 1.0.2。 |
| R105-12 | 真实点击、普通安装使用、受控 AppKit 测试和签名身份分别计入下表。 |
