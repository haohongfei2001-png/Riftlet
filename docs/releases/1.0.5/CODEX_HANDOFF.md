## 最小充分验收

以下是验收目标，不是要求新建十套测试框架。优先复用现有有效测试、隔离fixture、原生review工具和真实执行环境；源码检查、受控测试、普通原生、真实服务、签名包各写实际范围。

| ID | 必须证明的行为 | 有效证据 |
|---|---|---|
| V01 首次成功 | 新档案安装→必要授权→正常系统截图→微图→一次自然点击进入正确草稿，无预先手动修复隐藏状态 | 最终包普通Mac/真实Chrome ChatGPT；原文、旧附件和选区保留，发送0 |
| V02 快速多图 | 至少三组A/B，两次点击间隔≤2秒；两图各一次输入、对应START并收起；旧UNKNOWN不挡新图 | 最终包真实草稿与应用UI，对应图片/操作回执；无自动发送 |
| V03 失败及不明 | 输入前失败可恢复；START后同附件明确终止失败可恢复；无关错误不串图；导航/超时不伪造失败；主动移出不反复弹回 | 精确受控反例＋真实服务可取得的同包证据。若外部终态证据拿不到，自动重生未完成部分必须保留为未闭合，不能改产品定义结案 |
| V04 设置与恢复 | 正常界面简短；目录/写盘/Chrome/单项保存异常可见且一键到正确操作；只修相关问题 | 当前product host的中英、浅深实际截图，普通自然输入；旧值/未知字段无损 |
| V05 原生细节 | 最小/默认窗口无截断或空散失衡；系统IME组字后切页/关闭/Cmd-Q可理解；键盘/VoiceOver能完成核心设置 | 系统IME/辅助访问真实操作；模拟输入只能作辅助 |
| V06 捕获恢复 | 发布原件后manifest前、标注器打开、manifest后DB前中断，重启都能找回完整原件并只收录一次 | 隔离磁盘/强退故障注入与普通App回读；不自动附加 |
| V07 清理一致性 | 批量清理/撤销/重启/再扫描无复活、无重复收录；活动/UNKNOWN/仅存原件不被自动误删；原外部文件不变 | 混合资料fixture＋同包GUI操作；清理集合和实际空间口径一致 |
| V08 长期成本 | 返回设置不反复扫库；死目标UNKNOWN观察/写库衰减；长会话临时状态可退休；冷历史不挡当前新截图 | I/O、DB写入、集合计数/RSS、可交互时点。含GB级实际媒体与多草稿；不以6张空闲库代替 |

| V10 交付范围 | 最低声明系统/当前系统、实际两架构、屏幕/Space适用关键组合；签名公证/安装/更新身份一致 | 复用仍适用证据，改动影响格补测；NOT_RUN按实际承诺评估，不能伪称跨平台全验 |

自然点击性能同时记录冷态/暖态结果与p50/p95/最大值。150ms目标快照预算若有真实误拒，优化有证据的读取/异步续接；不能扩大主线程长阻塞或使用旧目标猜测。

W4的复杂性能改造须有测量依据；已确认的无效轮询/扫描直接修。小库不能出现明显退化，活跃路径不能等待整个冷历史完全读取。长会话保留的是紧凑防重复事实，临时DOM/缓冲/路由应可释放；清理后重放旧命令仍不能产生第二次setter。

普通可逆UI改动无需逐项另写镜像测试。针对数据删除、错误目标、重复输入、恢复和迁移保留有意义的反例。已验证且没有相关变更的范围不机械重复；每次改动只扩大到真实受影响的边界。

## 自主执行与持久交接

- 不等待用户协调分工、选择实现细节或逐个按测试步骤。可用的授权执行环境由你安排；失效测试机按正常方法修复或改用其它授权环境，不绕过认证/网络权限。
- 有一项受外部条件阻塞，标明这一项并继续其它包；所有可做工作和可安装候选仍要完成。不能把“先请用户重测一次”作为默认下一步。
- 每完成一个包更新一份短 `PROGRESS.md`：当前SHA、已完成ID、实际证据、剩余阻塞、下一条具体动作。只保留当前摘要，详细历史交给git；不另建重复状态系统。
- 分包分上下文读写，关键裁决和已完成状态及时提交。交接保留精确文件/提交/下一步；不要在一轮上下文中展开全部日志、全部截图或所有历史报告。
- 正式PR继续遵守现有B→G→H和五项检查；非作者复核是真实的另一个审查者，不自签其它身份。远端保护#83单列，不改门禁来制造完成。
