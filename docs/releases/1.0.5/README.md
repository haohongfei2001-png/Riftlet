## 1.0.5 的完成含义

- 设置能直接理解、选择和恢复，普通用户不面对工程参数、重复警告和无动作的状态说明。
- 截图仍是自然截图、一次点击、进入正确的当前草稿；接收即收起，明确失败可找回并按规则恢复；不自动发送或重复输入。
- 用户能管理截图资料，确定的临时垃圾会自行维护；清理有实际效果，旧图与未决操作不会因升级被误删。
- 长期使用不会因无效重复扫描、未变状态反复写库或无生命周期的临时对象持续增加负担。
- 最终候选包完成真实首次附加、快速双图、异常恢复、安装升级和界面验收；未运行的项目如实标明，不以 CI 代替。

不承诺无法证明的“零 bug”。放行标准是清除本版必做缺陷、完成关键实际流程、剩余风险与公开承诺一致。外部可用性访谈可继续安排，不把“必须先招募五个人”等非工程依赖设成停止全部开发的理由。
