# 1.0.9 产品体验

Riftlet 的日常操作仍是截一张图，回到正在编辑的草稿，点一下桌面边缘的缩略图。用户可以先用本地截图，随后按当前需要连接浏览器。

| 场景 | 观察与决定 |
| --- | --- |
| 下载和安装 | 1.0.8 磁盘映像已有正确的应用程序入口，Finder 中缺少图标位置和安装指引。1.0.9 在同一窗口并排显示真实 App 和「应用程序」，用箭头和中英文短句说明拖动方向。 |
| 第一次截图 | Apple 建议让人实际做一次操作，并将权限说明放到需要该能力的时刻。新安装先显示当前截图目录，获准后便可去截第一张图。打开快速入门本身只读取状态。用户可以稍后连接浏览器。[Apple 引导规范](https://developer.apple.com/design/human-interface-guidelines/onboarding) |
| 第一次附加 | 实际草稿开始接收这次点击对应的图片后，引导自动完成。升级保留既有选择。用户随时可从「设置 → 帮助」重看。Alfred 的入门文档将首次运行与从设置重新进入帮助分别说明。[Alfred 入门](https://www.alfredapp.com/help/getting-started/) |
| 设置 | Raycast 允许从具体操作直接进入相关设置，Alfred 将外观预览放在调整位置旁。Riftlet 把浏览器恢复放入「附加」，把桌面形态、位置和归档时间放入「截图托盘」，把系统截图目录和库操作放入「截图」。调整即时生效。[Raycast 设置](https://manual.raycast.com/settings) · [Alfred 外观偏好](https://www.alfredapp.com/help/appearance/) |
| 桌面边缘 | CleanShot 的浮层将近期截图和下一步操作放在一起，Shottr 把悬浮预览作为短暂的参考。Riftlet 延用窄托盘、现有屏幕位置偏好和截图仓库。鼠标滚轮一格即可翻页，触控板手势仍有距离阈值，惯性滚动不会再翻页。[CleanShot 截图](https://cleanshot.com/screenshots) · [Shottr](https://shottr.cc/) |
| 附加中断 | 尚未输入时给出用户可做的下一步。对已经开始且结果不明的操作保留原图和记录；重新附加仍由用户决定，草稿由用户发送。 |
| 范围和升级 | 两种普通浏览器共用同一套操作方式。当前公开支持 Google Chrome 和 Microsoft Edge 的 ChatGPT 网页版。Safari、Brave、Firefox 及其他 AI 网页的探索记录在独立开发分支，公开版保持实际产品可执行的范围。Sparkle 沿用稳定通道和原有公钥。 |
