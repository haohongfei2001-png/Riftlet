# Riftlet 1.0.9

- 第一次打开时，先确认 Mac 的截图保存位置，即可去试一张截图。需要附加时再连接当前浏览器。首张截图进入草稿后，快速入门自动完成；以后可从帮助重看。
- 设置改为原生侧边栏。浏览器权限和连接集中在「附加」，桌面位置、样式和闲置时间在「截图托盘」，截图来源和仓库在「截图」。
- 修复首次授权前保存的系统截图可能漏收，以及旧图库已有完整原图却提示暂缓收录的问题。普通鼠标滚轮一格即可翻页。
- 安装窗口并排显示 Riftlet 和「应用程序」。可通过应用内「检查更新…」升级，并继续使用原有偏好和截图库。

For Google Chrome and Microsoft Edge with ChatGPT on macOS 13 or later, on Apple silicon and Intel.

- Try a screenshot before configuring a browser. Quick Start finishes when your first screenshot appears in the draft and is always available in Help.
- Use the native Settings sidebar for browser access, tray placement and appearance, screenshot collection, or help.
- Screenshots saved while first granting folder access are collected afterwards. Verified originals from an older library stay quiet. Each mouse-wheel notch now turns a tray page.
- Drag Riftlet to Applications in the updated installer, or choose Check for Updates in Riftlet to keep your existing library and preferences.
