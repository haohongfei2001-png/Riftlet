# Riftlet 1.0.8（build 61）发行说明草稿

## 中文

- 点击桌面边缘的截图时，Riftlet 会核对原来的浏览器窗口、标签和 ChatGPT 草稿。连续点击两张截图时，每张图片分别核对和附加。
- 截图仓库会保留上传结果未能确认的原图和记录。选择「重新附加」后，你会看到可能产生重复附件的提醒。从截图仓库回到同一草稿核对附件，再点原图即可发起新的附加。原窗口或草稿已关闭时，仍可在截图仓库查看原图。
- 改进了 ChatGPT 将预览显示为 WebP 时对原截图的识别。消息仍由你在 ChatGPT 中发送。

适用于 macOS 13 或更高版本、Apple 芯片和 Intel Mac。可从 Riftlet 菜单选择「检查更新…」。

## English

- Clicking a screenshot at the desktop edge checks its original browser window, tab, and ChatGPT draft. When you select two screenshots in succession, Riftlet checks and attaches each one separately.
- Your library keeps the original screenshot and its transfer record when the upload result is uncertain. Choosing **Attach Again** explains the risk of a duplicate. Return from the library to the same draft, check its attachments, then click the original screenshot to start a new attachment. You can still view the original in the library after closing the draft.
- Riftlet recognizes the original screenshot when ChatGPT displays its preview as WebP. You send the message from ChatGPT.

Requires macOS 13 or later on Apple silicon or Intel. Use **Check for Updates…** in the Riftlet menu to update.
