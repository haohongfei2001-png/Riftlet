## Evidence and clocks

The two `native-verified-rapid-*.json` files contain the redacted per-image timelines, the exact package identity and hashes of the private source receipts. The independent audit read the real isolated queue directly in a read-only SQLite transaction. It matched each capture-source PNG to its stored media file, original browser File and receiver hash, matched the browser-decoded File pixels to the original attachment preview, and linked the durable START, invocation, native input, selected asset and original draft. Every pair had two distinct acknowledged bindings before the first click. Both original AppKit selections consumed exactly those bindings, and both durable targets agreed on the original Document, Composer and draft generation. The website observer proved the original editor nodes and earlier cards were still present. The active product draft generation was separately recovered from the two commit records after each pair. The passive website observer did not expose that private generation directly before the pair.

For each pair the host clock begins at the first AppKit event. The native commit interval bounds the file setter. The signed application separately reports that setter entry and change dispatch returned, and reports when it received attachmentAccepted. The website observer records input and change on the document's performance clock. Its setter-entry timestamp was unavailable. Compare intervals within their respective clock domains. Tray swallow start and close are presentation callbacks. Their interval measures the scheduled animation lifecycle, without a display-pixel timestamp.

Each image had already passed a read-only tray-row check before the pair sender started. Each native final check repeated the row identity, nine pixel samples, hit geometry, original draft, signature and foreground verification. The second-image row sample and final check record distinct points at which the image was usable. The exact first instant it became clickable was unobserved. The sender allowed 260 ms from the first posting before the second final check. `verifierBetweenPostsBeforeSecondFinalCheckMS` includes that pacing, scheduling and the first post's return. `qaFinalCheckElapsedMS` measures the second image's checks separately. Several second presses occurred while the first upload was still being observed. These measurements do not attribute all time to ChatGPT, a network request, or animation.

With access to either private receipt archive, extract it into an empty private directory and run the versioned auditor. Its stdout is the corresponding public JSON. No browser, network access or running application is needed.

```sh
python3 -B Tests/PreClickLease/native/audit_native_series.py /path/to/extracted/run /path/to/extracted/profile
```
