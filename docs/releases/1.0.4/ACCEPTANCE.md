## 1. 证据不能跨级代替

| 证据类别 | 必须记录 | 能证明什么／不能代替什么 |
|---|---|---|
| SOURCE | 固定源码SHA、函数、差异、独立审查 | 路径与约束；不能证明实际窗口、权限和服务成功 |
| CONTROLLED | 测试目标、fixture、输入、断言、日志 | 自动化模型／浏览器模拟的反例；不能冒充真实ChatGPT |
| NATIVE_GUI | 同一App包、运行模式、WindowServer图、AX／事件来源 | 真实AppKit绘制与原生事件；NSButton target-action不是硬件鼠标，AX树不是VoiceOver完整体验 |
| REAL_SERVICE | 真实当前Chrome/ChatGPT、专用草稿、身份与receipt | 实际附加与草稿保护；START不是服务端READY，更不是消息已发送 |
| SIGNED_INSTALL | 包哈希、codesign／Gatekeeper／票据、实际安装或更新 | 这一个包的发行身份和该安装路径；开发包CI、公证App与外层DMG公证不能互相替代 |

每例结果仅用PASS／FAIL／BLOCKED／NOT_RUN；另记已运行但范围有限的scope。BLOCKED需记录具体环境或权限缺口和可由哪个执行环境补齐；缺一格不停止其余可执行工作。进程退出码0、截图文件存在、测试总数及上轮绿色结果都不是当前格PASS。

### 已有1.0.3证据的准确起点

- 本轮从公有ZIP下载并核验的1.0.3/build25二进制SHA-256为`219c3d9febac0ff58ab03bb4d1869f374caff1da9256a0bf9b5968731bce9161`；原生复查记录见[evidence/native-runs.json](evidence/native-runs.json)。
- 其隔离设置运行 **14/14 PASS、37帧**；只证明记录内设置／host／SQLite／合成采集范围。真实权限、真实ChatGPT、VoiceOver、系统IME及热插拔未被这轮建立。
- 其桌面形态运行 **42例=41 PASS＋1 FAIL**，失败为`tray-owned-button-and-escape`，原因`trayCameraObscured`；有45帧。即便外层wrapper退出0也必须保留FAIL，不能称“全部原生验收通过”。
- T03须定位上述FAIL：若是产品输入／遮挡问题则修复；若是错误oracle则给真实窗口与原生事件反证后修测试。不能仅放宽遮挡阈值、删场景或继承其他截图为PASS。
- 早期真实三图附加、私有Sparkle升级及PR103界面记录保留原SHA、包和场景；图间约2–3分钟的成功不能代替本页要求的快速A→B。设计SVG与历史截图均不充当1.0.4运行证明。

## 2. 执行环境与单例记录

只在专用QA账户／VM或已确认隔离根中运行合成素材和无私人内容的测试草稿。不得覆盖用户生产profile、删除现有偏好、重建当前SQLite、复用生产聊天做演示、改TCC数据库或改稳定feed。先记录独立安装路径、进程PID、根和浏览器profile归属；退出只结束该测试实例。

每例最少字段：`caseID, taskID, sourceSHA, appVersion, build, executableSHA256, packageSHA256, macOS, arch, accountType, displayScale, mode, inputMethod, steps, observations, artifacts, result, scope, blocker, fixSHA`。artifact附相对路径与SHA-256；首次失败与修复后结果并存，不覆盖旧报告。

| 环境轴 | 必需覆盖与诚实边界 |
|---|---|
| macOS／架构 | macOS13最旧声明版本、当前受支持版本；Apple Silicon实际运行。Intel编译／CI单列；用户此前跳过的物理Intel不伪称通过，也不要求用户找机器 |
| 安装账户 | 标准账户与适用的管理员安装；个人Applications及共享Applications替换；未能取得的组合逐格NOT_RUN |
| 视觉 | 简中／英语；浅色／深色；1×／2×；640×560与600×460；更宽窗口正文上限720并居中 |
| 显示器 | 单屏、多屏、负坐标、竖屏、缩放、Dock换边、断连／重接、睡眠／唤醒；标明真实物理或虚拟显示器 |
| 辅助功能 | Reduce Motion、Reduce Transparency、Increase Contrast独立与组合；键盘、真实VoiceOver、Apple简体拼音IME |
| 数据量 | 空库、200／2000／10000条；另有1–2GB真实字节规模的合成PNG/JPEG，不只用小占位图 |

普通布局采用风险组合覆盖，不要求对所有轴机械做全笛卡尔积；已知FAIL、最小尺寸中英文、系统辅助功能现场切换、跨页历史、快速双图与升级路径必须直接运行，不能由组合覆盖推断。
