# 当前质量设计裁决

裁决日期：2026-11-14（北京时间）。依据为本轮用户授权、真实1.0.1发布边界与可定位证据；原实现和旧AI文档均不是自动正确。下列“裁决”授权工程准备/实现，仍须独立验收，不能预先标记产品已修复。

| ID | 裁决 | 依据与实施边界 |
|---|---|---|
| D01 | 保持截图→点图→正确Chrome ChatGPT草稿→用户发送 | 核心价值不变；不扩多浏览器/服务，不合并PR69来完成质量整顿 |
| D02 | 超时不能使无归属input合法 | QA-ATT-001已受控复现；保留可证明的动态/hidden/portal/重建路径，无法区分的匿名异步picker在写入前结束 |
| D03 | 正常START显示“已交给 ChatGPT”；未知输入单独呈现 | 以当前operation匹配的不可变START只读投影；失败/补偿/缺媒体优先；不将START当READY，不改retry/restore权限、不改旧UNKNOWN |
| D04 | 延续普通文件交接在START结束的已发布边界 | ChatGPT控制上传终态/发送；不为改历史标签重建大型事务引擎。确认pre-input失败正常可点击；真正输入不明继续保留。若未来要求START后自动重生，须有精确同操作失败证明的独立裁决，不能自动重传 |
| D05 | 旧prepared仅在能证明从未dispatch时恢复为可显式重试 | QA-ATT-002；不恢复旧内存FIFO，不碰dispatchIntent/START/UNKNOWN，不自动开始附件 |
| D06 | 纯偏好损坏不得阻断收录与历史 | 保留原始字节，采用会话安全默认，坏归档策略先暂停自动归档；修复该偏好不重建数据库、不删除图片 |
| D07 | 设置统一为通用/桌面/截图/帮助 | 一份AppKit界面和同一owner；常规有效变更即保存，失败就地反馈；保存安全机制保留 |
| D08 | 工程参数退出普通设置，已有偏好无损兼容 | 毫秒时长、点击区、编号间距等由软件负责；不是删除配置字段或重置用户视觉 |
| D09 | 保留三形态、当前默认、托盘2×2与已确认位置/比例 | 不因个人审美推翻风铃/微缝/托盘；托盘数量只显示可实现范围，最大4，原数值不静默改写 |
| D10 | “稍后设置”成为明确展示状态 | 不再每次启动强弹；不伪造权限完成。位置默认可用，不强制初次多做一次选择 |
| D11 | 历史/存储入口按用户任务组织；不默认删除 | 保留查看用量与当前原件；主动清理语义先设计，计数/范围/可恢复性明确。任何真正永久删除或迁移另行审查，不混入P1修复 |
| D12 | 沿用Sparkle、SQLite与现有可靠恢复机制 | 不为了少代码去掉签名、事务、journal、hash、identity及owner/revision；减少无效工作而非重做框架 |
| D13 | 当前入口短小，历史一次归档；当前状态单一 | AGENTS/产品/治理/执行入口已重整；旧证据按旧SHA保留，测试pass不等于真实服务pass |
| D14 | 不在本轮改正式下载、feed或发布新二进制 | 本轮交付审计与工程任务；修复后的发布需清除已知P0/P1并完成当前包独立验收 |

## 优先级与无法自动决策的边界

目标准确性与数据恢复先于视觉；更新入口和保存语义先于装饰；维护成本只针对明确热点。是否扩展目标平台、改变批准形态、自动删除现有数据不属于本次默认授权。远端保护如确需改变原审批身份要求，提交具体可评审配置后集中决策，不把一般代码修复都转交用户。

设置每项默认值、保留/合并/移动/自动化/隐藏/删除与迁移影响见[专项方案](SETTINGS_REDESIGN.md)。原历史决策见[快照](history/docs_DECISIONS.before-20261114.md)。
