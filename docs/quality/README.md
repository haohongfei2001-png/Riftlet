## 状态约定

Issue是缺陷讨论与关闭记录；`ITERATION_STATUS.json`是当前轮次及下一动作；`findings.json`与台账提供可检索的首版证据和排序。三者使用相同QA编号，不另建平行任务。后续修复更新现有Issue和状态，不把首版基线证据改成“已通过”。

本轮没有可调用的远程Codex编码任务启动接口；工程任务已写成可领取的GitHub交接，不能把创建Issue说成已启动后台修复。原生Mac、真实ChatGPT和发行验收由具备相应环境的工程/验收执行器完成，不要求用户代替测试。
