# Take your first screenshot and attach it

The four-page settings candidate includes English and Simplified Chinese setup, menu bar controls and screenshot history. Riftlet follows your Mac’s preferred language. The public 1.0.1 download uses the earlier, primarily Chinese interface. For 1.0.1, the Chinese labels below identify the controls you will see.

1. Open Riftlet from Applications. In setup, check the displayed screenshot folder. If access is needed, choose **Allow Screenshot Folder Access…** (授权读取系统截图文件夹…) and select the folder shown.
2. Open an editable ChatGPT draft in Google Chrome. Return to setup and allow Riftlet to control Chrome when macOS asks. In Chrome’s menu bar, select **View → Developer → Allow JavaScript from Apple Events**, then choose **Check Connection** in Riftlet. In Chinese Chrome the same menu is **显示 → 开发者 → 允许 Apple 事件中的 JavaScript**. This setting allows apps with Chrome automation permission to run page scripts. For local screenshot history alone, choose **Set Up Later** (稍后设置).
3. Choose your preferred desktop position, select **Get Started** (开始使用), and use the Mac’s Screenshot app to capture a window, an area or the whole screen. Save the image as a file. Its thumbnail appears at the edge of the desktop.
4. Bring your intended ChatGPT draft to the front in Chrome and click the thumbnail once. The image appears beside the message box alongside your existing text and attachments. The thumbnail retracts when ChatGPT starts receiving the image. You can click another screenshot while the first uploads. Check progress in the draft and send the message yourself.

If macOS denied Chrome access, choose **Open Automation Settings…**, then **System Settings → Privacy & Security → Automation** (系统设置 → 隐私与安全性 → 自动化). Turn on Google Chrome under Riftlet and return to setup. For a folder denial, select the displayed screenshot folder again. Its save location is shown in **Screenshot → Options → Save to** (截屏 → 选项 → 存储到).

Open **Settings…** (设置…) from the Riftlet menu bar icon.

| Page | What you can do |
| --- | --- |
| General (通用) | Set login behavior and window appearance, see the current version, check for updates and turn daily checks on or off. You choose when to install an update. |
| Desktop (桌面) | Choose screenshot tray, wind chime or micro slit, the screen edge and the display. Each form uses the same history. |
| Screenshots (截图) | Check the screenshot folder or choose **Allow Screenshot Folder Access…** to restore access, configure built-in capture, check local storage, open history or change the idle archive time. The default is two minutes. Choose 1–10 minutes or turn it off. |
| Help (帮助) | Check the Chrome connection, reopen setup or send feedback. |

In the existing 1.0.1 download, open **外观与布局** for desktop appearance, **使用与历史** for the archive time, or **权限与帮助 → 关于与诊断** for updates.

**Find an earlier screenshot.** Click the Riftlet menu bar icon and open **Screenshot History** (截图历史). Select an archived image and choose **Restore to Desktop** (恢复到桌面). Your original file is preserved. To stop collecting new screenshots or hide thumbnails temporarily, use the menu bar controls. Hiding the thumbnails keeps collection running.

**Upgrade an older copy.** If you use 1.0.0, quit the app, back up your library and replace the installed app once with 1.0.1 from the [official download](https://riftlet.com/). From 1.0.1, you can use **Check for Updates…** (检查更新…) from the menu bar icon’s right-click menu.
