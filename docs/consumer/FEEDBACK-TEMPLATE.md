# 私下反馈 / Send feedback

右键菜单栏 Riftlet 图标，选择「反馈与建议…」。也可在「设置 → 权限与帮助 → 反馈与建议…」进入。打开或关闭窗口只会保留本地草稿。点「发送反馈」后，已授权的报告可能在后台或网络恢复时继续投递。可选诊断默认关闭；可以在发送前预览，并在原记录查看状态或申请删除。无法打开 App 时，可在[安装问题入口](https://github.com/haohongfei2001-png/Riftlet/issues/new)仅提供版本、macOS 版本和报错类型。该页面公开。隐私问题请单独发至 [privacy@riftlet.com](mailto:privacy@riftlet.com)，报告编号也请私下提供。

遇到可能错投、重复、正文变化或图片丢失，请停止对该图片的进一步操作，保留原记录。描述现象即可，不必复现或提供聊天内容。

可把以下几项写进反馈：

- **使用环境**　Riftlet 和 macOS 的版本。附加相关时写 Chrome 版本。
- **发生了什么**　大约时间和时区、你的操作、预期以及实际结果。已经出现的短错误提示可以原样提供。
- **与附加有关时**　目标草稿中是否出现本图、旧正文与附件是否保留、微图是否收起，未知的项目可以留空。

发送的文字不会自动脱敏。请勿附上真实截图、聊天正文或标题、URL、完整路径、数据库、原始日志、浏览器凭据或验证码。程序中的反馈状态和报告编号有助于跟进；请私下保留。[隐私与数据](PRIVACY.md)

**English.** Right-click the menu bar icon and choose 反馈与建议…. Send a short description, your Riftlet and macOS versions, the approximate time and observed result. Keep private images, messages, links and credentials out of the report. If Riftlet will not open, [report an installation issue](https://github.com/haohongfei2001-png/Riftlet/issues/new) with the app version, macOS version and error type. That page is public. For privacy requests, email [privacy@riftlet.com](mailto:privacy@riftlet.com) privately. Only share report IDs in private correspondence.
