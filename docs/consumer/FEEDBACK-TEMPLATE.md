# 反馈模板 / Feedback template

右键菜单栏的 Riftlet 图标，选择「反馈与建议…」。也可在「设置 → 权限与帮助」展开「关于与诊断」进入同一反馈窗口。关闭窗口只保存草稿；点发送后，待发送报告可在后台重试。提交前可以预览并决定是否附带有限诊断。维护者尚未公布的支持邮箱、响应时限或下载地址不要自行猜测。

**不用附图也能报告问题。** 请勿粘贴真实聊天正文、图片原文件、完整磁盘路径、账号标识、Cookie、令牌、浏览器 profile、原始数据库/观察日志、反馈访问凭证。文字不会自动脱敏。需要展示界面时，先用自己制作的无隐私样例复现；不要在公开 Issue 上传真实截图。

复制以下内容，填能确认的部分，未知留空即可：

```text
版本 / Version and build:
Mac 架构 / Apple silicon or Intel:
macOS 版本 / macOS version:
Chrome 版本 / Chrome version (if attachment-related):
发生时间及时区 / Approximate time and timezone:
我想做什么 / Expected result:
最短操作步骤 / Short reproduction steps:
实际看到什么 / Actual result:
频率 / Once, sometimes, every time:

如与附加相关 / For attachment issues:
- 新聊天还是已有聊天（不提供 URL/标题） / New or existing chat, no URL/title:
- 点击前/后已有正文是否相同（仅是/否/未知） / Draft unchanged: yes/no/unknown:
- 旧附件是否仍在（仅是/否/未知） / Existing attachments retained: yes/no/unknown:
- 新图片是否出现、是否有重复 / New card present, duplicate present:
- 微图是否收起，网页是否显示错误或完成 / Retracted, page error or completion:
- 是否已再次尝试（次数即可） / Any retries already made, count only:

可选 / Optional:
- 原生设置或历史中可见的错误代码 / Visible error code:
- 本机记录编号仅在私有支持明确需要时提供 / Local record ID only if requested privately:
- 是否主动附带诊断 / Diagnostic snapshot included by choice:
```

若怀疑错投、重复、正文改变或图片丢失，先停止对那张图片的后续操作，保留本地记录并私下报告；不要用重传或清库复现。报告不需要提供另一段聊天的内容，也不需要读取其他人的数据。

**English:** Use the in-app private feedback channel when available. Free text is not automatically redacted. Describe steps, versions and whether text/attachments were preserved, without including the content itself. Do not send screenshots, raw logs/databases, browser profiles or credentials. For possible wrong-target delivery, duplication or data loss, preserve records and stop further attempts on that image. A queued report is not a delivery confirmation; check its displayed status.
