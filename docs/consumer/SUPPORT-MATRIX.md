# Riftlet 1.0.5 支持范围

Riftlet 支持 macOS 和 Google Chrome 中可编辑的 ChatGPT 网页。ChatGPT 调整网页界面可能影响附加功能。

| 场景 | 范围 |
| --- | --- |
| Mac 安装 | macOS 13 及以上，Apple 芯片与 Intel 通用安装包。1.0.5 通过官网下载 DMG 安装。1.0.1 起支持应用内更新，请在 Riftlet 中选择「检查更新…」。 |
| 系统截图 | 从 macOS 实际截图保存目录收录新生成的截图文件。普通下载图片、剪贴板截图和屏幕录像不属于此入口。 |
| 图片格式 | 识别带系统截图标识的单帧 PNG、JPEG、HEIC、HEIF、TIFF。超大、损坏或不受支持的文件会被跳过；系统原件保留。 |
| 内置截图 | 经屏幕录制授权后可截窗口、区域、全屏。「更多」进入其他操作。 |
| 桌面与历史 | 截图托盘、风铃、微缝使用同一队列；切换即时生效，选择会保留。历史默认列表，可切换图像网格。两种视图共享搜索、筛选、分页、预览与恢复。 |
| 网页附加 | 支持 Google Chrome 前台当前可编辑的 ChatGPT 草稿。仅对明确点击的微图发起附加。其他浏览器、桌面 ChatGPT、只读页面不在本次范围。 |
| 接收与发送 | 页面开始接收对应图片时收起微图。网络上传进度、最终附件及消息发送由 ChatGPT 展示或执行；结果待核实的图片不自动重传。 |
| 反馈 | 自愿通过 App 私下提交文字；诊断默认关闭，可在发送前预览。 |

**1.0.0 首次安装。** 已在全新的非管理员 macOS 账户中通过 Finder 安装到个人「应用程序」文件夹，验证首次引导、拒绝文件夹权限后的恢复、Chrome 连接、系统截图收录，从历史找回图片，以及重启后继续收录。

**1.0.2 附加路径验收。** 已在隔离的 ARM64 macOS 27.2 图形会话、Chrome 156 专用匿名 ChatGPT 草稿中，使用 1.0.2 同源私有签名候选依次附加三张不同的系统截图。原正文及已有附件保留，每图各有一次操作和匹配的 START，微图按规则收起；第三张双击仍只有一次附加，全程未发送消息。另一次点击后切换标签时安全停在输入前，截图保留。该次同时出现匿名登录分支，证据仅覆盖这一组合场景。点击间隔约两到三分钟，覆盖连续独立使用；快速并发压力及服务端最终上传完成状态未在此记录中验证。[源码与实际验收范围](../../engineering/quality/2026-11-14/actual-chatgpt-attachment.json)

**安装与更新验收。** 官网 1.0.1 已在上述隔离 Mac 中经实际应用内更新安装到私有 1.0.2，核对历史、媒体、设置、目录书签、反馈草稿及原 UNKNOWN 保留，并验证新系统截图收录和重启。该记录使用私有签名更新源，正式公开更新包和清单核验另行记录。[升级验收](../../engineering/quality/2026-11-14/actual-private-sparkle-update.json)

**尚未覆盖。** 本次未完成实体 Intel、最低 macOS 13 和完整 VoiceOver 朗读的实际使用矩阵。系统和架构支持来自构建目标与相关 CI；上述当前真实界面结果限定于已记录的 ARM64 macOS 27.2 环境。

**较早记录。** 较早版本的真实双图记录和 1.0.0 验收时独立 Mac 连接 ChatGPT 超时的记录继续保留，各自对应当时的版本与环境。

**1.0.5 验证范围。** 已在隔离 Mac 上验证 1.0.4 到 1.0.5 的原位升级、托盘翻页和相机菜单。真实 ChatGPT 草稿当时连接失败，一次附加、连续双图及服务端终止后的恢复仍待验证。[专项验收报告](../releases/1.0.5/FOLLOW_UP.md)

**开发分支的默认 Edge 实测。** 独立签名的普通测试 App 已把不同系统截图附加到同一临时草稿，保留原文字、选区和附件。Riftlet 的上传开始与服务最终完成仍按每张图单独核验，Edge 未列入公开版本的已验收组合。[开发分支实测矩阵](../UNIVERSAL_ATTACHMENT.md)
