# 这一版支持什么

本页适用于 Riftlet 0.3.5 (19)。

| 场景 | 范围 |
| --- | --- |
| Mac 安装 | 目标为 macOS 13 及以上的 arm64 与 x86_64。build 19 的 App 和 DMG 均已通过 Apple 公证及 Gatekeeper 检查。更新需手动安装。 |
| 系统截图 | 从 macOS 实际截图保存目录收录新生成的截图文件。普通下载图片、剪贴板截图和屏幕录像不属于此入口。 |
| 图片格式 | 识别带系统截图标识的单帧 PNG、JPEG、HEIC、HEIF、TIFF。超大、损坏或不受支持的文件会被跳过；系统原件保留。 |
| 内置截图 | 经屏幕录制授权后可截窗口、区域、全屏。「更多」进入其他操作。 |
| 桌面与历史 | 截图托盘、风铃、微缝使用同一队列；切换即时生效，选择会保留。历史默认列表，可切换图像网格。两种视图共享搜索、筛选、分页、预览与恢复。 |
| 网页附加 | 支持 Google Chrome 前台当前可编辑的 ChatGPT 草稿。仅对明确点击的微图发起附加。其他浏览器、桌面 ChatGPT、只读页面不在本次范围。 |
| 接收与发送 | 页面开始接收对应图片时收起微图。网络上传进度、最终附件及消息发送由 ChatGPT 展示或执行；结果待核实的图片不自动重传。 |
| 反馈 | 自愿通过 App 私下提交文字；诊断默认关闭，可在发送前预览。 |

**安装实测。** 已在独立管理员账户从带下载隔离属性的 build 19 安装包首次打开，完成引导、截图文件夹权限拒绝与恢复，以及第一张系统截图的收录与历史找回。build 19 修复了 build 18 在共享安装位置的文件读取和执行权限问题。非管理员账户的首次图形登录与使用尚未完整验证。

**真实附加。** 在正式安装的 build 18 上，打开 Chrome 的 Apple 事件 JavaScript 开关后，两张不同截图连续进入同一 ChatGPT 草稿，正文和原附件保留；逐图确认开始接收并收起，消息未发送。build 19 的附加代码与 build 18 同源，两个架构均已核对。此项实测直接执行于 build 18。
