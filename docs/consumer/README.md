# 开始使用 Riftlet

Riftlet 在桌面边缘呈现新截图。把要用的 ChatGPT 草稿放到 Chrome 前台，点一下微图，就能在该草稿中附加这张图片。消息由你发送。

支持 macOS 13 及以上的 Apple 芯片和 Intel Mac。安装后跟随引导设置截图文件夹与 Chrome。[官网下载](https://riftlet.com/) · [已发布版本](https://github.com/haohongfei2001-png/Riftlet/releases)
