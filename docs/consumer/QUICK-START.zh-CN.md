# 第一次使用 Riftlet

先确认你拿到的是维护者明确提供的测试版本，并阅读[安装与权限](INSTALL-AND-PERMISSIONS.md)。当前个人构建不是已公证的公开安装包。

1. **打开 Riftlet。** 菜单栏图标是控制入口。首次引导会说明截图来源；以后可从「设置 → 权限与帮助 → 使用引导…」重新打开。
2. **确认截图保存位置。** 在「设置 → 权限与帮助」查看识别到的目录。需要授权时点「允许访问此位置…」，选择显示的系统截图目录。Riftlet 不会替你改变 macOS 的截图保存位置，也不会把该目录的旧图片全部导入。
3. **截一张不含隐私的图片。** 按平时习惯使用 ⇧⌘3、⇧⌘4 或 ⇧⌘5，并让截图保存为文件。等文件保存后，微图会出现在边缘。仅复制到剪贴板的截图不属于文件收录。快捷键和保存方式可见 [Apple 截图说明](https://support.apple.com/en-au/guide/mac-help/mh26782/27/mac/27)。
4. **准备 Chrome 中的 ChatGPT 草稿。** 选择你要使用的新聊天或已有聊天，确保页面已加载且能添加图片。编辑器不必持有输入焦点。首次连接按[权限指南](INSTALL-AND-PERMISSIONS.md)允许 Riftlet 自动化 Chrome，并自行开启 Chrome 的 Apple Events JavaScript 选项。
5. **点一下微图。** Riftlet 使用点击当时的 Chrome 窗口与标签页，不自动发送消息。聊天出现对应的新图片预览并开始接收后，微图快速收起；你可以继续点击下一张不同的截图。页面仍可能在上传，最终状态请看 ChatGPT。

微图收起表示 **START（草稿开始接收）**，不是“网络上传已完成”，也不是“消息已发送”。普通附加路径此后不持续替 ChatGPT 验证最终完成。图片与记录仍留在本地历史。

## 三个独立开关

| 开关 | 打开开关后的含义 |
| --- | --- |
| 暂停收录 | 暂停期间不收录；已有微图和历史保留。恢复时，目录里符合条件的截图仍可能被收录，包括暂停期间保存的截图 |
| 隐藏裂缝 | 隐藏边缘微图；不改变收录开关 |
| 启用内置截图 | 提供 Riftlet 的截图入口；关闭它不关闭 macOS 截图或系统截图文件收录 |

没有可见截图时边缘保持安静。想临时避免截图中包含 Riftlet，可先隐藏裂缝；这不是所有截图方式都能自动排除 Riftlet 的保证。

## 常用位置

- 「位置与显示」选择显示器、六个边缘位置和可见数量；详细尺寸仍可调整。
- 「动效」调整到达方式，并主动预览示意效果。预览不会附加图片。
- 「历史与存储」打开本地历史。默认「当前视图」与可选「图像网格」使用同一批记录；切换不清空查询、筛选或原图。
- 设置里的布局和归档草稿需要保存。关闭有未保存内容的窗口时，可继续编辑、放弃或应用并关闭；保存失败会保留草稿。

## 没有附加成功时

先看微图旁的提示或「权限与帮助」。只有明确写着本次未附加时，才按提示修正后重新点击。若显示“结果待核实”，请先在原聊天检查是否已有附件；不要通过重复点击、重新导入或清理数据来试探。见[图片找回与不确定结果](RECOVERY-AND-FAQ.md)。
