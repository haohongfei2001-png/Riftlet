# 第一次截图与附加

1. 从「应用程序」打开 Riftlet。「快速入门」会显示 Mac 的截图保存位置。若需要授权，选择显示的文件夹。
2. 选「去试一张截图」。用 macOS 自带的「截屏」截取窗口或区域并保存为文件，桌面边缘会出现缩略图。
3. 在普通 Google Chrome 或 Microsoft Edge 中，将要用的 ChatGPT 草稿置于前台，点一下缩略图。如果浏览器缺少授权，按当前浏览器的提示设置。Chrome 的「允许 Apple 事件中的 JavaScript」位于「显示 → 开发者」。授权后回到草稿，在托盘上向上滑动并点选刚才的截图。
4. 点击后，截图移入最近历史。请在草稿附件区查看附加结果。可以继续添加下一张图，消息由你发送。

**再次使用截图。** 在托盘上向上滑动查看最近截图，向下滑动回到当前托盘。托盘空了也可以点桌面边缘的时钟按钮打开最近截图。想再用哪张，就点击历史中的那张图。如果上次结果未知，先核对草稿里已有的附件。

**调整托盘。** 在「设置 → 截图托盘」调整位置、外观和闲置收起时间。隐藏桌面缩略图时，本地收录会继续。

**再次查看引导。** 选择「设置 → 帮助 → 快速入门」。已有安装可从 Riftlet 菜单选择「检查更新…」。
