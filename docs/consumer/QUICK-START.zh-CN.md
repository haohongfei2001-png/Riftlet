# 第一次截图与附加

1. 从「应用程序」打开 Riftlet。在首次引导中确认 Mac 保存截图的文件夹。需要授权时选择引导显示的那个文件夹。
2. 在普通 Google Chrome 或 Microsoft Edge 打开可编辑的 ChatGPT 草稿并将其置于前台。回到 Riftlet 引导，点击「检查浏览器权限…」。macOS 询问时，允许 Riftlet 控制刚才使用的浏览器。在浏览器菜单栏中开启「允许 Apple 事件中的 JavaScript」，然后回到 Riftlet 检查连接。Chrome 的开关位于「显示 → 开发者」。只使用本地截图历史时可选「稍后设置」。
3. 选好缩略图出现的位置，完成引导。用 Mac 自带的「截屏」App 截取窗口、区域或整个屏幕，将图片存为文件。桌面边缘会出现缩略图。
4. 把要使用的 ChatGPT 草稿放在所选浏览器前台，点一次缩略图。图片出现在输入框旁，原有文字和附件会保留。草稿开始接收图片时缩略图收起。可以继续点下一张，上传进度在草稿内查看，消息由你发送。

**找回截图。** 单击菜单栏的 Riftlet 图标，打开「截图仓库」。闲置的缩略图默认在 2 分钟后归档，原图保留。选中已归档的图片，点「恢复到桌面」即可再次使用。在设置中找到「闲置后归档」，可选择 1 到 10 分钟或关闭归档。

**调整桌面外观。** 在设置中选择截图托盘、风铃或微缝。各版本的入口见[设置入口对照](README.md#设置入口)。三种外观共用同一段历史。如想暂时隐藏缩略图，可在「设置 → 截图」关闭「显示桌面截图」，收录会继续。要停止收录，可从菜单栏选择「退出 Riftlet」。

**更新 Riftlet。** 从 Riftlet 菜单选择「检查更新…」。手动更新时，退出旧版、备份截图库，再用官网下载的 App 替换原位置的副本。[官网下载](https://riftlet.com/)
