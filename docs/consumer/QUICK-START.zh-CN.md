# 第一次截图与附加

1. 从「应用程序」打开 Riftlet。「快速入门」会显示 Mac 的截图保存位置。若需要授权，选择显示的文件夹。
2. 选「去试一张截图」。用 macOS 自带的「截屏」截取窗口或区域并保存为文件，桌面边缘会出现缩略图。
3. 在普通 Google Chrome 或 Microsoft Edge 中，将要用的 ChatGPT 草稿置于前台，点一下缩略图。如果浏览器缺少授权，按当前浏览器的提示设置。Chrome 的「允许 Apple 事件中的 JavaScript」位于「显示 → 开发者」。授权后回到草稿，再点一次截图。
4. 草稿开始接收图片时，缩略图收起。原有文字和附件会保留。可以继续添加下一张图，消息由你发送。

**找回截图。** 从菜单栏打开「截图仓库」，选中图片并恢复到桌面。如果上次附加的结果未知，先看草稿里是否已有这张图，再决定是否再次附加。

**调整托盘。** 在「设置 → 截图托盘」调整位置、外观和闲置收起时间。隐藏桌面缩略图时，本地收录会继续。

**再次查看引导。** 选择「设置 → 帮助 → 快速入门」。已有安装可从 Riftlet 菜单选择「检查更新…」。
