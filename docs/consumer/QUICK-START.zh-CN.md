# 第一次截图与附加

1. 从应用程序打开 Riftlet。单击菜单栏的 Riftlet 图标，打开「设置 → 截图」，核对「截图保存位置」。遇到权限提示，可按[安装与权限](INSTALL-AND-PERMISSIONS.md)完成对应一项。
2. 按 ⇧⌘4 截取一块区域，松开鼠标，让 macOS 存成文件。桌面边缘会出现新图。按住 Control 只复制到剪贴板时，没有供 Riftlet 收录的新文件。想从 Riftlet 截图，可在「设置 → 截图」开启「显示截图入口」。
3. 把准备附加的 ChatGPT 草稿放在 Google Chrome 前台。确认能编辑，单击桌面微图一次。打开聊天后仍可保留已有文字和附件。以**本张图片出现在该草稿的附件区**确认收到了正确的图。
4. 页面开始接收本张图片时，微图会收起，对应记录为 `START`。这不是最终上传完成；请在草稿里查看进度。下一张可独立单击，消息始终由你发送。如果草稿中未出现预期图片，先查看「截图历史」和网页，再决定如何处理。「结果待核实」会保留，Riftlet 不会自动重传。

**微图暂时找不到？** 单击菜单栏图标，打开「截图历史」。默认未使用的微图 **2 分钟**后归档，原图和私有副本都保留。可在「设置 → 使用与历史」调整为 **1 到 10 分钟**，或关闭自动归档。历史中选中可恢复的已归档或已移出图片，点「恢复到桌面」，即可找回微图。

**想改变桌面外观？** 在「设置 → 外观与布局」切换截图托盘、风铃或微缝。三种外观共用同一队列和历史。「暂停收录」控制新文件收录；「隐藏桌面截图」控制桌面显示。隐藏时仍可继续收录。[恢复与常见问题](RECOVERY-AND-FAQ.md)
