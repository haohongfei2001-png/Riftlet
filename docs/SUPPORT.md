# 兼容范围与问题排查

## 无扩展连接开发分支

Public Beta 0.3.5 (20) 的日常一键附加目标是 Chrome 中的 ChatGPT 草稿。Edge、Safari 和原生应用的原型使用隔离的测试图片，尚未取得对应商业服务的一键附加验收。当前台应用或草稿无法唯一确认时，截图留在队列。其他浏览器不需要安装扩展或修改剪贴板设置。[开发分支兼容性矩阵](UNIVERSAL_ATTACHMENT.md)

## 已知范围

个人 Beta 1 精确源码 `004741fe25cbdd59b72bf3c04ec061c7a1e2c0d5`，正式 main `b61fc46cf931bdbd14deec1b47d077e92db61e16` 继承其运行源码。已接受的真实证据包括 ChatGPT 五张连续附加，以及最终版冷启动双图；没有用本轮合成测试替代这些证据。

| 项目 | 当前结论 |
|---|---|
| 系统要求 | 源码部署目标 macOS 13+；不是已完成每个系统版本的外部验收 |
| 架构 | 工程 CI 构建 ARM64 与 Intel；当前个人安装版 arm64，Intel 实机体验仍需验收 |
| 聊天入口 | Google Chrome 的 ChatGPT 可编辑新聊天与已有聊天；页面和账号功能变化可能影响兼容性 |
| 其他应用 | Safari、Edge、Firefox、ChatGPT 原生 App 和其他 AI 网站不属于当前真实验收范围 |
| 系统文件收录 | 单帧 PNG/JPEG/HEIC/HEIF/TIFF；最多128 MiB、1.6亿像素、单边50,000像素；不支持剪贴板单独截图、PDF、动图或多页文件 |
| 文件附加 | PNG/JPEG原样输入，其他支持截图通常生成等分辨率PNG；派生PNG超预算时单次尝试原文件，接收取决于页面兼容性；源图保留；HDR显示效果另行验收 |
| 动态附件菜单 | 本轮受控真实浏览器原语覆盖；已验证个人Beta尚无该备用分支真实页面触发证据，作为兼容性项保留 |
| 冷 MAIN 跨窗口 | 可能将Chrome窗口前置；目前没有因此错投的已接受证据，作为体验项，不追加输入资格门槛 |
| 新设置设计 | 六页/控制中心修正版浏览器回归通过；原生界面尚未接入安装Beta |
| 分发 | 个人Beta为ad-hoc开发包；Developer ID、公证、Gatekeeper和外部新用户验收尚未完成 |

## 按现象排查

| 现象 | 检查与恢复 |
|---|---|
| 截图后没有微图 | 确认截图保存成文件、保存目录未改变、收录未暂停、裂缝未隐藏；使用“重新检查截图来源与权限”。首次安装不会收录全部旧文件。 |
| 文件夹无法访问 | 对照状态中的实际系统保存位置授予访问；检查系统“文件与文件夹”。不要改成另一个普通图片目录。 |
| Chrome未连接 | 先打开Chrome；检查系统自动化授权与Chrome的Apple Events JavaScript选项，二者独立。 |
| 点击后图片保留 | 看运行状态的具体原因；确认当前是可编辑聊天及附件入口可用。Riftlet不会因点击动画就认定接收成功。 |
| 微图收起但聊天还在上传 | 收起依据是实际接收开始，网络传输由ChatGPT继续；这属于预期行为。 |
| 结果待核实 | 查看原聊天的对应附件，不清空DB、不重置旧操作、不反复恢复同图；记录发生时间和版本后反馈。 |
| 暂停/隐藏/关闭入口但保存失败 | 当前停止可能已生效，重启后的保存仍未确认；保留原操作意图重试该域。不要把重试变成反向恢复操作。 |
| 内置截图取消 | 取消不应产生新可见项。若授权被拒，按系统对应屏幕录制入口恢复，不需重置所有权限。 |
| 磁盘不足或写入失败 | 先在系统中处理可支配空间或访问问题，再重新检查；保留Riftlet数据库、journal、媒体和原图。 |
| 更新后无法启动 | 停止重复启动，保留新旧App和数据副本，按包清单及兼容范围回退；不要在未知迁移后直接降级数据库。 |

反馈时提供 App 版本/构建身份、macOS及Chrome版本、发生时间、操作顺序、是否有附件与正文变化。优先使用应用“反馈与建议…”；若通过仓库问题区报告，只提供不含隐私的描述。开发人员应使用受控生成图片重现，不要求用户反复上传私人截图。

## 外部验收仍需完成

在正式发行前按支持矩阵验证干净安装、签名更新后的授权、真实物理多屏/Spaces和睡眠唤醒、辅助功能/中文输入法、不同系统和架构。CI、隔离文件系统/Chromium测试与真实账户验收分别记录；尚未执行的项目不能标PASS。
