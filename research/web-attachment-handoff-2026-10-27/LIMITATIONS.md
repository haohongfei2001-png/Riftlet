# 边界、UNKNOWN、迟到失败与恢复

## 已通过的范围

- 真实 Chrome Apple Events 自动附加三张合成图，文字（包括中文/emoji 和选中文字状态下的草稿内容）及既有附件保留。
- 真正手动 File 输入的正常生命周期与精确预览证明；不是此前错绑标签页的缺失轨迹。
- 两个不同合成附件的实际重叠上传、继续输入合成文字，无附件认领串线。
- 上传中原生 XHR 中断，以及本图 UI100/原生字节100% 后、完成前的 XHR 中断；均无最终预览，未误判 ATTACHED。
- 原草稿切换“临时聊天”使 route 改变并失效。Home→Home 没有切换，NOT_EXERCISED；历史 `TAB_SWITCH` 标签不得解读为活动标签页切换。
- 原图保留、原意图再次分派的本地拒绝、刷新失去 observer 后 UNKNOWN；未实际重复上传。

日志与所有回放仅证明这些样本。不是统计可靠性估计，不证明消息已发送、服务器最终完成或所有页面版本兼容。

## 恢复规则与已实现程度

| 情况 | 必须的处理 | 已交付代码/证据与限制 |
|---|---|---|
| 分派前 | exclusive-create + fsync 意图，带原 operation/asset/target | 两套 Python 分派器；正式工程应沿用数据库事务，而非按实验路径部署 |
| 分派成功回执 | 只记 inputTriggered/候选 | 不能消费；`change` 返回并非完成 |
| 超时、失联、刷新、进程退出 | UNKNOWN，原图与意图保留，只读核对原目标 | AE timeout/query 示例；刷新实际证据已保存，进程崩溃/重启全流程未真机覆盖 |
| 重复调用 | 本地拒绝，不再次触达 input | MID/POST100 的重复意图检查真实执行；transport 不变 |
| 本图移除、被替换、重新上传、错误 | 否决 ATTACHED，保留原图 | 生命周期审计拒绝；UI 未展示关联错误时不捏造“明确失败” |
| 换草稿或收据迟到 | 原 lease 失效，不能把旧结果归给新草稿 | 真正 temporary-chat 路由样本；完整 tuple 反例见 v1，其他代际情形未真机覆盖 |
| 用户继续输入、其他文件完成 | 保留本图独立状态，不把文字 hash 当代际，不借用他图完成 | 真实并发/输入轨迹；新同名附件冲突需保守拒绝 |
| 正向 ATTACHED | 消费前重验，持久化关联结果；仅可恢复地移出待处理区 | 本包是判定/证据；未实现正式队列、动画或消费事务 |
| ATTACHED 之前观察到迟到错误 | 同一附件错误否决成功，无自动重传 | v1 反例及异常审计器两个新回放检查都是 SIMULATED |
| 已经消费之后出现迟到失败 | 保留本地原图，关联旧操作，恢复可处理/待核对状态；不重传 | **策略要求，未完成生产 rollback 实现，未取得真实迟到失败样本** |
| 用户决定重试 | 先核对原操作是否仍有残留，之后显式新 attempt | 没有 retry-safe profile；不能将 abort/status0 直接等价为“可安全重试” |

`UNKNOWN` 不意味着所有正常上传永久未知：完整逐图生命周期和内容证明满足时能返回 ATTACHED。缺失的目标关联、错误、内容或完成证据才阻止消费；禁止用固定等待补齐。

## 保留 NOT_TESTED / NOT_PROVEN

- 严格内部 READY：没有明确、可关联的正向应用完成回执；继续 NOT_PROVEN，本交接不再研究。
- 服务端最终化 HTTP 5xx/明确拒绝；最终预览后迟发错误。已有100%用例是客户端 abort，不是这两个场景。
- 同 URL、同 DOM 节点、不出现已观察失效事件的换草稿；通用服务器草稿 epoch。
- 浏览器活动标签切换、多 profile 正确自动捕获、浏览器重启及进程崩溃后的完整恢复；本地生成 session/nonce 不能代替这些证据。
- 同名冲突、DOM 卡片重建/移动、未知页面版本、多帧 composer；规则是拒绝含糊关联，不声明已经真机测试。
- 已消费后的逆向动画/队列恢复、人工确认重试之后的端到端恢复。
- Web Work 独立 surface、ChatGPT Mac 客户端、Classic：不由本包准入。
- PNG 以外格式、图片缩放/有损转换/不同色彩管线；不能拓宽精确 RGBA 校验的实测适用范围。

## 故障证据解读

MID 和 POST100 的网络事件只使用已观察到的自有创建响应关联上传地址。请求 URL、响应体、服务器文件 ID 均未公开。原生 upload progress 回调的日志写入可发生在 abort 回调之后，故保留原顺序及 requestLocalId，不重新编排为猜测的服务器顺序。

v1 的 followup 规则把请求体引用文件 ID 的旁路 fetch 也纳入了观察，出现 TypeError；这些不计为上传失败或重传。v2 收紧为精确路径片段。证据文件保留版本来源以便复核，不将旁路错误冒充本图中断。fault bridge 已 STOPPED；本次交接没有调用任何实机代码。

## 公开数据边界

`PROVENANCE.json` 记录本地实验的项目相对来源和原文件哈希。公开日志是去敏投影，不承诺与本地原日志字节一致。浏览器身份一致替换保留相等/不等关系，真实实例值和对应表不公开。操作/图片 UUID 均是实验生成、只与合成图有关，可保留。

完整 HTML、任意 leaf text、网页载荷属性和 profile 信息被剔除；已保留的正负判定在去敏后重新回放一致。图片只有蓝/橙生成图和随机噪声，未发布屏幕截图附件。公开 runner 只离线读取；`src/lab-only/` 不能在生产页自动执行。
