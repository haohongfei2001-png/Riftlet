Getting started

Start with a screenshot you’re comfortable sharing. The Riftlet icon in your Mac menu bar opens settings, history and feedback.

Quick start Installation Permission recovery FAQ Feedback

Quick start

  1. Check the save location. Open Settings → Permissions & Help (权限与帮助). If access is needed, choose 允许访问此位置… and select the screenshot folder shown there.
  2. Take a screenshot as usual. Use Shift-Command-4 for a region, or your usual macOS shortcut. Once the file is saved, look for the thumbnail at the screen edge. Clipboard-only captures are not collected.
  3. Click the edge thumbnail. Keep the intended chat active in Chrome, with an editable draft that accepts images. The text field does not need keyboard focus. The thumbnail retracts when the draft begins accepting that image.

Check the new attachment, your text and any existing attachments in the original draft. You can click a different screenshot next. You decide when to send the message.

Installation

There is no public installer. If the maintainer supplies an approved test build, check its source, architecture, version and SHA-256 against the delivery instructions. If Riftlet is already installed, quit it first and keep the previous App and a verified backup.

If macOS blocks the App, keep the alert and contact the maintainer who supplied it. Leave system protections in place while you wait for a verified package.

Permission recovery

Screenshot folder
In 权限与帮助, select the folder shown. If needed, check System Settings → Privacy & Security → Files & Folders. Return to Riftlet and choose 重新检查 to check again. Riftlet leaves the macOS save location as you set it.
Automation permission
Open Chrome, then choose 检查 Chrome 权限… in Riftlet. If you previously denied access, open System Settings → Privacy & Security → Automation and allow Google Chrome under Riftlet. Return to the App and check again.
Chrome’s JavaScript setting
In Chrome, choose View → Developer → Allow JavaScript from Apple Events. This setting and macOS Automation are separate requirements for the browser handoff. You can continue collecting screenshots locally with the Chrome connection off.
Optional built-in capture
Riftlet’s own window, region and screen capture tools need screen recording permission. You can continue to use normal macOS screenshot files without granting it to Riftlet.

FAQ

Why did my screenshot not appear?

Wait for the floating macOS preview to save as a file. In the menu bar check 暂停收录 (pause collection) and 隐藏裂缝 (hide thumbnails), then check folder access and free space. Eligible screenshots still in the folder may be collected when you resume.

What if there is no chat ready?

The thumbnail stays at the edge. Bring the intended chat to the front in Chrome and make sure its draft can accept an image. Click again only if the App explicitly says the image was not attached.

If a thumbnail disappears, has the upload finished?

After an attachment click, the thumbnail retracts when the draft starts accepting that image. Putting it away yourself or letting it archive only changes its local visibility. Check the original ChatGPT draft for upload progress, completion or an error. If the result is uncertain, keep the record and check the attachment there. Riftlet does not automatically submit it again.

Where can I find an archived thumbnail?

Open history from the menu bar, or go to Settings → 历史与存储 → 打开历史…. Viewing a record does not upload the image. Eligible records can return to the edge. Keep uncertain submissions with their original record.

Feedback

Open 反馈与建议… from the menu bar or from Settings → 权限与帮助. Include the version, the shortest steps and what you saw. Choose 发送反馈 to submit. Closing the window saves a draft.

Preview the optional diagnostics before sending. Your own text is not automatically redacted. Say whether a new image appeared and whether the draft and previous attachments stayed intact. Screenshots, chat text, full paths and account details are unnecessary.
