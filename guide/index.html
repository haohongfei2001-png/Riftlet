使用指南

第一次使用，从一张不含隐私的截图开始。所有常用操作都可以在 Mac 菜单栏的 Riftlet 图标中找到。

快速开始 安装 权限与恢复 常见问题 反馈与建议

快速开始

  1. 确认保存位置。打开「设置 → 权限与帮助」，查看系统截图位置。如果需要授权，点「允许访问此位置…」并选择那里显示的文件夹。
  2. 照常截一张图。按 ⇧⌘4 选择区域，或用平时的 macOS 截图方式。等截图保存为文件，新微图会出现在屏幕边缘。只复制到剪贴板的截图不会被收录。
  3. 点一下边缘微图。让目标聊天在 Chrome 的当前标签页打开，确认草稿可编辑且能添加图片，再点微图。无需先点文字输入框。草稿开始接收这张图时，微图收起。

到原草稿查看新增附件、原有文字和附件，再决定是否发送。可以接着点击另一张不同的截图。Riftlet 不会替你发送消息。

安装

当前没有公开安装包。收到维护者明确提供的测试包时，请先核对来源、适用芯片、版本和该次交付的 SHA-256，再按随包说明安装。已有 Riftlet 的 Mac 先退出 App，并保留备份和旧版。

如果 macOS 阻止打开，保留提示并联系提供该包的维护者。保持系统安全设置，等待可验证的安装包。

备份、更新与回退

权限与恢复

系统截图文件夹
在「设置 → 权限与帮助」选择显示的目录。需要时到 macOS「系统设置 → 隐私与安全性 → 文件与文件夹」检查访问权限，然后回到 Riftlet 点「重新检查」。Riftlet 不改变 macOS 的保存位置。
允许 Riftlet 控制 Chrome
先打开 Chrome，再点 Riftlet 的「检查 Chrome 权限…」。此前拒绝过，可到「系统设置 → 隐私与安全性 → 自动化」，在 Riftlet 下允许 Google Chrome，再回到 App 重新检查。
允许 Chrome 接收页面指令
在 Chrome 菜单「显示（或视图）→ 开发者」启用「允许来自 Apple 事件的 JavaScript」。这个开关与 macOS 自动化权限分别控制页面连接。选择不开启也可以继续本地收录。
可选的内置截图
只有使用 Riftlet 自己的窗口、区域或全屏截图时，才需要对应的屏幕录制权限。也可以继续使用 macOS 系统截图。

常见问题

刚截完图，为什么看不到微图？

等系统浮动预览保存为文件。在菜单栏检查「暂停收录」与「隐藏裂缝」，再检查截图目录和可用空间。恢复收录后，仍在目录中的合格截图可能会补收。

点击时没有可用聊天，怎么办？

微图会留在边缘。把要使用的 Chrome 聊天切到前台，确认草稿能编辑、能添加图片。仅在明确提示本次未附加时，再点一次。

微图从边缘消失，表示上传完成了吗？

点击附加后，草稿开始接收这张图片时，微图会自动收起。手动收起或到期归档只改变本地显示，无法据此判断附件状态。请到原 ChatGPT 草稿查看进度、完成或错误。若结果待核实，保留本地记录，先核对原附件。Riftlet 不会自动再次附加。

在哪里找回已收起或归档的截图？

从菜单栏打开历史，或前往「设置 → 历史与存储 → 打开历史…」。查看图片不会上传。可恢复的记录可以放回边缘；结果待核实的图片请留在原记录中核对。

反馈与建议

从菜单栏或「设置 → 权限与帮助」打开「反馈与建议…」。写下版本、最短操作步骤和实际看到的结果，再决定是否点「发送反馈」。关闭窗口会保存草稿。

诊断可在发送前预览，由你选择是否附带。正文不会自动脱敏。只需描述是否出现新图片、旧附件与文字是否仍在，无需提供截图、聊天正文、完整路径或账号信息。
