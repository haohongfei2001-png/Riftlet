Privacy & local data

Your screenshot files and Riftlet’s private copies stay on your Mac. Clicking a thumbnail shares that image with ChatGPT. Submitting feedback shares your report with the maintainer.

Files and storage

Original screenshots
macOS saves screenshots in the folder you chose. Riftlet keeps a private copy when it collects a new screenshot. The original remains where macOS saved it.
Private copies and history
In Finder, press Shift-Command-G and enter ~/Library/Application Support/Riftlet/ to find the ordinary installation’s data folder. It holds media, history, configuration and feedback data. System preferences also store the screenshot-folder bookmark. Feedback credentials are held in Keychain.
Storage usage
Choose Settings → 历史与存储 → 检查用量 to see logical sizes for media, staging, import journals, built-in captures and the queue database and its companion files. System originals, feedback and external backups are counted separately. Reclaimable space depends on the file system.
Retracting and archiving
Removing one or all thumbnails from the edge or archiving them changes their visibility in Riftlet. Original files, private copies, history and attachments already in a chat are retained. The App currently has no permanent-delete control for these screenshot copies.

Sharing with ChatGPT

During attachment, Riftlet checks the editor, relevant controls and attachment previews in the current Chrome page. It temporarily reads text and selection to check that the draft is preserved. The handoff contains the image you selected. ChatGPT can receive it before you send a message, under your account and service settings.

Riftlet has no account, screenshot cloud sync or background usage telemetry. Viewing local history, retracting and archiving do not remove chat attachments.

Feedback and withdrawal

After you choose Send, your text, category, random report ID, version and submission time go over HTTPS to Riftlet’s Cloudflare receiver and may reach the maintainer’s private feedback center. The maintainer may use authorized AI assistance to review it. Optional diagnostics include a limited set of event types and counts.

A submitted report can continue sending after connectivity returns or the App restarts. Check each record in the feedback window to cancel or request deletion. A report that has already attempted delivery needs service confirmation for deletion. A locally saved status confirms only local storage. Uninstalling does not withdraw a submitted report.

How to send feedback

Backup, update and rollback

  1. Save and quit. Save settings and feedback drafts and quit Riftlet from its menu bar. A verified offline backup includes the full data folder, with databases and their companion files, media, journals, configuration and feedback. Keep original screenshots and the previous App separately.
  2. Follow the manual update instructions. Check that the new version can read the current history before replacing the App. A change in signing identity may require you to select the screenshot folder again. Check actual collection with a new sample image.
  3. If an update fails, keep both versions. Quit and back up the latest data. Roll back only the App after confirming the older version understands the current history. Restoring a stale database over current data would lose newer records.

The folder backup excludes macOS preferences and grants, Keychain and system originals saved elsewhere. Store the backup somewhere private.

Uninstalling and cleanup

Quit Riftlet and move the App to Trash to stop using it. Private media and history, original screenshots, backups, preferences and feedback credentials may remain. If space is low, pause collection and check the usage report.

If you intend to clear data, keep a complete backup first and identify any uncertain submissions. Deleting individual media or database files can break image recovery and the records needed to check an uncertain attachment.
