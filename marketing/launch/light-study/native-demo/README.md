# Meridian Inlet · Public Beta desktop excerpt

The released universal executable ran from the verified build 20 disk image in an isolated settings-review session. Two original tide illustrations were displayed in an owned window. macOS captured that window twice. A PID-filtered WindowServer recorder captured the actual Riftlet floating layers over a blank paper backing. The cursor and surrounding desktop were excluded. The editor preserves all 720 native frames in order at 30 fps. The silent edit pairs each native state with the appropriate screenshot and opens up the framing after the second image arrives.
