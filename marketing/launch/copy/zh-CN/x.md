## 媒体卡片标题

把这一处，带进草稿。

## 发布主帖

```text
两张潮汐图，同一处岸线。哪一张才是你想问的？

在 Mac 上照常截图，把正在写的 ChatGPT 草稿切到 Chrome 前台。点桌面边缘对应的微图，就能附上那张截图。

Riftlet 公开测试版 https://riftlet.com/
```

## 一句话介绍

```text
Riftlet 把刚截好的图放在 Mac 桌面边缘，让它离 Chrome 里正在写的 ChatGPT 草稿只差一次点击。
```

## 可选串帖回复

```text
ChatGPT 开始接收这张图时，微图就收起来了。去草稿的附件区核对，继续改你的问题，写好了再按发送。
```

## 常见问题回复

**点一下会把我写的消息发出去吗？**

```text
你决定何时发送。点击微图只会把选中的图片交给当前可编辑的 ChatGPT 草稿。
```

**可以用 ChatGPT 的 Mac 桌面版吗？**

```text
当前公开测试版支持 Google Chrome 里的 ChatGPT 可编辑网页草稿，桌面 App 和其他浏览器暂未支持。
```
