# 画面与声音来源

两张潮汐图是为这次拍摄创作的虚构图版。两种潮位共用一个连续高程函数与两个测点，没有引用地理测量资料、图库或第三方底图。可用 [图版源文件](../video/project/plates.py) 重建 [低潮](plates/low.png) 和 [高潮](plates/high.png)。图版、排版、剪辑和配音轨中的音符供 Riftlet 使用并随本套推广素材分发。

产品像素来自公开发行的 macOS App，拍摄对象仅限本项目新建的非私人演示图片。原始录屏及系统截图在本工作树的 `source/raw/` 保留。这里采用目录级 Git 忽略规则，避免未审阅原片进入历史。经过白名单取景、公开内容复核的制作素材与导出由本分支追踪。详细连接关系见 [拍摄记录](../video/capture-log.md)。

官方图标沿用[官网 SVG](../../../website-assets/riftlet.svg) 的完整图形和配色。英文展示字由项目已使用的 [Instrument Serif](../../../website-assets/fonts/Instrument-Serif-OFL.txt) 排印。系统字体只用于渲染，成品中仅包含文字像素。中文标题使用 macOS 宋体，正文使用苹方，英文正文使用 Helvetica Neue。品牌标识的归属不改变。影片的提示音在工程内合成，未使用歌曲、采样、第三方音效或旁白。Riftlet、Google Chrome、ChatGPT 和 macOS 的名称均按其实际指代使用。
