# 音乐与声音设计

《截屏、点选、继续》的配乐围绕 D–E–A 三个音展开。开头由近距离毡槌敲出动机，在两次截屏之间发展成轻巧的切分节奏。点击前留出短暂的安静，附加出现时加入低音和两个短共鸣。后半段恢复打字和律动，最后以原动机和 D 小调六九和弦收束。

`score.py` 是完整乐谱、合成器、拟音、混音和母带工程。需要 Python 3 和 NumPy。运行 `python3 score.py score-master.wav` 可生成双声道 48 kHz、24-bit PCM 母带。随机部分使用固定种子。没有外部采样、素材库、语音、第三方乐曲或生成服务。本片没有使用音频生成提示词。室内声场、弦音、钢琴毡槌与木质共鸣、贝斯、轻打击和操作声均为本片合成。拟音仅用于广告混音。

| 横版时间（秒） | 声音落点 |
| --- | --- |
| 0.055 / 0.36 / 0.85 | 三音动机，左近至右中，小组乐器进入 |
| 5.10 / 5.55 | 第一次快门、缩略图落位 |
| 8.10 / 8.55 | 第二次快门、缩略图落位 |
| 13.20 / 13.45 | 单次鼠标按压、图片成为草稿附件的落点 |
| 17.80–20.62 | 两组打字与自然停顿 |
| 23.00 | 低音与弦音拾起片尾和声 |
| 25.62 / 26.00 / 26.62 | D–E–A 三音片尾签名，尾声自然衰减 |

横版母带为 1,440,000 个双声道采样帧。FFmpeg `ebur128=peak=true` 测得 −15.9 LUFS，LRA 2.2 LU，真峰值 −3.1 dBTP。Apple `afclip` 检查无削波。以上测量对象为 WAV，视频 AAC 转码后的最终测量以成片验收记录为准。

## 15 秒竖版

主片通过剪辑复核后，竖版提取主片开头 2.18 秒的分轨，在原来的乐器、和声和节奏单元上重新安排其余段落。单击前的短停顿与结尾的 D–E–A 动机都保留。`short_score.py` 和 `score.py` 放在同一目录后，运行 `python3 short_score.py score-vertical.wav`。

| 竖版时间（秒） | 声音落点 |
| --- | --- |
| 2.53 / 3.03 | 首次快门与托盘落位 |
| 4.43 / 4.83 | 第二次快门与托盘落位 |
| 7.54 / 7.75 | 单击与附件出现 |
| 9.60–11.19 | 继续输入 |
| 12.00 | 品牌画面和声 |
| 12.60 / 12.95 / 13.50 | 片尾三音，衰减至 14.9 秒 |

竖版母带为 720,000 个双声道采样帧，15.000 秒。FFmpeg EBU R128 测得 −15.9 LUFS、2.8 LU LRA、−3.7 dBTP。Apple `afclip` 无削波。Apple SoundAnalysis 本地模型逐段检查，两部母带的全部 15 个三秒窗口均把音乐列为首项（横版 0.77–0.95，竖版 0.84–0.95）。当前审片环境未提供可感知的音频输入，未记录主观听感。
