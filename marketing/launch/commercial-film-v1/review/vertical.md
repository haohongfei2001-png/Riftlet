# 竖屏短片

中、英文各 15 秒。手机画面使用与主片相同的桌面、系统截取区域、屏幕边缘缩略图、指针与草稿图层。片中「交互示意」对应该真实感合成，没有使用个人账户素材。

## 剪辑与取景

| 竖版时间 | 主片时间 | 观众看到的操作 |
| --- | --- | --- |
| 0–6.00 秒 | 0–6.00 秒 | 原草稿有一张总览图和一个问题。截取分日访问量图；屏幕边缘从空到出现缩略图，随后单击。新图从 4.80 秒开始出现在已有附件旁。 |
| 6.00–11.50 秒 | 10.00–15.50 秒 | 回到同一草稿。靠近输入区域，跟随光标写完第二句，再带出保留的附件和发送按钮。 |
| 11.50–15.00 秒 | 16.50–20.00 秒 | 同一草稿保持打开。沿主片斜向转场进入品牌收尾和下载地址。 |

剪辑保留原速。两个切口分别采用 35 毫秒的升余弦交叉淡化，仅接合切点前的余音。截图、缩略图出现、点击、进入附件的声点沿用 2.73、3.16、4.33、4.80 秒；输入由第 7 秒开始，尾标声点在 12.05 秒。英文片的输入特写随句长拉开，为第二句和光标留出空间。「两种外观」的补充镜头留在横版。

## 重建

从本项目目录执行以下命令。操作系统字体和 Python 依赖同主片制作工程。竖版直接读取同目录下的主片画面工程与 `film/score.wav`。

```sh
python studio/vertical.py zh-CN --render
python studio/vertical.py en --render
```

对应语言目录下的 `vertical.mp4` 为成片，`vertical-thumbnail.png` 为从该成片 5.70 秒解出的第 172 帧，`vertical.srt` 为可选字幕。

## 成片验收

2026-11-23，中文与英文版各自经过 macOS AVPlayer 1 倍速独立播放。两次都呈现了 450 帧、到达 15.00 秒片尾并收到正常结束事件。中文实时时钟用时 15.17 秒，英文 15.12 秒。复核了每条完整播放时间线上 43 个观察点，另在源画面精查 4.33 秒的点击。声音通过成片 AAC 的 EBU R128 检查，本次回放的本机扬声器保持静音。

开头的草稿只有暖色总览图。2.73 秒截取的曲线图在空白边缘出现，4.33 秒点中缩略图，4.80 秒后它和原图同处一行。第 7 秒开始继续写；在完整输入区镜头中，发送键完整可见。片尾的域名和 Mac 下载提示约有三秒独立阅读时间。

两张 PNG 均与对各自成片单独定位至 5.70 秒重新解码的结果逐像素匹配。中文与英文各七条可选字幕，按竖屏时间码另行编辑。
