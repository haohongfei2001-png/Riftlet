# 影片结构与剪辑选择

主片与三条短片使用同一组为公开拍摄创作的低潮、高潮图。画面中的两个橙色测点固定，可以凭海湾形状识别新进托盘的是哪张图。没有录取浏览器画面时，读者仍能分清屏幕上实际发生的桌面动作与文字介绍的下一步。

| 主片镜位 | 观众看到什么 | 画面和声音的处理 |
| --- | --- | --- |
| 开场 | 暖纸上的问题和海湾局部，观众先认出要讨论的东西。 | 原始图版做平面特写，海岸在固定构图内缓慢移动。低音轻入。 |
| 系统截图 | 在专门的样张窗口拍摄原创图版。 | 使用 macOS 实际生成的窗口截图。显示取景结果；截图快捷键或选区框只有实际录到才出现。 |
| 托盘 | 同一幅图出现在实际运行的发布版内，下一张可以并排辨认。 | 只取该进程的窗口；固定裁框保留原始时序。操作字幕与图面分区。 |
| 选择 | 截图入口的动作、选择一张图的本地响应。 | 给选择动作足够停留时间。无真指针素材时保留原动作，通过画面外的标注说明输入。 |
| 草稿 | 独立的文字镜位交代在哪个程序打开草稿、接收与发送的区别、历史测试范围。 | 不展示示意网页。没有当前真实接收画面时，文字卡不得看起来像附件或聊天界面。 |
| 收尾 | 官方标志、Riftlet、网址、系统与 Beta。 | 留足阅读或暂停时间；和音自然衰减。 |

竖片从版面上重新分配空间，上半屏最多一个问题，中部安排人眼可辨认的原生托盘，下半屏安放一句操作。第一条围绕按图找回，第二条围绕展开托盘，第三条围绕两次潮位图片的收录。精确入出点见 [拍摄记录](capture-log.md) 与 `video/project/` 下的剪辑源。
