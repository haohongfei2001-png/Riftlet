# Local delivery checks

From the repository root, run the verifier with a Python environment that has PyAV, Pillow and NumPy. macOS and its Command Line Tools supply the AVPlayer runtime and Swift compiler. The check opens no application windows. AVPlayer plays the complete local video in real time at rate 1 with audio muted. Its video output delivers images according to the player's own presentation clock. The final status requires the natural-end notification and coverage across the complete duration. The terminal needs access to the Mac's media services for AVFoundation to decode H.264. No screen-recording permission or screen capture is used.

```sh
build/launch-production/venv/bin/python marketing/launch/video/project/verify/check_media.py \
  --scores build/launch-production/audio \
  --out build/launch-production/qa/review-01
```

Select an empty output directory for each run. The player writes a full-size JPEG from the displayed video for each elapsed second and one from the last displayed frame. `player/<movie>/player.json` records the wall clock, media clock, displayed-frame count, largest inter-frame gap and the natural playback end. The separate audio read decodes the AAC track and measures the first and last audible signal, peak and stream endpoints. This check runs muted.

Pass the WAV directory generated by the editor with `--scores` to compare the audio after encoding with the original cue envelope on a 10 ms grid. The verifier records the strongest correlation and its lag relative to the edit. The three portrait edits may each have more than one language version. All identified MP4s play to completion. For a partial recheck select `--groups video` or `--groups gif images covers`; use a fresh output directory for each run.

The graphics pass verifies PNG integrity and decodes the full image. It composites every GIF frame twice, requires matching pixel digests and delays on the two traversals and records first/last pixel variation alongside the largest adjacent change. The infinite-loop flag, dimensions, frame timing, distinct-frame count and two cycle durations are in `report.json`. A seam value measures changes in mean channel levels on a small sample. Read it alongside the visible first and last frames.

The local `sheets/` directory contains one timecoded sheet per video, one loop strip per GIF, and contact sheets for the images and covers. Open those sheets, then inspect fine text, crops or controls in the full-size images. Use the final report's SHA-256 values to associate playback and visual findings with the exact exports.
