# Riftlet · 薄界 / Quiet edge

**一套已收敛、可操作、可直接指导原生实施的最终设计建议。** 基线是正式工程 `1920e0562db893a3292af89a89270a26ddb46a5f`。新视觉尚待创始人审阅；本轮没有把设计自动批准为原生实现，也没有修改正式 App、Core、Web、SQLite、准入或 PR #1。

## 先体验，再读规格

1. 打开 **[Riftlet-Product-Prototype.html](Riftlet-Product-Prototype.html)**。单文件、离线运行，无安装、无联网依赖。
2. 看右缘的日常三图，然后点一张。图片先等待，合成开始信号到达才快速吞噬；完成随后更新在草稿和历史中。
3. 靠近右缘上方相机，切换窗口／区域／全屏。槽位固定，只有取消盖片移动；在合成桌面点击或拖出选区，拍完仍保持展开。按当前 X 或 Escape 才退出。
4. 在“设置 → 显示与动效”比较**无／磁力吸引**。这个选项只管新截图来到裂缝；不会关闭独立的快速吞噬。原型初始“无”仅便于首轮观察，不是擅定产品默认值。
5. 切到“十二图”、长图1:8或宽条8:1。打开“100%逻辑尺寸”，横向滚动到右缘看实际大小；小屏队列可以翻页。评审控制条不属于产品界面。
6. 打开首次使用、历史、反馈。反馈草稿可关闭再打开，也可保存为待发送、取消、移除本页合成记录。没有云端已送达状态。

需要逐个观察状态时，打开底部“状态演示”，选择“手动分步观察”：先点微图，依次点“模拟严格开始”和“模拟最终完成”。开始与完成是两个独立动作；选择“模拟结果未知”后，图片隐藏到历史，原目标仍受保护。未来安全失败重生单独标注为**尚未开放的条件状态模拟**。

**本页所有图片、草稿、权限、上传、历史和反馈均为合成数据。** 原型只保存在当前页面内存，刷新即复位；“本机保存”是所设计的原生产品文案，不代表此HTML创建了SQLite或真的保存到磁盘。不会读取系统截图、剪贴板、浏览器账号或真实聊天，也不会发送消息。演示安排的900ms等待不是实际性能指标。

## 推荐的统一方向

裂缝是一条稳定的桌面遮挡边。截图以自己的比例伸出它，编号支持位置记忆。空间感来自遮挡与连续运动，不来自发光、波浪或装饰。预测入口保持一块细窄玻璃；辅助窗口使用相同的字体、间距和颜色角色，但保留原生窗口各自清楚的信息结构。

本轮集中解决四个不成熟之处：极端比例图难以点中、长队列改变首图位置、辅助窗口各有一套层级，以及等待／开始／完成混为一种视觉成功。推荐保留72×56pt包络、25%遮挡和60pt行距，增加可见编号垫片、稳定首槽和可选完整预览；细直边界改为一个设备像素。

已有青绿split-R图形保留。“薄界”是艺术方向的工作名称，不是品牌更名。精确数值、材质和新辅助交互均标为本轮建议，详见[决策分类](DECISIONS.md)。

## 精确实施入口

`APPKIT_SPEC.md`为原生空间／交互规格，`motion/MOTION_SPEC.md`为精确时间函数的唯一来源，`TOKENS.json`用于快速取值。图稿负责视觉、原型负责合成可操作流程；若遇未注明的差异，不得把HTML的浏览器实现细节当作Core行为来源。

随后实施应继承现有截图上传机制、Feedback v0.1以及独立预测入口和原生磁力分支。不要重新实现上传、反馈存储或第二套Presenter。新增远端磁力分支的检查见[补充审计](research/arrival-native-branch-check.md)：实际实施节奏、source准入与本设计推荐必须分开。

## 保持的发行边界

- 限定真实快吞噬历史证据不变；本轮未重传H、F或旧UNKNOWN。
- 普通生产上传、安全失败／安全重试仍关闭；反馈服务没有部署。
- 当前候选支持范围不因设计扩大：Chrome中文ChatGPT普通已有对话，以及已有profile所限的原始PNG。
- 无ACK冷首击、人工物理鼠标、多屏／Spaces／Retina、系统捕获自排除、原生材质和真正输入法体验仍需对应真实Mac证据。
- 本轮没有新原生CI或真实上传PASS。设计原型检查不能代替这些事实。

## 重建与来源

```sh
python3 prototype/build.py
node prototype/model-regression.test.js
python3 visual/render-boards.py
python3 motion/render-motion.py
```

原型无第三方运行依赖。画板重建使用Python、Inkscape和可用中文字体；影片使用Python、Pillow、ffmpeg／ffprobe。生成使用的Noto字体只作为渲染依赖，未作为App资源重分发；Mac实现使用系统NSFont，不携带SF字体文件。具体哈希分别在`prototype/build-manifest.json`、`visual/outputs/manifest.json`与`motion/verification.json`。
