# Riftlet · 薄界 / Quiet edge

## 这份设计的地位

这是 2026-10-28 独立产品设计专项的**最终推荐主方向**。它以正式工程 `1920e0562db893a3292af89a89270a26ddb46a5f` 为行为基线，继承已经批准的裂缝与预测入口原则，供创始人审阅并指导之后的原生实施。**设计交付不等于用户已批准所有新尺寸，也不等于代码已实现或真实 Mac 已验收。** 本轮不修改正式 App、Core、Web、SQLite、上传准入或 PR #1。

完整固定来源及历史覆盖关系见 [决策来源账本](research/decision-register.md)。源码事实分别见 [原生界面审计](research/native-surface-audit.md) 和 [入口与动效审计](research/entry-motion-audit.md)。下文把已批准的行为与本轮提出的艺术判断分开。

## 1. 最终推荐方向

**让截图像一张暂时夹在桌面边界里的小纸片，而不是放在工具栏上的按钮。** 裂缝只负责遮挡，内容自己提供辨识。辅助窗口使用平静、清楚的原生层级；预测入口以一块细窄玻璃与它相连，不创造第二套视觉语言。

“薄界”描述空间关系，不是新增品牌名称、Logo 或特效。已有网页青绿 `#19B7A4` 和 split-R 图形保留；不改造已选标记，不向照片或截图施加品牌染色。

### 四个有意保留的特征

- **一条直边。** 薄、直、稳定，没有波浪、尖端、开合、光束或粒子。深度来自图片越过同一遮挡平面，而非新增装饰构件。
- **原始图像比例。** 72×56 pt 是拟合包络。横图、竖图和长图维持各自形状；编号辅助空间记忆，不用文件名占据边缘。
- **一块玻璃。** 预测入口闭合为小型单面板，向上连续生长；模式槽静止，取消盖片移动。相机线条与背景各自响应距离，图标始终清楚。
- **安静的结果。** 点击有反应，等待有含义，真实开始后快速消失；最终成功留给原草稿附件表达。Riftlet 不庆祝、不重复提醒。

### 本轮为何继续选择小尺度遮挡

既有 R2 在 54／72／90 pt 中比较过识别度与屏幕占用，72 pt 适合作为继续打磨的中间尺度；它没有因此成为用户批准的固定值。本轮保留 72×56、25% 遮挡和 60 pt 行距，重点改进稳定锚点、长图命中、明暗材质与窗口一致性，而不是靠更大的图、更亮的线或更多阴影制造精致感。

编号与图像可见左缘的间隙为8pt。普通截图没有额外的玻璃卡片底。极端比例图也不裁成统一方块；仅在编号处提供**可见的 22×24 pt 标记命中面**，同时保留图像自身的命中范围。这样，用户看到的可操作区域与实际接收输入的区域一致，透明间隙继续让给桌面。

## 3. 本轮新提出的精确选择

以下均为**本轮推荐**。其中数字不是此前用户原话，也不通过本文件自动进入正式 App。

| 项目 | 推荐 | 依据与代价 |
| --- | --- | --- |
| 微图 | 72×56 pt 等比 fit，右侧25%遮挡，60 pt 行距 | 继续已有可调基线，保留图像各自轮廓；超长图仍依赖编号和完整预览 |
| 裂缝 | 线宽 `1 / backingScaleFactor` pt；2×屏为0.5pt，1×屏为1pt | 空间由遮挡产生，线宽为一个设备像素；旧0.7pt仅为历史基线 |
| 队列首槽 | 固定在预测入口下方，容量不够时使用轻量溢出导航 | 少图变多图不再把首槽推向上方；牺牲少量一屏容量，换取位置记忆 |
| 预测入口 | 闭合36×36 pt，展开36×132 pt，固定32 pt槽距 | 继承已认可单玻璃形态；不四散为独立按钮 |
| 极端比例命中 | 可见22×24 pt编号标记＋真实图像矩形 | 不制造看不见的44×44遮挡区；普通图不强加标记卡片 |
| 完整预览 | 可选悬停450 ms；最大320×240 pt，等比显示；AX自定义动作“查看完整预览”，历史窗口内聚焦条目可用Space | 用于识别极长图或细节，不是单击附加前置；不拦截全局Space或AX按钮默认Space激活；预览不截取当前桌面、不读取新来源 |
| 浅色 | 中性近白与墨色，青绿只承担少量动作／选择语义 | 保留已喜欢的明亮背景；不以所有表面染绿表示品牌 |
| 深色 | 中性偏绿深灰、清楚文字、低强度边缘 | 与浅色共享角色关系，无霓虹、高光圈或发光阴影 |
| 圆角 | 小型玻璃／辅助窗口服从同一有限层级；图片本身保留原比例和内容边缘 | 不机械把所有对象做圆；最终具体值由精确规格和原尺寸视图共同约束 |
| 辅助窗口 | 首次使用与日常状态分层，历史用预览与清楚状态，Feedback保留本地草稿和主动诊断 | 减少工程术语与纵向长表，但不隐藏权限阻断、支持范围或未送达状态 |
| 等待反馈 | 当前项的克制状态与按需解释，不用假进度百分比 | 明确“点击已接受”与“已经开始上传”不同，不制造速度承诺 |

`22×24` 是有形的编号命中区域，不是把当前行包络的44 pt参数改名。透明缝隙仍应穿透；图像 alpha 透明像素是否穿透须另作明确实现选择和实测，不随效果图默认为已解决。

固定槽位是**每次会话按默认模式确定后冻结**，不是所有默认设置永远采用同一排列。只有发生溢出时才在底部预留20pt导航与8pt间隔，不为普通短队列留空的分页控件。

### 三项留给最终视觉审阅的集中判断

1. **空间几何是否成立：** 72×56／25%／60 的日常尺度、入口下方稳定首槽、溢出处理，以及22×24极端比例标记，须在100%逻辑尺寸下整体看。
2. **材质关系是否合适：** 单一薄玻璃、近白／深灰与有限青绿的关系，是否既可见又不抢内容。不是重新选择大量配色候选。
3. **边角处理是否克制：** 图像内容边缘、编号标记、入口与原生辅助窗口的圆角层级是否属于同一产品，而不变成一排圆角控件。

本轮已内部收敛为一个推荐方向，不要求创始人为每个间距逐项决策。以上三项是审阅完整成果的聚焦点，不能被写成已经获得最终批准。

## 4. 本轮明确不替用户决定的事

- **入缝默认模式未定。** 设置保留“无／磁力吸引”，初次展示或演示选择不构成生产默认。可在首用选择，尚未选择时不得声称用户已选择磁力。
- **24小时归档仍是工程默认。** 可以展示现有可调值，但不把它包装成用户最终保留政策；不新增删除期限、限额或源文件清理。
- **品牌资产不重开。** 本轮保留已选青绿 split-R；不替换网站、App 图标或域名内容。
- **真实失败与安全重试不开放。** 目标状态可设计，生产准入另依真实证据；UNKNOWN始终不重传、不清除、不解锁。
- **普通生产、其他适配器和反馈云端不开放。** 设计完成不扩大当前 Chrome 中文普通已有聊天／受限 PNG 的内部候选支持。
- **不加入拖动排序、OCR、云同步、通用图库或自动发消息。** 完整设计指现有产品闭环完整，不是新增功能清单。

## 5. 旧材料的四项公开修正

1. R2／v1 的 READY 后吞噬、可见 UNKNOWN 和空队列留线只保留为历史；本轮不继承。
2. 两模式旧稿中 none 关闭全部运动的范围，按本轮要求缩回“截图入缝”。上传开始后的快吞噬保留独立语义。
3. 预测入口参考中的三图分页与560px画布绝对坐标，不扩大为全设备原生规格。正式布局按当前屏幕与可用区域计算。
4. 已有真实快吞噬的限定 PASS 不变，但本轮原型、影片与图稿均为设计证据，不生成新的真实上传或原生窗口 PASS。
