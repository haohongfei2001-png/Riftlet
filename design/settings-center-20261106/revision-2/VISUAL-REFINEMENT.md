# v2 有限视觉精修与 AppKit 映射

2026-11-06｜仅修订设置设计候选的 CSS，不是正式 AppKit 界面验收。

本轮保留 Quiet Edge 的绿色语义色、六页导航、设置分组、上下文“详细自定义/精细参数”、窗口比例与既有动效。只针对实际原始截图中的文字辨识、选中态对比度、鼠标目标、六位置选择器和说明排版作小范围调整，不删除有效个性化，不新增功能或重做产品架构。

## 1. 依据与交付边界

已逐张查看 v1 `evidence/20261106-browser-02/screenshots/` 的 **P1–P6、D1–D6、C1–C5、C8**，并对照 [原 CSS](../prototype/style.css) 的色值和尺寸。代表画面：[浅色位置页](../evidence/20261106-browser-02/screenshots/P2.png)、[浅色截图页](../evidence/20261106-browser-02/screenshots/P3.png)、[深色位置页](../evidence/20261106-browser-02/screenshots/D2.png)、[控制中心](../evidence/20261106-browser-02/screenshots/C1.png)。

原图显示：桌面行标题多为 12 px、说明为 11 px；控制中心开关说明仅 10 px；六位置按钮实际覆盖为 49×23 px；开关的透明 input 与视觉同为 30×18 px。浅色选中项用 `#087f73` 文字叠在 `#dcebe4` 上，对比度低于同色主按钮的白字组合。视觉层级基本成立，主要问题是这些小字、小目标与个别同一行说明挤压，不需要整体放大或改布局。

本文件与 [v2 CSS](prototype/style.css) 共同定义本轮覆盖。**AppKit 实施时，本文件第 2 节的具体值优先于冻结 v1 [TOKENS.json](../TOKENS.json) 的对应项；未列出的 token 和交互仍沿用 v1 文档。** 不以 CSS 与旧 token 不一致为由让后继重新猜字号、颜色或点击尺寸。所有 CSS px 是网页合成原型的逻辑尺寸；AppKit 采用对应 pt 目标并用真实控件/辅助功能检查，不能将浏览器尺寸直接当作 WindowServer 命中证明。

本作者只写 `revision-2/prototype/style.css`、本文件。state/HTML/文案由另一实施角色负责；已协调其在 `.popover` 内增加一个 `.popover-content` 包装，顺序仍为头部到页脚，并复用 `.domain-save-errors`、`.write-error`、`.button`。本轮不修改 v1、`Sources/`、生产配置或 refs，不运行原 build 脚本。构建、浏览器回归和新截图由集成负责人合并执行。

| 控件 | v1 | v2 实际目标/呈现 |
| --- | --- | --- |
| 普通按钮、下拉、数值输入 | 通常 29 px 高 | **至少 32 px**；文本输入 height 32，其他控件可随内容增高 |
| 六位置选择器 | 2 列×3 行，49×23 px（位置页） | 保留 2×3 的左右/上中下关系；**62×至少32 px**，间距 **6 px**，字号 **12/18**，圆角 6；选择态增加字重/内边，不只靠绿色 |
| 开关 | 可点击与视觉均 30×18 px | **label/input 44×32 px**；视觉轨道仍 **30×18 px**，不把开关画得更重 |

## 3. 高度、滚动与错误约束

设置仍采用 v1 的 960×684 目标窗口和内容滚动区；不为多字或大控件锁短行高。页脚允许错误文本换行，窄预览可把按钮组换到下一行。长 dialog 最多占宿主高度减 48 px，内部纵向滚动；取消/继续编辑等操作仍须键盘到达。

Popover 保留 336 px 目标宽度和箭头外壳，最大高度为宿主可用区域减 54 px；`.popover-content` 是唯一内部滚动层，正常短内容仍按自然高度，滚动只作空间不足的兜底。该层保留圆角并使用 `scroll-padding-block:12px`，焦点目标使用 12 px 滚动边距；外壳不裁箭头。控制中心仍只放最多两行异常摘要和一项聚合“查看未保存的设置”动作，完整按域错误与重试放在通用/相关设置页，不把三张错误卡堆在 Popover 中。三停止域同时失败也不能通过截字、删错或压小字体解决。

这些是原型中可核对的 CSS 约束。原生 NSPopover 应根据实际 `visibleFrame` 定位与限制内容大小，必要时用内部 `NSScrollView`；不将 CSS 的 54 px 直接当作所有菜单栏、Dock、屏幕缩放下的通用常数。真实 AppKit 材质、菜单跟踪、窗口焦点和命中仍须实测。
