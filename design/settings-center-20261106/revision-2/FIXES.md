# X1–X13 闭环

旧版失败记录与原始截图见 [不可改写的 v1 FAILURES](../FAILURES.md)。以下全部由同名原断言重新执行通过；没有删除断言、改预期或减少原用例。

| 项 | 实际修正 | 新增防回归 |
|---|---|---|
| X1/X2/X3 | 收录、可见性、截图入口各有有效值、最后确认值、未确认目标与错误；停止运行和保存失败同时表达 | R1–R4 三错误并存及逐域同向重试 |
| X4/X5/X10 | 权限恢复和无关保存不清错；放弃布局只清该草稿域 | R4–R6 |
| X6 | 独立 retry-save 携带原目标，不从当前开关取反 | R2/R3 真实执行逐域重试 |
| X7 | 五个无效可编辑控件转只读说明，七个兼容字段仍保存原值；所有有效定制域保留 | L1/L2 非默认兼容值应用及恢复后不变 |
| X8 | 清空可见队列不承诺无后端的批量撤销；保留文件、历史与附件 | 原 A3 / X8 |
| X9 | 主屏选择保存选择时具体 ID/UUID，断开仅运行回退 | 原 M1/M2/X9 |
| X11 | sheet key-view 包括 select/textarea，保持完整循环 | K1/K2 |
| X12/X13 | change 不重建输入/点击目标；保存和关闭读取当前草稿；后台刷新不替换编辑节点 | A1/A2 单次 mouse down/up；E1–E7 文本/焦点/选区/组合态 |

额外修正：暂停且隐藏说明不再声称正在收录；减少动态不把合法 40ms/0ms 动画延长成 80ms（E8）。

原生 App 未因此改变。原 A3 的缺失 .desktop-rift 不能证明实际裂缝已消失；组合事件为 DOM 测试，不是系统 IME。测试范围详见 TESTING 和独立审查。
