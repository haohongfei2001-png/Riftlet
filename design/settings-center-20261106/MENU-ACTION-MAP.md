# 现有菜单能力去向

依据 main b61fc46 的 `Sources/RiftletApp/RiftletMain.swift::installMenu()`。本表防止精简菜单时丢失有效能力；只映射UI，不改变底层语义。

| 当前入口/selector | 新入口 | 处理 |
| --- | --- | --- |
| statusLine / updateControlTitles | 控制中心顶部状态；通用页面同源状态 | 移除技术模式长标题，保留真实运行/持久化失败区别 |
| 设置 / showSetup | 控制中心“设置…”；右键菜单；前台⌘, | 单例六页窗口，记住上次页面/窗口尺寸 |
| 使用引导 / showOnboarding | 通用、权限与帮助 | 升级不强制再次展示 |
| 反馈与建议 / showFeedback | 权限与帮助；控制中心辅助入口 | 继续使用既有独立Feedback流程 |
| 入缝动效 / showArrivalSettings | 设置→动效 | 不再是孤立设置窗口；保留无/磁力吸引 |
| 文件访问 / openFilePrivacySettings | 权限与帮助→截图位置 | 故障状态定向到此 |
| 隐藏裂缝 / toggleHidden | 控制中心和通用的独立开关；右键同源命令 | 只隐藏显示，不恢复/暂停收录 |
| 暂停收录 / toggleCollection | 控制中心和通用的独立开关；右键同源命令 | 只控制系统截图收录；沿用当前保存失败语义 |
| 截图 / beginScreenshot | 控制中心主动作；右键菜单 | 沿用内置截图入口的可用性；不打开新上传路径 |
| 截图历史 / showHistory | 控制中心；设置侧栏辅助入口；历史与存储页 | 打开已有历史窗口，保留筛选与恢复限制 |
| 清空可见队列 / clearVisible | 历史与存储→收起当前待用截图 | 说明文件/历史/聊天附件保留后明确确认 |
| 自动归档 / configureArchive | 历史与存储→闲置后归档 | 快捷选项与自定义小时；保留明确保存语义 |
| 显示最新 / showLatest | 控制中心辅助命令/右键菜单 | 仅定位已有可见页；不重新附加 |
| 显示最早 / showOldest | 控制中心辅助命令/右键菜单 | 保留原能力，不与最新混淆，不作为首页常驻参数 |
| 重新检查来源与权限 / recheckSetup | 权限与帮助；实际故障定向动作 | 只检查，不自动上传或重放旧操作 |
| 检查本机存储 / checkStorage | 历史与存储→检查用量 | 未检查/检查中/成功/失败分别显示，不能伪造0B |
| 私有存储状态行 / storageLine | 历史与存储内辅助结果 | 不常驻菜单栏 |
| 重新载入几何 / reload | 权限与帮助→主动展开的精细工具 | 仍走现有验证与应用路径，不通过重置修复 |
| 打开工程几何文件 / openGeometry | 同上，或深层参数说明中的“查看配置文件” | 保留专家可达性；不放在主设置页 |
| 退出 / quit | 控制中心底部；右键菜单；前台⌘Q | 退出不删除队列、文件或既有附件 |
| Add generated/synthetic images | 只在原隔离模拟/验收模式的开发入口 | 不暴露为普通消费者功能，不向真实队列添加测试图 |
| 打开离线合成演示 / launchSimulation | 帮助下主动选择的演示（开发能力保持隔离） | 首用可使用合成说明；不制造业务成功记录 |
| 打开真实截图内部候选 / launchSystemScreenshotCandidate | 开发/验收工具，保持既有模式边界 | 不放入普通设置，不借设计开启内部候选或重复安装 |
| Web acceptance / system candidate技术范围行 | 仅其模式下的开发详情 | 原始事实不删；不把内部测试词当普通用户状态 |

## 同一命令源

`NSMenu`、Popover和设置窗口发送同一host命令，显示同一带revision的快照。不能为方便界面演示增加另一套 `capturePaused` / `userHidden` 持久化，也不能把已保存意图当成当前运行状态。瞬时刷新不可重建正在编辑的文本控件或重置焦点。

## 原型边界

HTML只演示上述入口及合成操作结果。Finder、系统权限、内置截图、Feedback发送、原生配置文件与真实历史都由说明对话或合成样本替代，不伪造外部行为已发生。未实施的原生命令应在工程交接中继续有清晰去向。
