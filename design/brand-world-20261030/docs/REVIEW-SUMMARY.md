# Riftlet｜品牌候选评审摘要

日期：2026-10-30。推荐：**Passage / 隙入**。状态：可查看、可交互、可编辑的独立候选，待品牌方决定；没有正式替换 Logo 或上线官网。

先看 [完整评审页](../site/review.html)、[中文官网](../site/zh/index.html)、[英文官网](../site/index.html)与[三方向比较图](../brand/directions-board.png)。完整文件索引见[DELIVERY](DELIVERY.md)。

## 1. 这次设计解决什么

Riftlet 值得独立存在的理由，是减少截图成为对话上下文时的搬运：刚截下的图在可预测的屏幕边缘等候，用户选中它，再交给当前受支持的草稿。品牌应让人记住这个轻巧而有控制权的动作。[产品事实](product-truth.md)将它与截图编辑器、文件架、剪贴板管理和自动 AI 问答区分；不将相关既有能力包装成首创。

原官网已有可保留的暖纸/青绿克制感、衬线标题和可操作示例。主要变化是把叙事集中到同一个交接机制，让 Logo、页面空间与动作共用一个理由；同时修正旧演示“最终 READY 后才吞噬”的契约差异。旧页面仍在[对照入口](../baseline/index.html)，审查依据见[现状审查](current-site-audit.md)。

## 2. 三个方向的真实取舍

| 方向 | 成立之处 | 代价与风险 | 结论 |
| --- | --- | --- | --- |
| [A · Split R](../brand/direction-a.svg) | 名称联想最直接；青绿沿袭自然；紧凑轮廓适于图标 | 仍容易落入科技首字母标，空间机制需要额外说明 | 保留为可信对照，不与主方案并列推荐 |
| [B · Passage](../brand/mark.svg) | 内容形体与固定薄界的关系来自实际交互，可发展成标识、构图和动作 | 需要与字标/演示一起建立含义；早期轮廓有喇叭、旗帜和刀刃联想 | 推荐并完成矢量与小尺寸精修 |
| [C · Inflection](../brand/direction-c.svg) | 折转空间有艺术性，材质与立体方向可展开 | 折页/灯具联想更强，水平折转离真实竖直薄界较远；小尺寸意义易丢失 | 淘汰作为 Riftlet 主标识，保留探索证据 |

不是要求孤立 Logo 讲完“Mac 截图进入 ChatGPT”的全部故事。B 的优势是形态可以与真实动作连续使用；它的名称识别仍依靠稳定字标和长期使用。独立比较见[Logo 审查](independent-logo-review.md)，生成概念与最终矢量是不同阶段，后者是交付母版。

## 3. 已落到成品的设计决定

**标志。** 保留两个独立路径：不对称的内容平面与稳定边界。将早期过深凹口收浅，延长左侧、压平下缘以减弱喇叭感，圆化边界端部以去掉刀刃感。16/32px 使用更强边界和更开阔缝隙的专用轮廓。七档尺寸与单色版本已实际导出并图像检查，见[尺度板](../brand/scale-check.png)及[资产说明](../brand/README.md)。

**系统。** 保留有识别潜力的薄荷青绿，配深森林色、暖纸和少量砂色；网站使用平面色与空白，App Icon 容器才带轻微深度。字标使用有许可的轮廓文件；正文使用本机字体栈。没有竞品素材再分发、远程字体依赖或为“AI 感”添加的紫蓝光晕。规则见[视觉规范](brand-guidelines.md)。

**文案与页面。** 中文“把眼前的，带进对话。”和英文“Show what you mean.”分别按自然语言组织，用副标题立即补全 Mac、边缘、受支持草稿与发送控制权。完整网站把产品承诺、交互、轻量配套与真实状态串联；主要 CTA 引导亲手体验，未提供虚假的下载入口。[中英文文案](brand-strategy-and-copy.md)含可公开介绍稿，并明确限定测试和未公开发布。

**交互。** 同一演示覆盖点击、模拟开始信号、快速离场、稍后就绪、明确失败与开始后未知。用户文字与原有附件保留，网页不发送。主演示“无”入场默认不替原生做决定。磁力入场是说明性实现，不包装成已经验收的原生运动轨迹。

## 4. 质检发现了什么，怎样处理

| 发现 | 已落地的处理 | 仍需保留的限制 |
| --- | --- | --- |
| 概念轮廓有喇叭/刀刃联想；极细缝隙小尺寸会闭合 | 修改几何、分离光学小尺寸、实际导出单色及七档 PNG | 抽象形状的多义性仍存在；没有用户识别实验或正式商标清查 |
| 中文指引断成孤字、尺度说明相互矛盾、状态字过小 | 生成页面改为“点一下小图”“桌面局部 · 机制演示”，修订状态/说明样式 | 早期截图保留为审查证据，最终观感以当前页面和最新捕获为准 |
| 原队列固定位置不补位；退出横向缩放会扭曲图像 | 根据可见项补位；离场只平移与淡出，保持截图比例 | 网页是放大的机制示意，不是原生录屏 |
| 开始后未知与最终完成可能混淆 | 未知保持隐藏并记在历史，显示“待核实”，禁止盲目重派 | 失败恢复仍是条件模拟，原生准入未开放 |
| 部分说明对比度不足；hidden 可能被 flex 规则覆盖 | 修正四组被定位的文字色；增加全局 hidden 规则 | 计算的四组色值不是全站对比度或无障碍认证 |
| 键盘聚焦可带动截图容器，禁用源图可能失去焦点 | 使用 overflow:clip；在禁用/隐藏前记录焦点，按条件接续历史按钮 | 源码意图须与实际浏览器行为核对，不能据此声称完整 VoiceOver PASS |
| 页面退出与 BFCache 的模型生命周期 | pagehide 清理，恢复时重新建模；隐私改为不上传/不主动持久存储 | 不保证浏览器自身缓存或表单恢复绝不保留内容 |

详细依据分别来自[官网视觉审查](independent-website-review.md)、[契约审查](site-contract-review.md)和[源码报告](qa-source-report.md)。记录版本的确定性引擎测试为 **10/10 通过**，严格资源与语义检查通过；这只是已执行范围的结论，不能换算成真实客户端或全平台浏览器验收。

## 5. 这套候选最强的部分与剩余不足

最强的部分是统一性：标志的关系、网站的空间和模拟中的离场使用同一种边界逻辑，截图仍保留原比例，用户继续掌握目的地与最终发送。相对品质参考，吸收的是叙事节奏、真实产品解释和用色纪律；相对同类工具，强调具体交接体验而不是夸大独有功能。证据与对比见[官方参考研究](brand-references.md)。

剩余不足也明确：抽象标识尚需通过实际使用建立联想；系统字体在不同平台会有差别；没有正式商标检索、真实 Dock/Finder/菜单栏集成、全浏览器和屏幕阅读器证明。OG 与 SEO 尚需按真实部署域名整合，候选保持 noindex。最重要的是，品牌与模拟完成度不能提高原生附件准入等级：普通启动仍以截图收录为主，真实附件仅有指定条件证据，自然物理首击等门槛继续由正式原生工作负责。

## 6. 本轮需要的决定

建议品牌方决定是否采用 Passage 的**主标识关系、青绿/暖纸体系与核心叙事**，再进入最小整合。无需把已淘汰方向也打磨为第二套正式品牌。网站整合、原生资源接入、合并和上线按[采用步骤](adoption-and-scope.md)分别执行。
