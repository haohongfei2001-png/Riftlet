# 官方站点的实际视觉观察

2026-10-30。与 `brand-references.md` 的产品与文案来源配套。以下由主执行者实际打开官方网站并观察渲染后记录；不复制或分发第三方截图、字体、Logo 和产品素材。

| 官网 | 实景机制 | 对 Riftlet 的设计取舍 |
| --- | --- | --- |
| [mymind](https://mymind.com/) | 温暖底色、极大衬线文字、少量彩色对象，先让人理解记忆与整理的情绪结果 | 学习先说结果；Riftlet 的下一步必须接真实机制，不借用其标志或视觉对象 |
| [Claude](https://claude.com/) | 纸色、衬线排版和人的工作画面，让技术服务于具体意图 | 用自然语言说明控制权；不借 AI 助手身份为 Riftlet 增加不存在的理解或推理能力 |
| [Craft](https://www.craft.do/) | 有性格的字标、纸张和拼贴氛围，产品画面与内容创作相互支撑 | 可以温暖而有编辑感，但 Riftlet 不应变成文档工作台或图库 |
| [Linear](https://linear.app/) | 深色、大规模真实 UI 和精密层级，产品的秩序承担品牌表达 | 学习精确状态与一致性；不复制企业级密集控制台，微小边缘交互才是主体 |
| [Raycast](https://www.raycast.com/) | 深色基底、中心承诺、红色斜向符号，动作与 macOS 工具气质统一 | 学习明确的动作语言，不借其红色斜切图形及扩展生态承诺 |
| [CleanShot X](https://cleanshot.com/) | 白蓝框架、清楚的截图品类、实用功能视频、商业证明 | Riftlet 不争“全功能截图编辑器”；没有真实用户证据就不放评价或用户数量 |
| [Shottr](https://shottr.cc/) | 橙色识别与直接的工具说明，专业功能表述克制 | 解释刚需、减少营销套话；不将网站做成功能清单 |
| [Xnapper](https://xnapper.com/) | 深蓝基底、紫青强调、直接展示截图美化结果 | 学习可见的结果差异；Riftlet 不加工美化用户截图，也不仿照其渐变体系 |
| [Dropover](https://dropoverapp.com/) | 黑色基底、简洁标题、临时文件架与直接操作示范 | 研究边缘/暂存机制的既有能力；不能把这些泛化能力宣传为 Riftlet 首创 |
| [Screen Studio](https://screen.studio/) | 深色与紫色识别，实际录屏和录制结果支撑品质感 | 将来以真实 App 录屏增强可信度；本轮合成图只承担已标明的机制说明 |

部分网站的首次进入动画会短暂留白，后续截图已读取稳定画面；未把动画中间态当成网站缺陷。此观察不构成跨页面穷举或用户研究。

## 竞争表达的关键边界

[AI Screenshot 的官方 Chrome 商店条目](https://chromewebstore.google.com/detail/ai-screenshot/jchfdipnibgapeiojhnncgncpgnaccif) 已描述将截图附加到既有 ChatGPT / Claude 会话而不发送。Dropover 已具备边缘停靠、监视文件夹等相关机制。因而 Riftlet 的候选叙事不声称发明“截图进 AI”或“边缘暂存”。

机会在于把熟悉的 macOS 截图习惯、稳定的边缘位置、局部露出的原比例微图、明确点击、草稿保护和诚实的异常状态做成一件连贯的小工具。这是体验质量的竞争，不是独占功能的声明。

## 图形相似性初审

主执行者已将三种方向与本表品牌的实际符号、字标及 App Icon 表达方式作视觉比较。最终两路径构造未直接借用所审品牌的标志；也主动排除了相机、聊天气泡、AI 星形、叠矩形等通用模板。Passage 仍可能被部分观察者读成扬声器或其他空间符号，已通过不对称底边、较长左边与钝化薄界降低这一倾向。

这只是在所审样本内的初步设计比较，不是全球图形数据库穷举、商标可注册性意见或法律清查。正式采纳前仍应针对最终图形做目标市场的商标检索；识别与记忆效果也需要真实用户的小样本验证。
