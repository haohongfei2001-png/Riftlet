# Riftlet「隙入 / Passage」品牌视觉规范

版本：2026-10-30 设计候选。本文规定候选的使用方法，不代表创始人已批准正式品牌、原生 App 已切换图标或官网已上线。

## 一、品牌核心

Riftlet 的中心体验是把眼前的视觉内容带进正在进行的对话。符号由一个内容平面与一条固定边界组成；官网以真实的选择与交接动作解释这两个形状之间的关系。

主文案：**把眼前的，带进对话。** 英文：**Show what you mean.**

图形表达的是“通过与遮挡”，并不承诺用户单看图标就能猜出截图软件或 ChatGPT。分类与支持范围由邻近的准确文案承担。不得把普遍存在的截图附加、边缘停靠或不自动发送，宣称为 Riftlet 首创。

## 二、主色与背景体系

### 品牌色

| 名称 | 精确色值 | 主要用途 |
|---|---|---|
| 深林绿 / Forest ink | `#123E38` | 主标志、深色品牌区、重点行动 |
| 青绿 / Mint | `#46D1B1` | 品牌强调、主 App Icon 容器 |
| 暖纸白 / Warm paper | `#F4F1E8` | 浅色背景、深底反白标志 |
| 暖沙色 / Sand | `#D7A482` | 少量辅助色、图像中的温度 |

保留青绿，是为了延续此前已有认知，同时用深林绿与暖纸白让它更安静、可信。暖沙色用于形成温度，不承担正常正文或核心状态辨识。

### 当前候选网页色板

这些是页面表面与文字层级的实际 token，不能误当成另一套 Logo 配色。

| 用途 | 浅色 | 深色 |
|---|---|---|
| 页面背景 | `#F4F1E8` | `#132E29` |
| 抬高表面 | `#FBFAF6` | `#1D3C35` |
| 正文 | `#163C35` | `#EDF2E9` |
| 次级文字 | `#5E6D63` | `#B4C3B6` |
| 分隔线 | `#D3D9CE` | `#38564B` |
| 柔和底色 | `#E5EAE0` | `#25473D` |

深色模式不是把网页机械反相。真实截图保持自己的颜色，不能被全局色相滤镜污染。图标可换反白主件，页面插图和产品截图需单独检查。

## 三、标志结构与编辑边界

主源文件：`brand/mark.svg`，256×256 设计坐标。

| SVG 层 | 含义 | 编辑规则 |
|---|---|---|
| `content-plane` | 接近边界的内容平面 | 保留轻斜上缘、较长直左缘、浅凹右缘和更平的下缘 |
| `screen-edge` | 固定屏幕边界的抽象 | 垂直、稳定、顶部和底部钝化，不改成刀刃、叶片或光束 |

第二轮矢量精修针对真实缩小后的扬声器歧义，拉长了左缘、收平了下缘。生成概念图中的柔性大凹面与尖端没有被机械保留。**可编辑 SVG 为后续制作基准，生成图仅记录探索。**

两部分必须保持既定位置关系，不各自旋转、不随容器拉伸，不把内容平面单独当品牌主标。不得添加相机、聊天气泡、星形、粒子或另一层象征物来“解释”符号。

### 单色、浅底与深底

- 浅色背景使用 `mark.svg`；深底使用 `mark-light.svg`。
- 印刷、模板与特定系统用途使用 `mark-mono.svg`。
- 需要任意颜色时改变两个路径的 fill，不能同时改变几何或透明度关系。
- 全透明底的标志与带容器的 App Icon 是不同资产，不应互相替代。

## 四、净空、尺度与光学小尺寸

定义 **X = 正常主标右边界最大宽度，约 19 个设计单位**。可见符号外至少保留 1X 净空；大版面优先 2X。主标 SVG 的画布已含安全留白，不应通过负 margin 把形状紧贴其他文字。

主标在常规尺寸下使用正常 master；**16 和 32 像素使用独立的 `mark-small.svg` 光学 master**。小版加强边界并扩大开口，不是将大图无差别缩小。

| 尺度 | 资产与检查重点 |
|---|---|
| 16px | 光学小版；读出两个组成部分与开放缝隙，不依靠细凹面辨认 |
| 32px | 光学小版；边界必须独立，不与主体粘连 |
| 64 / 128px | 正常版；无需阴影也应成立 |
| 256 / 512 / 1024px | 正常版；检查曲率、边界和中心感，不能用材质遮盖轮廓问题 |

`brand/scale-check.png` 与 `brand/scale-512.png` 记录实际导出的渲染检查。图标必须按原比例显示；不使用 CSS 强制不同宽高拉伸。最小尺寸的精细曲线不可被当成信息载体。

### 菜单栏

使用 `menu-bar.svg` 或对应黑白 PNG。它们为纯单色、透明背景，**不能带青绿 tile、圆角底板、渐变、阴影或永久品牌色**。原生工程正式采用时，需要设置适当的 template 行为并在明暗菜单栏真实检查；本专项没有操作真实 Mac。

## 五、App Icon

主方案：青绿底、深林绿符号。备选深色资产：深林绿底、暖纸白符号。

- 主画布：1024×1024。
- 容器：起点 72、72，宽高 880，圆角半径 196。
- 外侧留白透明，不能补成不透明方形背景。
- 容器渐变为 `#71E2C8` → `#46D1B1` → `#23B598`，只是轻微材质层次。
- 细边缘使用克制明暗变化，不增加光晕或强立体贴纸感。
- 标志几何与网站主标一致；16／32 输出切换到光学小版。

完整交付包括 PNG 七尺度、`AppIcon.iconset/` 与 `app-icon.icns`。ICNS/ICO 已做文件格式读取检查，**尚未做真实 Finder、Dock 与菜单栏渲染验证**。这是正式采用阶段的必要检查，不能在设计报告里虚报通过。

## 六、字标、字体与许可

### 固定品牌资产

`wordmark.svg` 使用 DejaVu Sans 轮廓，已经转为七个独立可编辑的字形路径，并调整整体字距。配套有明暗版本与横向 `lockup.svg`。固定资产无字体下载和运行时字体依赖。

DejaVu 的许可说明附在 `brand/FONT-LICENSE.txt`。没有捆绑字体二进制，也没有用竞品字体。生成概念图中的文字不作为字体源，不应据其外观推断字体许可。

### 网站英文与中文

标题使用本机可用的衬线字体形成阅读温度；正文与交互使用系统无衬线字体保证熟悉性。当前候选实际栈：

- 标题：`Iowan Old Style`、`Baskerville`、`Noto Serif CJK SC`、`Songti SC`、`Georgia`、`serif`。
- 正文：`-apple-system`、`BlinkMacSystemFont`、`Segoe UI`、`PingFang SC`、`Noto Sans CJK SC`、`sans-serif`。

英文页面另由 `html[lang=en]` 使用独立的 Latin-first 衬线／无衬线回退，避免英文字母和弯引号优先落入 CJK 字体而产生过宽间隔；中文保留上述系统字体栈。

只引用设备已有字体，不分发 Apple 字体。不同平台的换行与字面会变化，因此中文和英文都要按实际渲染审查。导航中的实时文字遵循页面字体栈；固定对外品牌图稿使用转曲字标，以保留一致轮廓。

标题不能依赖过细字重或超宽字距制造精致感。中文避免孤字落行，按钮和紧邻图标的引导短语优先完整成行。普通正文优先 16–18px；关键模拟性质、状态和可操作说明不宜低于 12px。

## 七、空间、内容与图像

品牌画面可以具有一条稳定竖向边界、局部遮挡和受控留白。实际内容是主角，不加不相关发光物、紫蓝渐变球或科幻黑洞。

演示使用合成示例素材，不引入私人截图、真实聊天、账号、密钥或个人资料。图像可以有暖色与丰富细节，容器和状态保持安静。优先解释一个完整任务，不堆满模拟图像卡片。

### 原生尺寸与艺术放大的区别

精确来源：正式工程 `98e66a956d55b5fac71718bc627dd89705b2a506` 的 [RiftConfiguration.swift](https://github.com/haohongfei2001-png/Riftlet/blob/98e66a956d55b5fac71718bc627dd89705b2a506/Sources/RiftletUI/RiftConfiguration.swift)。

| 原生工程起点 | 数值 |
|---|---|
| 完整微图适配框 | 72×56pt |
| 隐藏比例 | 25% |
| 行距 | 60pt |
| 边界线 | 0.5pt |
| 外侧参数 | 14pt |
| 最小命中区域 | 44×44pt |

这些是工程参数，不是营销性能数字；微图保持原始比例，并不强制裁成 72×56 图片。网页可以解释性放大、组合与裁切，但应标注“机制演示”或“放大细节”，不能把放大后的控件称为原生真实尺寸。没有待用图时，原生边界消失；品牌 Logo 中的边界可以始终存在，两者含义不同。

## 八、动效与状态

品牌动效：边界固定，内容接近并被遮挡。导航标志不持续循环，不做有节奏的呼吸或旋转；它不应该暗示持续监听屏幕。Reduced motion 使用静态结果或轻微淡化。

产品演示必须维持因果顺序：点击 → 等待正向开始信号 → 快速退出可见队列 → 后续附件就绪。**点击本身不等于开始；消失也不等于最终上传成功。**

原生参考时长：快速吞噬 0.120s、补位 0.160s、reduced motion 0.080s。这些是界面动画参数，不能写成上传速度。网页可为了讲解使用不同节奏，但应明确属于模拟。

两个入场选项仅为“无”和“磁力吸引”。它们不改变开始信号后的快速吞噬规则。

不确定状态不能显示确定成功，不自动重传；安全失败恢复属于当前尚未开放的真实准入范围，网页若演示它必须标注条件性目标行为。页面不得自动发送模拟消息或展示自动产生的 AI 回复，让访客误解真实产品能力。

## 九、采用边界与最小步骤

此候选保持设计与正式工程隔离。正式采用至少包括：创始人确认方向；在独立网站变更中引用本套资产；原生集成负责人更新图标并检查真实 Dock/菜单栏；按真实发行状态调整 CTA 与兼容说明；确认后再合并与发布。

初步视觉比较不能替代商标清查。当前可以说“独立开发的候选”，不应说“全球唯一”“已验证无商标冲突”或“已达到顶级品牌标准”。设计质量由实际可见成果与使用体验判断。
