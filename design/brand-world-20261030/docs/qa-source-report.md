## 演示契约与初始状态

初始模型只有一张待用样例：`shot-1`，状态为 `available`，可见。新附加列表为空，操作阶段为 `idle`。虚拟时间前进 20 秒后状态仍保持不变，没有凭计时自动生成 `positive_start` 或 `ready`。

页面草稿还展示一枚**明确标为“原有附件 / Existing attachment”的合成附件**。它用于让用户观察追加新图时原附件是否保留，不代表本次演示已经上传成功。它与模型中新附加列表分开管理。

“亲手试一试 / Try the interaction”重置样例并把操作引导到缩略图，不自动执行附加。“体验这个情境 / Run this scenario”由用户显式触发所选本地条件模拟。所有图片都是候选提供的合成 SVG，页面明确写明本地模拟、无屏幕读取、无 ChatGPT 连接。

### 正常模拟的事件顺序

| 相对时间 | 事件/状态 | 源缩略图 | 草稿中新附件 |
| --- | --- | --- | --- |
| 0ms | 点击，checking | 保留可见 | 无 |
| 650ms | 模拟 positive_start | 开始离场 | uploading |
| 650–770ms | 120ms swallow | 向边界平移 | uploading |
| 770ms | swallowed | 隐藏 | uploading |
| 1770ms | ready | 保持隐藏 | ready |

这些数值是网页模拟时序，**不是实测性能或原生上传速度承诺**。核心区别得到明确验证：取得开始信号后即可离场，最终 READY 在其后发生。

### 失败与未知

- **明确失败后**：恢复同一个源项，移除该次失败演示附件；再次派发需要新的明确点击。页面已说明这是一种条件模拟，原生安全失败恢复准入仍关闭。
- **开始后未知**：源项保持隐藏；模型及历史显示 `unknown`，附件也保持未知，不标为 ready，不再次派发。步骤文案是“待核实 / Awaiting confirmation”。
- **开始前未知**：控制器支持保留源图但锁住盲目重试；这是模型覆盖范围，主页面没有把它作为额外默认入口。
- **没有开始信号**：源图保留，未创建附件，不产生吞噬事件。

检查未发现把“不确定”“点击”“开始”直接显示为最终成功的路径。最终 ready 只能来自明确选择的成功模拟，或控制器显式的模拟核对方法；网站没有将后者接成自动重试。

## 十项引擎测试

1. 初始一张待用样例，没有新附件和自动成功。
2. 正向开始先于120ms吞噬，吞噬先于最终就绪。
3. 重复点击与并行第二项不能重复派发。
4. 明确失败恢复同一源项，不能自动重试。
5. 开始后未知保持隐藏、不假成功、不重派。
6. 开始前未知保留可见，但禁止盲目重试。
7. 无正向开始时不隐藏源图、不制造附件。
8. 重置通过世代号隔离迟到回调；即使注入的计时器取消无效也不能污染新状态。
9. 样例最多三个，身份稳定；模型根本不持有草稿文字。
10. 返回的快照与内部状态隔离；dispose 后迟到任务不再改变状态。

此前 composer 底部与带透明度的范围说明低于4.5:1的问题已经修正。最终范围说明不再因 opacity 降低对比度。

最后冻结的样式还包含851–1100px范围的来源示例尺寸与位置规则、深色引言强调使用 jade、英文页面优先使用拉丁字体栈，以及指定标题片段保持同行。深色 jade `#46d1b1` 在对应基础背景 `#132e29` 上的数学对比度约为7.59:1。这里确认源码与导出一致，不推定实际浏览器不存在遮挡或字体问题。

### 浏览器生命周期

`pagehide` 清理脚本计时任务、恢复示例草稿默认值并销毁当前模型。`pageshow` 在 `event.persisted` 时创建新的模型，清空渲染差分状态并重新呈现初始快照。因此源码已具备 BFCache 恢复路径，避免恢复页面继续绑定到一个已 dispose 的模型。

这属于源码路径审查，**本报告没有实际触发浏览器 Back/BFCache**。隐私文案已采用“不上传、不主动写入持久存储”的表述，没有把浏览器自己的缓存行为包装成已验证的擦除保证。

### 减少动态效果与队列补位

OS reduced-motion 规则关闭动画与过渡；网页 QA 的 `motion=reduced` 标记同时覆盖根滚动器的 smooth 行为。`scrollDemo()` 对减少动态效果路径显式使用 `auto`。

源缩略图使用保比例素材尺寸，退出规则仅做平移和透明度变化。剩余可见项在当前项隐藏后重算位置，未知项保持隐藏，不凭补位复活。页面通过复用节点维持动画起始状态。

### Hidden 语义与键盘边界

全局 `[hidden]{display:none!important}` 已加入，保证提示、历史及缩略图的 hidden 属性不会被组件的 flex 等 display 规则重新显示。静态检查对这一跨组件不变量进行了定向检查，避免只检查缩略图自身的隐藏规则。

截图轨道已使用 `overflow:clip`，不再把裁切容器作为可程序化滚动的 scroll container。源码意图是避免聚焦部分遮挡缩略图时容器自动滚动、把边界向内带动；实际几何与滚动位置应由浏览器记录确认。

渲染逻辑在设置 disabled/hidden 之前记录“当前焦点仍在即将禁用或隐藏的源图”，并提供 `preventScroll` 的历史按钮接续；情境测试按钮在忙碌时被禁用也有接续。条件覆盖 checking 刚开始时的禁用，而不只等待770ms后的隐藏。焦点已经移往草稿时不强行抢回。源码条件的存在不能替代完整键盘路径验收。
