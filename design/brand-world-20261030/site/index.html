      A few things
      worth knowing.

      Can I download it now?

      There is no public, notarised release yet. Internal ARM and Intel builds exist, but they are not a general-use release. Follow the project for an installation guide when public testing is ready.

      Which conversations are supported?

      The admitted test path currently covers specific ordinary, existing conversations on the Chinese ChatGPT website in Chrome, with constrained PNG inputs. Other browsers, the ChatGPT Mac app, new-chat Home and Work are not claimed as supported.

      Does it send messages for me?

      No. The product contract is attachment to a draft, never automatic message sending. The website demo only updates local sample content; its send indicator is deliberately inactive.

      Where do my screenshots go?

      The native queue and history are local. Using an attachment intentionally passes the selected image to the supported ChatGPT draft. Optional feedback uses a separate service. This is not a claim that the complete app works offline.

      What does this website access?

      Nothing on your screen, clipboard or ChatGPT account. The demo uses original synthetic artwork. Typed demo text and attachment states are handled in this page’s memory. This page does not upload them or write them to persistent storage. No analytics, account or submission form is included.

      Is Riftlet affiliated with OpenAI?

      Riftlet is an independent product. ChatGPT is a third-party service; no endorsement, official partnership or universal compatibility is implied.
