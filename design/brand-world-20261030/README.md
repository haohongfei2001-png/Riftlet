# Riftlet｜品牌与官网独立候选

**推荐方向：Passage / 隙入。** 一片内容，一道固定薄界，一个由用户决定的动作。这里交付可编辑品牌资产、三个方向的实际视觉、中英文完整静态官网、可操作的本地机制演示，以及产品事实、研究和验证材料。

日期：2026-10-30。**本候选尚未被正式采纳，不替换生产官网或原生 App，不代表公开发行。** “隙入”是这套设计的方向名称，产品仍名为 Riftlet。

## 建议评审顺序

1. 打开[品牌评审页](site/review.html)，比较三个方向，再看[设计决定摘要](docs/REVIEW-SUMMARY.md)。
2. 在[中文](site/zh/index.html)或[英文](site/index.html)网站编辑示例草稿，点击边缘小图；再选择明确失败、开始后不确定、没有开始信号等情境。
3. 查看[尺度板](brand/scale-check.png)与[完整视觉规范](docs/brand-guidelines.md)，确认静态标识、App Icon、菜单栏与网页属于同一体系。
4. 结合[当前产品事实](docs/product-truth.md)和[采用步骤](docs/adoption-and-scope.md)决定是否进入正式整合。

## 源码与最小重建

网站源文件包括 [brand.css](site/brand.css)、[website.js](site/website.js) 和 [demo-engine.js](site/demo-engine.js)。两份语言页面由 [build-site.py](tools/build-site.py)生成；评审页由 [build-review.py](tools/build-review.py)生成；单文件由 [export-portable.py](tools/export-portable.py)导出。改动生成内容时，应同时维护对应生成器，并重新导出单文件。

已有网站可直接打开。只有重新生成设计资产时才需要构建依赖：Node.js、`sharp`，以及 Python 3、`fontTools` 与许可允许的 DejaVu Sans 源字体。字标导出脚本为 [build-wordmark.py](tools/build-wordmark.py)；默认字体位置及 `RIFTLET_WORDMARK_FONT` 说明见[资产说明](brand/README.md)。

在本目录运行：

```sh
node tools/build-brand.cjs
python3 tools/build-site.py
python3 tools/build-review.py
python3 tools/export-portable.py
```

如果 `sharp` 安装在运行时专用模块目录，可在第一条命令前设置 `NODE_PATH` 指向该目录。单文件导出器只用 Python 标准库，没有额外依赖。上述脚本不会下载字体或竞品素材；原始概念探索图、浏览器截图与已经导出的 OG PNG 随交付保留，不是这些命令每次重绘的产物。

验证命令：

```sh
node tests/demo-engine.test.cjs
python3 tests/site-static.py --strict-assets --json
```

[十项状态测试](tests/demo-engine.test.cjs)和[静态检查](tests/site-static.py)验证网页实现；不验证真实 ChatGPT、原生客户端、VoiceOver 或所有浏览器。已记录的结果与准确边界见[源码报告](docs/qa-source-report.md)。[site/qa.html](site/qa.html)仅供候选检查，不是生产页面。
