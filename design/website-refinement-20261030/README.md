# Riftlet｜保留原站的双候选精修

2026-10-30。设计候选，不是官网上线或原生产品发行。PR #19 的 Passage 方向不采用；split-R 图标、现有短标题、近白/青绿/杏色角色保留。

## 打开方式

下载本目录，保持相对目录不变，浏览器打开 `A.html` 或 `B.html`。两份入口共用相同 HTML 和交互源；B 由文件名或 `?variant=b` 选择。英文可切换，也可添加 `?lang=en`（B 使用 `?variant=b&lang=en`）。`baseline/index.html` 是指定 main 的只读对照，不是新的产品契约。GitHub 文件页默认显示源码，不是公共预览。

对话附件另有两个单文件网页、完整离线评审入口、源码和原尺寸截图 ZIP。仓库的 `previews/compare-desktop-thumb.webp` 只供构图概览，不用于判断细字；完整 1440×1000、390×844 和全页 PNG 在交付包中。

## 设计取舍

A 推荐作为精修主线：保留当前 main 的桌面、源图片与草稿构图；精修比例、点击目标、响应式与文字层级。用不同的后续章节解释比例、临时边缘和发送控制，不再重复一套完整演示。

B 保留为艺术方向候选：同一品牌、标题和交互，把原有空间边缘语言放大，增强遮挡与位置记忆。它不是实际原生界面的尺寸。第二轮已收紧空白，修正图片比例和首屏文案；不能据此宣称 B 整体优于 A 或原站。

A 的提升主要在叙事完整性、交互正确性和细节，首屏视觉属于克制迭代，不是质量跨级。没有品牌认知或转化率实验，不把自评或通过测试等同于世界级设计。正式采用仍需用户裁决。

## 行为

只有显式的合成 positive-start 事件使微图退出；最终 ready 稍后独立发生。明确失败恢复可点图；开始后 unknown 在历史中保留且禁止重派；没有开始不消失。已输入文字、原有附件和用户移除意图保留。支持有限引导、键盘、队列位置保护、深色桌面示意及减少动态。所有图片与事件均为本地模拟，无真实截图、剪贴板、ChatGPT、上传或消息发送。

## 证据与边界

15/15 模型检查；A、B 各 38/38 浏览器检查（共 76）；四组模块化/单文件输出像素一致性检查；两组常规动态吞噬检查。环境为 Linux Chromium 144.0.7559.96、DPR 1。矩阵为 320/390/768/1024/1440/1920 CSS px、中英文。没有横向溢出或 JS 错误。两次整套任务因执行时限中止，之后按 A/B 分开完成，不宣称首次全量运行通过。

浏览器环境禁止本地 URL 导航，因此使用隔离 in-memory document、内联全部资源并阻断网络渲染；未修改浏览器策略。原站/A/B 使用同一环境与视口。不是线上 CDN、Safari、iPhone、真实 Mac 或 VoiceOver 验收。未承诺全站 WCAG 认证、全浏览器兼容、公开下载或生产附加支持。

## 复现检查

模型测试：`node tests/model.test.cjs`。完整浏览器测试：先安装 Python 的 `beautifulsoup4`、`playwright`、`pillow`（按本机策略准备 Chromium），运行 `python tests/export-portable.py`，然后分别运行 `VARIANT=A python tests/browser.py`、`VARIANT=B python tests/browser.py`。测试脚本当前使用 `/usr/bin/chromium`；其他环境需改为实际安装位置。`tests/portable.py` 的像素比较还需要交付 ZIP 内对应的参考 PNG。完整测试记录和全尺寸 PNG 在对话交付包，仓库提交保留摘要与可复现脚本。
