## 最重要的设计决定

1. **能力诚实先于首用精简。** 普通仅收录模式不承诺点击附加；Q01 可先在原三页结构内完成。Q02 的一页快速开始是可独立采纳的精简提案。
2. **本次请求与下一张模式分开。** 倒计时显示已冻结目标，切模式只说明下一张。X / Escape 仍结束整个截图会话；已完成图保留。
3. **附近说明只表达事实。** 沿用已有短线、tooltip、AX，补正式设计中的 240pt 非激活说明；prepared 使用中性处理中。说明和动画不创造开始、完成或重试资格。
4. **恢复指向真正缺失的条件。** 目录访问、自有入口的 Screen Recording、Chrome Automation、Chrome 脚本设置、目标验证彼此独立。恢复权限不重放旧截图或旧点击。
5. **清晰预览不影响原图。** 保留历史三栏、当前页搜索和恢复资格；完整 Fit 预览独立按视口×backing 解码，有像素、实际 rowBytes、单任务及 epoch 预算。
6. **本地保存与送达分开。** Feedback 的服务能力持续可见；取消待发送、申请云端删除、已解决正文移除各自消费正式 engine 的资格。关闭保护继续保留，增加组字/忙碌/保存失败的准确解释。

固定边缘几何、双输入岛和透明缝隙、450ms peek、固定模式槽、移动取消盖片、无／磁力吸引、真实 uploadStarted 后快速吞噬、独立完成、无成功 Toast、UNKNOWN、原图和历史均保留。没有引入第三种动效、不安全自动重试、自动发送、清库或新的上传准入。

## 如何审阅交互原型

浏览器直接打开 HTML 即可，不需要安装、登录或网络。左侧是设计审阅控制区，右侧保留候选原生窗口的目标尺寸与薄界几何。全部截图、文字、权限和回执是合成内容；页面不读真实截图、聊天、浏览器认证或剪贴板。

切换“审阅情境”可固定看某个状态；右侧的产品动作与左侧的模拟事实按钮演示后续转换。固定情境中的剩余秒数刻意静止，便于比较；选择“运行倒计时（模拟）”才开始时钟。点击图片只进入受理阶段，`uploadStarted` 与独立完成必须分别注入，不会因等待而成功。UNKNOWN 用新的独立合成样本继续审阅，绝不解锁旧图。

建议审阅这六条路径：

- 首用：仅本地收录 → 来源可读无需重复授权；候选 → Chrome 条件未就绪；完成不自动试传。
- 捕获：运行倒计时 → 连续切换模式 → 本次目标不变 → X 结束 → 迟到完成无效。
- 附加：点第二张 → 连续点击 → prepared → 实际开始 → 完成或 UNKNOWN；鼠标移到另一张不能改变操作资产。
- 恢复：撤销入口录屏权限、Chrome 访问、目录暂不可读、显示器回退、保留隐藏和暂停。
- 历史：待核实记录只读；选择另一记录时详情/时间/预览同身份；Space 仅列表焦点内生效。
- Feedback：保存待发送、草稿保存失败、模拟组字阻止关闭、取消本机待发、申请云删除并等待真实确认。

原型没有实现完整 App、TCC、文件选择、Finder、Chrome 或网络后端；设置侧栏用于选择本次审阅情境，不冒充已完成所有设置页。浏览器中的复制/打开系统位置按钮只说明原生意图，不实际访问剪贴板或系统。HTML 字体采用系统回退，macOS 以系统字体为准；Linux 出图使用 CJK 字体回退，不视为最终 AppKit 字形或窗口栅格验收。
