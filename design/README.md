# Design — current directions

Riftlet has two existing edge-presentation forms and one newly user-directed parallel form. This index distinguishes a selected design direction from a shipped or natively accepted implementation.

Next step: [Riftlet's design brief](../docs/DESIGN_BRIEF.md), grounded in [the actual product constraints](../docs/PRODUCT.md). Distinguish mockups, engineering candidates, observed platform behavior and user-approved final design. Do not add invented real-app screenshots.

| Form | Scope and status |
| --- | --- |
| 微缝 | Existing narrow edge-rift presentation; preserve its current behavior and implementation. |
| 风铃 | Existing presentation form; preserve its current behavior and implementation. |
| [截图托盘（第三种形式）](third-form-screenshot-tray/README.md) | User-directed design baseline dated 2026-11-07. Based on the user-selected Saytile/Riftlet desktop composition, with adjustable image occlusion, bounded aspect-ratio thumbnails, and selectable color themes. Design direction only; native implementation and acceptance are not claimed. |

The screenshot tray is a peer presentation choice, not a replacement or an additional management panel. The three forms share the existing screenshot queue and attachment lifecycle.
