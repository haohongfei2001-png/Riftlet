# Riftlet · 真实比例交互原型 v1

独立设计评审成果。根据工程 PR #1 的 `485fa87a31140f9d2e428db69ec5e0599b1f96ae` 还原界面，使用合成桌面、截图、聊天和回执。**没有修改正式原生工程、适配器、PR #1、main 或 riftlet.com。视觉未冻结。**

## 立即运行

双击 `Riftlet-Interactive-v1.html`，用 Chrome 或 Safari 打开即可。完整 CSS、JavaScript、桌面图形和截图生成器均在一个 HTML 中，运行不需要安装依赖、登录或连接网络。

本轮实际运行检查使用托管 Chrome 预览。当前执行浏览器的 URL 策略禁止 `file://`，本地双击打开和 Safari 兼容性没有被写成已测通过；完整边界见下方检查记录。

源码包中，已构建版本位于 `dist/index.html`。修改 `src/` 后使用已安装的 Node.js 执行：

```sh
node build.mjs
```

这只把模块合并为独立 HTML，不下载任何包。`dist/index.html` 和 `dist/Riftlet-Interactive-v1.html` 内容相同。

## 先这样体验

1. 保留 **100% 真实比例**。初始 3 张图，直接点击桌面右侧的微图。
2. 点击 **生成截图**，或用 2 / 3 / 5 / 8 / 12 / 20 队列按钮切换测试场景。队列按钮会重置本轮合成附件和操作；这是评审工具，不是产品删除行为。
3. 切换点击结果：成功、明确失败、持续等待、UNKNOWN、上传期间换对话、上传期间出现新图。注入测试回执按钮可以结束等待，或核对原 UNKNOWN 操作。
4. 在模拟 ChatGPT 输入框输入文字，在左侧切换对话；草稿按对话保留。附件从占位、进度、确认到完成分阶段显示，不发送消息。
5. 比较浅色、深色、多窗口和最大化。拖动 Chrome 标题栏和右下角可以移动、调整窗口。绿色交通灯按钮切换最大化，Dock 的 Chrome 可以恢复窗口。
6. 选择 1470 × 956、1440 × 900 或 2560 × 1440 参考画布。100% 下过大的画布可滚动，**定位右缘**回到 Riftlet 位置；**缩小总览**只用于整体构图，不用于判断尺寸。
7. 点击 **沉浸体验**隐藏全部评审控件。Esc 返回；⌥ / Alt+Shift+N 可以在打字时产生合成截图，此快捷键仅存在于评审工具层。
8. 打开 **状态与测量**查看真实点击矩形、队列尺寸和事件记录。长队列把滚轮放在微图或数字上逐行查看；最早 / 最新也只属于评审工具。

## 几个值得留意的真实细节

- 72 × 56 pt 是拟合包络，不是每张图片都固定成这么大的卡片。横图、竖图、极长条图的可见面积不同。
- 只有图像本身、数字和一条细线；没有放大微图、额外圆角、装饰投影或环形进度。
- 新图只淡入。等待时浅入 2.5 pt 并保留单下划线；UNKNOWN 是双下划线且保持原操作。
- 长队列会使第一行上移，超出容量时按行滚动。吞噬后先补位，再重新编号。
- 默认是**合成传输模拟**。另有**普通工程模式 · 适配器未启用**，对应当前普通原生工程版点击后保留的行为。

## 还原与验证边界

几何、参数、动作顺序依据原生源码。Chrome / ChatGPT 的环境、回执时长与异常控制是独立合成评审模型；不是现有 App 已能真实上传的证明。浏览器字体、系统动态色、亚像素绘制及可用屏幕区域也有明确建模假设。

真实 AppKit 首击、非激活、透明窗口穿透、Spaces、多显示器、系统截图捕获、真实 ChatGPT 上传，仍由原生工程与本地 Codex 验收。本原型不与他们共享或争用真机环境。
