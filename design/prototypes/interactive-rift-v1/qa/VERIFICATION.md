## 独立审查后修复

- 裂缝绘制层级与原生顺序对齐。
- 未越过合成输入边界不能注入“成功”制造虚假吞噬。
- 切换对话能结束 indefinite wait 并转 UNKNOWN，原对话租约不自动复活。
- 补位完成后恢复 aria-disabled 与点击状态，并更新完成提示。
- 主题按钮只绑定评审控件，不将整个桌面或裂缝误当成主题开关。
- 本地 HTML 不序列化带运行时残留的 DOM 再导出，避免重复微图。

## 可复现静态检查

```sh
node build.mjs
node qa/check-geometry.cjs
```

build 会检查四个 JavaScript 模块语法，并生成完整无依赖 HTML。几何检查直接比较源码推导的固定数值；没有安装测试框架。

Chrome 本轮观察窗口约 1363 × 936 CSS px、DPR 1；实际工作台可用区域会扣除评审栏。截图是浏览器程序的运行画面，可能被聊天显示器缩放；判断尺寸仍应打开程序并选择 100%。UI 中 `0.7px` 会受浏览器亚像素栅格化影响，不能声称与 Retina 上的 AppKit 像素完全相同。

## 独立 HTML 的检查边界

独立 HTML 与经过运行检查的入口字节相同，所有样式、脚本和合成素材生成器均内嵌，无外部资源依赖。**云浏览器的 URL 安全策略不允许 `file://`，因此本地双击打开测试标为 NOT_RUN。** 没有通过其他浏览器、协议或执行方式绕过此限制；也没有把 HTTP 预览测试冒充成本地文件测试。用户可下载 HTML 后在自己的 Chrome / Safari 打开，无需服务器或安装依赖。
