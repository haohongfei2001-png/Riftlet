# 第四、第五种桌面呈放形式：折页与口袋

**状态：用户明确指定纳入五种并列呈放形式的设计候选；本 PR 仅提交设计与交互原型，不改生产 App。**
**基线：正式 main `4908dc79eb2e8af5ea3d53cfb81a719c7fdf5c9d`。**
**关系：与「微缝」「风铃」及第三种「截图托盘」互斥并列；本设计不取代前三种。**

## 用户决定

- 新增第四种「折页（Edgefolio）」和第五种「口袋（Pocket）」。
- 两者均采用更贴合 macOS 的**白色毛玻璃底座**，替换此前设计稿中深色、硬边、像裂缝补丁的底座。
- 白色毛玻璃是底座材质，不是新的品牌主色。品牌主色仍为 `#19B7A4`，深色辅助仍为 `#087C70`；原版 Logo `website-assets/riftlet.svg` 不变。
- 两个形式均复用同一截图队列、原图、点击目标、上传状态和历史；不得复制或创建第二套生命周期。
- 五种呈放形式使用同一个互斥的持久化选择项。保留现有个性化能力；新增形式不得重置其他外观、显示边缘、可见数量、遮挡、到达方式、减少动态或历史设置。

## 共用底座：macOS 白色毛玻璃

底座不再画成一条深色裂口或硬边胶囊。它应像轻量 macOS 浮层：半透明白色、柔和背景模糊、细白高光、低对比边缘、克制的环境阴影。底座是截图页片的背景承载，不应比截图本身更醒目。

### 设计 token（逻辑点）

- Base material：`NSVisualEffectView.Material.popover` 候选；以真实系统渲染比较 `hudWindow`，不自行伪造系统材质。
- Blending：`behindWindow`；State：`active`；圆角 10–12 pt。
- Light appearance：白色毛玻璃观感，白色高光约 0.72–0.90 alpha，细边缘 0.5–0.75 pt。
- Dark appearance：保持相同材质和层级，使用系统自适应材质；不可强行保持不透明纯白而造成刺眼亮块。若产品最终要求白色恒定，须作为单独、可评审的 tint token，不硬编码到材质本身。
- 阴影应轻，避免厚重黑边、发光描边、渐变色条和多重投影。
- 品牌色仅用于 1 pt 左右的状态/焦点提示，不铺满底座。
- 提高对比度时增强轮廓与文字，不改变点击几何。
- 无截图时，整个形式消失；不留下空底座或常驻裂缝。

网页原型用半透明白色渐层、描边与轻阴影近似表达材质；它**不能**证明真实 backdrop blur。原生必须使用 `NSVisualEffectView` 并在 macOS 浅色、深色、提高对比度及复杂壁纸下验收。

## 04 — 折页 Edgefolio

- 每张截图保持独立、持续可见；共享同一个边缘根部和连续页片节奏。
- 图片按原始宽高比适配，不裁剪、不拉伸；横图和竖图进入同宽页片，编号置于独立、固定宽度的编号槽。
- 推荐研究尺寸：适配框 96×64 pt；页片宽约 106 pt；相邻页片节距约 72 pt。保留原配置 72×56 pt 作为兼容对照，不覆盖用户已保存值。
- 单张时底座紧凑；多张时沿边缘纵向扩展。十张仍沿用当前可见数量和分页逻辑，不创建无限货架。
- 点击目标属于各自页片；页片间空白穿透，不由共享底座抢占所有点击。

## 05 — 口袋 Pocket

- 静止时图片轻度错位叠放，形成紧凑的边缘口袋；不得把所有图片合成一个不可分辨的按钮。
- 悬停时平顺展开，所有可见图片分别具有独立命中区域；点击任一张都直接附加，不要求先展开或二次点击。
- 展开时维持队列顺序和可预测位置；收拢只改变呈放几何，不改变队列索引。
- 叠放遮挡是纯视觉属性，不得让截图身份、点击目标或失败状态丢失。默认遮挡保持克制并继续支持现有个性化设置。
- 减少动态时直接呈现稳定展开/收拢终态，不执行旋转、弹簧和位移动画。

## 必须继承的交互合同

1. 一次点击附加；不自动发送、不要求拖放、粘贴、文件选择器或二次确认。
2. 轻按不是成功。只有原目标、原截图的正向 START 证据到达后，才快速吞噬。
3. 明确或极高置信度的实际失败才恢复为普通、立即可点击的截图。
4. START 后 UNKNOWN 保持隐藏、只观察原操作，不盲目重试；不得阻塞不同截图。
5. 吞噬可快，补位必须等待现有指针/交互保护门通过，不能把下一张移到仍停留的指针下方。
6. 无有效目标或输入未开始时保持可见。
7. 不改截图原件、队列身份、历史默认 `current`、可选 `imageGrid` 或任何既有个性化设置。

## 原生实现建议

- 只增加 presentation-style 分支与可逆的布局/材质参数；复用现有 queue model、asset identity、hit testing、START/UNKNOWN/failure 状态和 archive/history。
- 折页/口袋各自实现独立的纯几何布局器；共用一套截图 cell view 和点击路由。
- 底座使用单个 `NSVisualEffectView`，截图页片作为其上方独立子视图。避免整组视图做一个大命中区域。
- `NSVisualEffectView` 仅负责材质；边缘根部/切口用独立轻量 `CAShapeLayer`，不要把深色裂缝路径重新做成实体底座。
- 动画按 asset UUID 驱动，不按数组索引驱动；吞噬、失败返回和补位沿用现有 reducer/状态机。
- 设置迁移采用新增枚举值，旧值字节语义不变；未知值安全回退到既有默认「微缝」，不能重写用户偏好。
