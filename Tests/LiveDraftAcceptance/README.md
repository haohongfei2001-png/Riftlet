# Build 53 live draft QA

The two previously recorded operations can be read from the isolated build 53 QueueStore without opening either browser. Supply the original QA root, operation UUID and PNG digest to `python3 read-operation.py`. The command verifies the candidate executable, then returns a sanitized record for that operation. The two captured records are in [build53-exploratory-store.json](../../docs/releases/1.0.7/evidence/build53-exploratory-store.json).

The public Browser client exposes provider tab IDs in enumeration results. Its standard `tabs.new()` has no dedicated-window option, and a controlled Tab's optional `windowId` is unavailable on the extension backend by default. The canary uses the advertised `management` capability on the selected external browser. For an explicitly requested family, use the official client's initial selection and documentation step in the connected session:

```js
const chrome = await agent.browsers.get("chrome");
nodeRepl.write(await chrome.documentation());
```

For Edge, acquire its separate persistent handle with `const edge = await agent.browsers.get("edge");` followed immediately by `nodeRepl.write(await edge.documentation());`. Read the complete output before using the handle and consult the advertised management capability documentation. Supply that same `browser`, `browsers: agent.browsers`, `bundle` and optionally `browserID`. The harness checks the selected handle's ID and family against discovery metadata. A failed bootstrap can be classified with `browserHealth({connectionError: error})`. An unknown family, missing trusted RPC or absent window-management capability stops before creating a window.

Call `browserHealth(options)` from `browser-preflight.cjs` for a read-only precheck. It returns only status fields and does not enumerate tabs. During window acquisition, the harness reads only identifiers of existing tabs, then claims its own confirmed blank. Subsequent input guards query only that QA window. The same check runs inside `createLockedDraft(options)`, so a separate probe is optional. The canary makes one normal, non-incognito window with `management.windows.create()`, confirms the active blank is new, correlates its tab with the exact `browser.user.openTabs()` result for `claimTab`, and verifies the claimed provider tab ID. It never claims an existing personal tab. Failed setup reports a stable error code; a lost creation or claim reply reports `UNKNOWN` and is never retried. An unconfirmed tab is retained. The signed-in state of the new composer must still be checked by the draft observer.

Supply an independent `readNative(bundle)` callback returning the current macOS foreground bundle, kernel-birth session ID, window ID and selected tab ID as strings. Build the included identity-only observer once with `Tests/LiveDraftAcceptance/build-front-identity.sh /absolute/path/to/front-identity`. Invoke that executable with the bundle ID from the authorized Mac QA collector and parse its single JSON object in memory. It sends one PID-addressed Apple Event requesting the selected tab descriptor with interaction and permission prompts disabled. It can neither activate a window nor send keys or read a page. A failed read is a blocker. Keep identifiers local. Before accessing the draft, the foreground identity must match the original normal window and the claimed provider tab; a format mismatch between browser IDs and native IDs fails closed. The canary handles the initial browser-internal blank page using window metadata and the native observer alone.

In addition, supply locators grounded in that live UI for the genuine New chat action and the original editor, and the existing independent read-only `read(tab)` draft observer. The observer must retain the correlated controlled tab handle, report the native window ID string as `windowHandle`, and sample its original document, composer, draft generation, navigation and route with no re-binding. The canary guards the official tab mapping and native foreground independently on every input. Keyboard API availability is a prerequisite. Delivery is observed only when the original text and selection are read back. Without a trusted browser or live draft observer, G1/G2/G4 stay unexecuted.

After landing on the official home page, the harness rejects a conversation route, existing content or ambiguous editor. It activates New chat and freezes the draft. The seed phase presses individual keys directed to that tab, then Shift-Left and verifies the selected text. No clipboard, global keyboard or Send action is used. With an existing test attachment in the same composer, `beforeClick(requiredPriorCard)` records the selection and member identities. `afterClick(receipt, expectedPayloadSHA256)` reads the same draft after the actual user-path Riftlet click. Successful page-only observation must still be correlated with the independent signed-app action and receipt. The helper covers the fresh draft setup. Saved-chat ownership, a native tray click, elapsed time, cross-run uniqueness, the G4 loop and W0 admission are separate.

Use `withLockedDraft(options, execute)` to cover setup, the test body and cleanup; it returns the callback result and cleanup status. Failed setup and callback errors carry a cleanup status when a tab was allocated and identified. The helper uses the original Tab object's close method once. Uncertain ownership, changed content and a lost close reply are reported separately. An individual `createLockedDraft` caller should await `run.close()` in its own finally block.

If Edge shows the generated QA filename but the signed App has no START, `edgePreviewShape(generatedName)` requires the observer's `locateOriginalEditor(tab, target)` to return the original native and draft identity fields, tab/window handles and a locator uniquely bound to that composer. It uses a read-only evaluation on this locator even after focus moves away. A collector lacking that locator cannot collect the shape. The diagnostic samples the original editor's visible matching preview and its bounded ancestry. It records source type, current/declared source equality, decoded dimensions, child counts and placement of the same-file Remove control. Original URLs, pixel data, message text and generated filename are excluded. No observation of this shape was possible on the historic attempt.

`node --test locked-draft.test.cjs` runs an isolated fake browser with deliberate focus/identity changes. It does not exercise browser keyboard delivery or establish G1/G2/G4.
