支持范围

Mac
构建目标为 macOS 13 及以上。当前个人安装包适用于 Apple 芯片（ARM64）。Intel 构建经过自动化检查，Intel 实机及各系统版本仍需分别验证。
Chrome 中的 ChatGPT
打开要使用的聊天，将能添加图片的草稿留在当前 Chrome 标签页。Riftlet 只向点击微图时的草稿交接图片。本版本的首张和连续第二张截图仍待在真实 ChatGPT 上复验。
其他环境
目前的测试范围不包含 Safari、Edge、Firefox、ChatGPT 桌面 App 或其他 AI 服务。临时聊天、Projects 和组织工作区也需分别验证。

版本说明

0.3.0 (3) · Personal Beta 3
本地历史支持列表和图像网格。切换浏览样式会保留当前搜索、筛选和选中图片。这个版本已在个人 Apple 芯片 Mac 上安装验证。
0.3.1 (4) · 维护候选
这个版本改进了重新打开历史时的图片读取。个人 Mac 试更新后无法继续读取原截图目录，换回 0.3.0 并重新选择该目录后恢复了收录。目前仍使用 0.3.0。
本次预览（未发行）
首次引导说明了截图后要点击哪张边缘微图。选择文件夹时会显示 macOS 的截图保存位置，选错目录后可按提示重新选择。「设置 → 历史与存储」新增「在 Finder 中显示数据文件夹」。

公开下载还需完成 Developer ID 签名、Apple 公证和普通 Mac 的安装检查。此处没有可供外部分发的安装包。

封闭测试

我们计划邀请 10–20 位平时就在 Chrome 中用截图提问的 Mac 用户，了解首次设置是否顺手、几周后是否还愿意使用。封闭测试尚未开放报名。

受邀后，第一次任务是用自己制作的无隐私样图，在专用草稿里试两张截图。无需发送聊天消息。后续按自己的节奏使用，可自愿反馈或退出。
