Compatibility

Mac
Builds target macOS 13 or later. The personal installation runs on Apple silicon (ARM64). Intel builds have passed automated checks. Intel hardware and individual macOS versions still require hands-on testing.
ChatGPT in Chrome
Keep the intended chat open in the current Chrome tab with a draft that accepts images. The handoff targets the draft selected when you click. The first screenshot and an immediate second attachment still await verification against live ChatGPT on this build.
Other environments
Safari, Edge, Firefox, the ChatGPT desktop app and other AI services are outside the current test scope. Temporary Chat, Projects and managed workspaces also need separate verification.

Version notes

0.3.0 (3) · Personal Beta 3
Local history offers a list and an image grid. Switching views keeps the search, filter and selected image. This version has been installed and checked on a personal Apple silicon Mac.
0.3.1 (4) · Maintenance candidate
Reduces repeated image decoding when reopening existing history. This candidate is for isolated testing. The personal installation remains on 0.3.0.

Public distribution awaits Developer ID signing, Apple notarization and installation checks on a clean Mac. No installer is available here.

Closed beta

We plan to invite 10–20 Mac users who already ask questions about screenshots in Chrome. We want to learn how setup feels and whether people return to Riftlet a few weeks later. Sign-ups have not opened.

If invited, you’ll start with two non-sensitive images you create yourself and a dedicated draft. You can leave the message unsent. After that, use Riftlet when it fits, give feedback if you wish, or leave at any time.
