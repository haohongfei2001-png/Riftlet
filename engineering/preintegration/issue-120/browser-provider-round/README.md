## 开始真实验收的条件

桌面版本 26.1117.31558 的磁盘配置含 browser，服务文件在位。当前桌面会话的可信握手返回 `Trusted RPC service is not configured: browser`。Computer Use 拒绝代理操作桌面 App 自己的设置。现有证据能定位失败阶段，尚不能确定服务未注册的内部原因。官方恢复入口是桌面设置的 Computer use；Edge 另需在现有配置启用官方扩展。扩展与登录状态相互独立。此次普通配置新增窗口、按键、截图点击均为零。

启动前先对照官方安装诊断，再在官方客户端已选的浏览器上检查管理能力，创建一个新普通窗口，限定查询其中的单一空白标签。验收工具交叉核对原生进程出生、窗口 ID、选中标签 ID 和浏览器交付的标签身份。新建聊天只点一次，可以等待页面更换原稿身份；到期停止。后续真实按键仍需在原编辑器中见证结果。原窗口、标签或草稿发生变化即停止。等两个 canary 均完成后的同包 G1/G2/G4 才能用于本轮准入。[运行入口和观察者要求](../../../../Tests/LiveDraftAcceptance/README.md)

## Edge 原操作

对历史隔离库中的同一操作重读，Edge 创建后 10.466 秒更新为 UNKNOWN，START 表无行。Chrome 的历史操作在 4.625975 秒写入 START，4.626205 秒更新操作。新增 Edge 观察按原进程、窗口、标签、文档、编辑器及草稿世代关联页面和存储。计时分别保留预览读取边界、库读取边界、实际 START 时间和最近更新时间。读取超时或身份不符会结束采样。上轮 Edge 预览的来源、真实解码尺寸、原卡和移除控件关系及回执丢失位置仍缺实站数据。旧 UNKNOWN 保持只读。[原记录](../../../../docs/releases/1.0.7/evidence/build53-exploratory-store.json)

## Provider 修复和复核

旧网页资源在上传控件重建后读不到仍在原草稿附件区的原卡。修复后，写操作仍绑定原文件输入，已输入后的只读观察单独核对原编辑器、附件区和原卡。受控 WebKit 夹具实测一次 input、一次 change、零错投、零发送，文字、选区和旧附件保留。非作者用编译资源独立重放五种情况：原卡报错会报告明确失败，同名另一卡报错保持 UNKNOWN，替换后换回编辑器、附件区或历史项均拒绝读回。各组的二次提交均被拒，重建的文件输入保持为空。编译后的 Swift 适配器及 SQLite 验证了重启后只读续查、原 PNG 找回、用户新点击才开始第二次操作。测试站点为本地夹具，焦点和可见性由夹具提供。Claude 和 Gemini 仍缺各自的实站准入。

私有开发 ZIP 含上述修复，已重新解包、验证资源与源码逐字节相符、执行三个自检并通过 deep/strict 签名校验。架构 arm64，ad-hoc 签名，未公证。既有 build 53 DMG 的 SHA-256 重新核对相符。两 PR 均保持 Draft，公开版本仍为 v1.0.5。[开发包收据](development-package.json) · [Safari 独立客机收据](../hosts/safari-epoch/receipt.json)
