## 仍会影响普通使用的限制

1. 真正点击时没有完整 ACK 的场景仍安全拒绝；Beta 不保证 Chrome 首次启动、刚切聊天、恢复页面后的即时点击成功。正常稳定页面与边界必须区别，不要求先聚焦编辑器，不把再次点击作为解决方案。
2. 上传前等待通常可感知，本样本点击到窗口消失约 2.72 秒。当前等待提示主要经 tooltip/辅助功能呈现，连续点击的可见反馈仍有体验改进空间。
3. 系统截图包含 Riftlet 自身的既有 **FAIL 保留**。可主动隐藏裂缝降低干扰，但不是系统截图通用排除方案。
4. 真实 Chrome 物理鼠标附加、指定 CLEAR 靶点、补位后物理双击、不同图形/缩放全面覆盖、多显示器物理操作、Spaces/全屏、首次安装/Gatekeeper/真实权限撤销恢复、T0/T1/T2 本轮 **NOT_RUN**。没有为了扩大结论再上传图片。
5. 普通生产上传、安全失败和重试继续关闭；受限候选不扩范围。Feedback 接收端仍未配置，本机草稿不代表开发者已收到。
