  even when an attachment button exists. Otherwise the operation activates the
  real local action and follows the UI it opens or controls. Native and labelled

* The adapter intercepts the input's click/showPicker temporarily. An object
  invoked by the current control can receive its own input/change while detached.
  Native async/await can reach an existing unlinked picker. The program restores
  its descriptors and leaves Promise, timers and animation scheduling alone.
  Concurrent unidentifiable picker invocations retire before the setter.
* Programmable pointer/mouse phases and cancellable clicks are untrusted.
  An opener that already advanced on pointerdown is not clicked again. The
  application's file object receives one native setter followed by input and
  change. The old acceptance rule still requires the original current file's

  excluded. Trace fields grant no input, retry, completion or file authority.
