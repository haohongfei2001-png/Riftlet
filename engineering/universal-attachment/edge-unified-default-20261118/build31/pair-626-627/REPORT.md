## 624 的修复

实测源码 `fb4e8fa` 只要在发送文档绑定请求前剩余不足 50 毫秒，就会返回 `invalidReply`。624 当时尚有约 49.5 毫秒。签名候选 `cb82a72` 以 Apple Event Manager 的完整 tick 为单位向下取整，同一点击的原生身份读取、文档绑定和最终选择复核继续共用 150 毫秒。独立 macOS 接收器在 49.5 毫秒的案例收到一笔请求并回复，低于 1 tick 的案例未发送。签包为 1.0.5（31），可执行 SHA-256 为 `2ef4f1abadf7893ca88b58a839092fbdac891942627971949467b46cbf04e3c2`。[签包与系统回包](runtime.json)

该修复第一次送 CI 时，ARM64 上两个步骤在编译独立 Edge 探针时退出。三份独立 `swiftc` 清单在当时的源码上均可复现。`04fa8ff` 将限时发送函数由普通 Edge 执行器传给只读宿主。原三份清单在修复后均能编译，鼠标自检不投递事件。此次调整沿用原有进程和目标复核、系统权限预检与超时处理。[原 CI、失败及修复](arm64-compile-followup.json)

## 625 留在原草稿的图片

后续只读检查从原草稿具名卡片中读取了现有、已加载的 IMG。它的内嵌 PNG 和用同一 Edge 离屏 Canvas 编码原截图所得 PNG 均为 1,386,479 字节，SHA-256 均为 `fe8f5658ddf52d7082020bfb11392c12f10c58db3506b01de12ac0469df212f8`。逐像素比较原截图解码和预览解码，591,552 个像素中有 25,716 个存在最大 1 级的 RGB 差异，透明度一致。这次读回没有文件输入、网络请求或文档写入。[原稿图片读回](original-625-preview-readback.json) · [独立审查与测量范围](625-content-audit.json)

该结果确认了 625 留在草稿中图片的内容。早期进度所在的卡片和移除按钮已在预览出现时换成新对象，服务处理流也没有可读终态。625 的历史 START 和完成回执继续按原记录保留。[原始点击和处理记录](../pair-624-625/REPORT.md)
