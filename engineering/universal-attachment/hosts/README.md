# Local host inventory

On macOS, run `swift engineering/universal-attachment/hosts/inventory.swift` from the repository root. The read-only query uses LaunchServices registrations (including applications outside ordinary install directories), per-bundle running application counts, and known bundle names in system and user Applications directories. A package filename alone cannot match a host. Duplicate metadata can represent distinct registered paths for the same build. The report omits installation paths, process IDs, window titles, URLs and foreground application identity.

See [the dated inventory](local-macos.json). The initial sandboxed lookup returned zero registrations even for installed browsers and had no foreground identity. The recorded snapshot was captured with actual LaunchServices visibility. It observed three running Chrome processes and one running Edge process, alongside one ChatGPT-labelled Codex process. These counts indicate coexisting receivers. They establish no cross-browser attachment outcome.

Safari 27.0 directly declares a current tab, tab index and JavaScript event in its scripting definition. Its tab class declares no stable tab ID. This Mac had zero running Safari processes at the snapshot, so no owned neutral window was available to probe over Apple Events. No Safari window was launched or inspected. Safari receiver selection, tab/document continuity, file insertion and receipts remain unverified. The CI command `python3 -B engineering/universal-attachment/hosts/safari_fixture.py` runs only on a fresh GitHub-hosted macOS console. It checks that Safari is not already running, launches the test instance, determines Automation permission without prompting, then attempts to bind three loopback documents at the very same URL across two windows. It checks that closing only its first tab shifts its sibling's native index and that the document-specific marker survives that shift. It makes no changes to Safari's JavaScript and Automation settings. A 77 status records the unavailable prerequisite. Successful fixture identity evidence would still leave file handoff and commercial-service support unverified.

Its AI draft surface and attachment support were not exercised. User-facing ChatGPT branding should not silently alias one native bundle to another.
