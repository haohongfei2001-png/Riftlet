## 给 Pro 的使用方式

查看器里的图片排列是证据索引，不是桌面布局；真实位置/图层在 artifacts.json。许多截图中的窗口处于非活动状态，因此标题和控件呈系统灰色；这不是一次新的视觉裁决。PNG 是原始 WindowServer窗口像素，MOV为实际时间戳的有损编码，约11Hz的抓帧频率不是产品帧率。黑色/透明空白不代表已测试壁纸。示例只有自有合成内容，保留所有未通过与未执行结果。

当前参数来自实际保存配置：适配框72×56pt、隐藏25%、行距60pt、默认每页3张；实际第一张可见图片54×48pt。220ms到来、60ms按压、120ms吞噬、160ms补位、180ms返回是配置值，不是本轮网络START的实测时延。

真正的不同壁纸、磁力、START吞噬与上传失败恢复动态仍缺本轮完整证据：浏览器工具禁用；独立 native timeline 因后台窗口不在当前 Space 明确失败，原 `exit0` 误报已针对性修复，但没有放松显示资格来制造成功。新桌面视觉语言交由Pro决定，本轮不改品牌或结构。
