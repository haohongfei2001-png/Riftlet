# 原生视觉与系统窗口收录补充

打开 [离线查看页](index.html)。录像可在页内播放，浏览器不支持 MOV 时可打开原文件，用 QuickTime 播放。原有 44 张 PNG 和 3 段录像保留在[既有视觉基线](../../native/visual/index.html)。

源码为 main `15490d8817e435e402ff0cba55fdb92078100ab6`。浅色和深色两段投影由该源码的原生呈现工具生成，只捕获工具自有合成窗口。浅色录像含 142 个视频样本，深色录像含 140 个，均为 1600 × 2560 像素、单视频轨、无音轨。四张选定静帧逐字节复制，清单同时记录原文件 SHA-256 与 ImageIO 解码后的 sRGB 预乘 RGBA 像素散列。录像采样包含捕获开销。本次投影没有网络接收回执，不能用于判定真实附件状态或应用帧率。

同一 main 的正式 App 可执行文件 SHA-256 为 `5a7eb19885c2e252e5df556ee1af29311ef396c86ada5133846aa5ff619f6eac`。隔离实例的两页引导经真实 macOS 窗口截图生成两份不同 PNG，测试检查或补充截图资格标记。收录后两份私有媒体分别与原件一致。对第一张微图投递一对归属已校验的软件左键按下/抬起事件后，两张仍可附加，资产为 2、operation 为 0、START 为 0。此场景没有浏览器目标，`REAL_ACCEPTANCE_NOT_RUN`。

系统截图只列原始散列与尺寸。原图含本机元数据，其中一页还显示隔离目录路径。首次数据库只读核对误用了忽略 WAL 的模式，随后在含完整 WAL 的临时副本上核实结果，未重做截图收录或点击。
