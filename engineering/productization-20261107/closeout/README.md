**个人准入**：现有个人安装可以继续使用并保留回退；本次扩大的 `PERSONAL_BETA_3_ACCEPTED` 仍缺当前真实附件证据。**封闭 Beta**：尚缺干净设备的安装、授权和首次成功附加，以及可信分发。**公开推广**：`PUBLIC_BETA_BLOCKED_OWNER_CREDENTIALS`；还需公证、干净设备 Gatekeeper 和封闭试用证据。没有招募或公开分发。

下一位工程负责人先查本目录的最终身份记录及 PR #46。待有可用、已授权的浏览器接口，再用此安装版本和新的空白草稿测试两张截图，保留正文和附件、不发送消息。维护版不做无人值守二次替换；先用[升级身份预检](../../../docs/release/MANUAL_UPDATE_AND_RECOVERY.md)核对候选。待账户所有者配置可使用的 Developer ID Application 身份和公证凭据后，从同一已审核源码构建发布候选，在独立 Mac 验证首次安装、授权与手动回退。整体桌面创意如需改变，另由 Pro 根据原始原生视觉资料裁决。
