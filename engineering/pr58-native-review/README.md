## 产品源码与实拍

产品增量 `5995131894d5c7c5877cb22b854b2a9f4cd121a3` 删除折页、口袋入口、专属绘制与布局。既有配置的原始值可无损往返；旧折页和口袋显示为托盘，未知值或未启用的风铃回退微缝。既有微缝选择不变，新用户默认在整体验收时裁决。附件、数据库及恢复机制无改动。

真实目标显示器分别为 1920 pt 横屏右边缘和 800 pt 竖屏左边缘，托盘各为 **240 pt、100 pt**；两台均为 2×。展开宽度不变，四个菜单键分别命中，三条样例记录身份和顺序保持。1× 仅有程序级几何检查。9 项使用真实产品模块和 XCTest 测试体的本机断言通过；本机为 Command Line Tools，未将该执行器记为完整的 XCTest CI。

评审 App 源码为 `18e4fc303d95530cee99f27a11cec2cf40160412`。其界面仅写 `Riftlet-PR58-VisualReview/appearance.json`；生产设置、权限状态、数据库与登录项不作为这个预览的写入目标。9 次系统 AXPress、24 次控件读回验证了收录、隐藏、内置入口、历史列表/网格跨窗口同步且退出重开后仍保留。34 张最终原生窗口实拍（17 场景 × 浅深色），3 种历史视图均为 808 × 492 pt，控制中心为 320 × 213 pt。曾出现的台前调度缩略图、浅色弹层低对比度、历史被大图撑宽均未算入通过证据。源码和最终实拍经非作者复核。逐项状态及散列见 [acceptance.json](acceptance.json)。

## 在本机打开或复验

在 macOS 安装 Command Line Tools，给下方构建命令一个新的输出目录。应用签名为本机 ad-hoc 设计预览身份，不是可分发的签名更新包：

```sh
bash engineering/pr58-native-review/build-review.sh "$TMPDIR/riftlet-pr58-ui-review"
open "$TMPDIR/riftlet-pr58-ui-review/Riftlet 界面预览.app"
```

启动后显示设置，使用“窗口”菜单查看其他界面。重新采样可在获准录屏的 Apple Silicon Mac 上编译 `capture/Snap.swift`（部署目标 macOS 13），再用安装有 Pillow 的 Python 运行 `capture/sample.py <Review可执行文件> <Snap工具> <新输出目录>`。工具校验窗口所有者与实际像素尺寸；设计示例不需要真实用户数据。用 `make-gallery.py --help` 查看离线画册的输入要求。
