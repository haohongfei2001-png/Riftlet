# 截图托盘：颜色和取消滑盖

本次增量以 0.3.4 (12)、`c5e61ff83ebea098cdae63e4cf8b58a7c65f93d7` 为比较基线。[PR #51 原始图与规范](../../design/third-form-screenshot-tray/README.md)仍决定托盘的材质、几何、开合与补位。[build 12 的窗口采样和故障记录](FINAL-TRAY-ACCEPTANCE.md)保留为历史证据。

- **颜色。** 系统和紫蓝玻璃仍是可直接选用的预设。自定义单独保存色相和色彩强度；切回预设不会覆盖这两个值。色彩只作用于托盘表面，图片保留原图颜色。检查自定义时必须在同一桌面背景、同一倍率和相同截图的条件下比较，并另查图片内容及托盘边界没有随之改变。
- **取消。** 默认截图键继续使用已有截图控制器。取消能力随真实活动会话出现。检查一次取消必须看到同一截图会话结束、原有选择器消失、托盘可再次操作，且没有生成截图；只有滑盖动画或视图方法被调用不构成该项通过。
- **独立附件验收。** 签名、单元测试、窗口截图和取消成功均不能证明 ChatGPT 接收。受支持的 Chrome 接口在创建独立测试窗口时返回 `Creating browser windows from extensions is not supported in Owl.`；没有取得本任务可用的专用空白草稿。两次投递均未执行，setter/change、实际附件、START、对应吞噬、正文保留及未发送无本次观测数据。没有改用私人标签或其他控制通道。

## 已确认的设置保存故障

独立复核在初版 `05119e8` 中输入 101% 强度后切到系统主题，再将边距设为 22；保存返回隐藏强度字段非法，实际边距仍为 6。修正只区分当前可应用的字段与保留的未提交输入：预设下保存其他字段不会使用或丢弃隐藏的色值，切回自定义后仍可纠正该草稿。复验需覆盖无其他改动、存在其他布局改动、重新显示后纠正三条路径。
