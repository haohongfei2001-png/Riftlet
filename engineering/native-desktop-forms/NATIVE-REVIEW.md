# 原生桌面呈放验收

同一隔离 App 的设置页、真实截图收录器、SQLite 和桌面面板参与测试。每次用新的 UUID 建立独立数据目录，使用自行生成的 PNG。窗口图像由 WindowServer 从当前 App 拥有的窗口编号生成，原始文件只在签名 Mac 的私有证据目录保存。

| 检查 | 已观察结果 |
| --- | --- |
| 微缝、截图托盘、折页、口袋 | 逐一操作原生设置弹出控件。0、1、2、3、4、5、10 张时检查可见身份和活动操作。 |
| 风铃 | 设置保留该条目，显示待确认并禁用。没有经过完整验收的风铃 renderer。 |
| 托盘 | 软件 CGEvent 鼠标在实际相机按钮打开菜单，三种截图和更多选项在同一行。向 App 事件队列投递 Escape 后收起。真实窗口收到滚动 delta -80，由 1–3 页片移至 4–6。 |
| 口袋 | 软件 CGEvent 悬停展开，原指针下 UUID 保持，16 帧按实际采样时间留存。 |
| 白色材质及外观 | 浅色、深色；两种材质在同进程实际纯白窗口和有图案窗口前方由 WindowServer 抓取。对比度另用原生高对比度外观覆盖，两块实际显示器均为 2×。 |
| 显示器 | 设置切换 1920×1080、800×1280 两个真实屏幕。检查四种形态的行帧和当前显示器，分别测试左右布局。 |
| 重启 | 同一可执行文件启动新进程；读回口袋偏好及 10 条完整资产记录，数据库记录摘要相等。 |
| 物理操作与外部服务 | 现场 1× 屏幕、用户硬件操作、系统“提高对比度”开关、VoiceOver 实际朗读、ChatGPT 真实接收、START 以及失败恢复均未在本轮窗口矩阵中验证。 |

首次滚轮试验采用进程定向的 CGEvent，超时且未观察到翻页。第二轮先将指针移动到经过 WindowServer 确认为本 App 的窗口，再通过系统事件流滚动，实际观察到事件和页码变化。保留了首次失败。第一次 45/46，第二次 48/48，第三次 51/51；第三次另有重启 PASS 和 89 张原始 PNG。独立的 Swift 布局执行共 1678 条断言，覆盖屏幕负原点、1×/2×几何、边缘约束下的口袋锚点和矩形命中。只有 CI 完整 Xcode 环境运行 XCTest。

## 复跑

用同一隔离 App 可执行文件，先运行 `Riftlet --settings-review <新UUID> --settings-review-run --desktop-forms-review`，待退出后运行 `Riftlet --settings-review <同一UUID> --settings-review-restart-check --desktop-forms-review`。请使用有 WindowServer 的登录桌面。程序将结果写入该 UUID 的 settings-review 专有数据根下的 evidence 子目录。检查 report.json 的逐项状态和 restart-report.json。无图形桌面或事件投递受限时保留失败。

准备工作树的第三次调试包 SHA-256 为 `9a07ce1b2af033552662c7ca02dd09fe8db5e672b59aeee315d04631679a5ab0`。正式发布候选的源码及包身份需要单独记录。

### 五张队列的失败返回回归

初版 0.3.4 (7) 的单独生命周期探针发现，在五张队列中吞噬首张并完成补位后，已获明确失败证据的原截图恢复为可见，但面板仍锚定第二张。四种形态均可通过翻页找回同一 UUID。两张队列没有复现。已有视觉矩阵不覆盖此序列。

共享面板现识别新出现的 safeFailure 可见修订。在保留按压、选择和指针补位保护的前提下，它把恢复的 UUID 带回视口。翻页、显示和点击继续使用原有记录。后继私有候选使用 0.3.4 (8)。旧包及其失败证据独立保留。

修正版基于 `6df831f971a474a3ee9ba4749e4c0749bbbbe865` 的独立 AppKit + SQLite 程序级重放共 16/16 场景通过。2 张和 5 张队列中的原 UUID 无需翻页即可再次点击，第二次显式点击才创建 attempt 2。也覆盖各形态吞噬中切换、另一张保留、指针保护和 UNKNOWN 不重投。这些记录使用受控的持久化状态和真实原生视图，不证明本轮真实 ChatGPT 附加。

正式 CI 另捕获了历史兼容边界：启动时已经隐藏的旧 UNKNOWN 日后恢复时，不能抢占当前页。后继修订将自动回到视口的范围收窄到本页实际观察过 START 吞噬的 UUID，并在显式翻页后释放该记忆。复用原有历史回归，原断言保留。最终候选为 0.3.4 (9)。
