本轮统一界面
设置窗口内包含运行状态、截图入口、显示与动效、隐私与存储、关于与支持。
默认截图模式只影响下一会话；关闭预测入口仍保留系统截图收录。显示器选项保留断开设备的选择。
系统减少动态/增加对比度/减少透明度有相应呈现；最终真人系统切换仍需单独验收。
入口完成截图后保持当前模式；取消或明确打开辅助窗口会收回选择层，避免覆盖设置/历史/反馈。
极端比例图片使用可见编号垫片，悬停可查看完整比例；新视觉参数仍为实施候选。

首次安装与启动
1. 解压整个 ZIP，将 Riftlet-Internal-Beta 文件夹放到固定位置，例如个人“应用程序”文件夹。
   保持 App、启动入口和本说明在同一文件夹。不要覆盖反馈开发者或其他工作树中的 App。
2. 如已有旧 Riftlet 实例，请从它自己的菜单正常退出；不要删除任何本地数据。
   一次只启动这一份内部候选，以免多个菜单和裂缝造成混淆。
3. 双击 Riftlet.app 进入普通产品入口，使用 Riftlet 数据根。当前源码配置系统截图与
   内置截图附加、真实开始及独立完成观察；准确能力以同包 ordinaryBuildInfo 为准。
   安全重试与未决多附件继续仍未准入。不要把已配置的功能当作正式发行或真机验收通过。
   Start-Riftlet-Internal-Beta.command 仅用于沿用历史系统截图候选的隔离验收入口。
   它会短暂打开终端，再直接启动同目录的 App；不需要输入命令。
   看到菜单栏“Riftlet REAL TEST”即为正确模式；应用可能没有 Dock 图标。
   不要同时或反复启动两个入口；该 command 不改变普通入口的编译能力或迁移旧数据。
   反馈是否能够发送由本包的反馈配置决定，与截图上传准入相互独立。
4. 若 macOS 提示未识别开发者，请确认是本次交付包后，按系统“隐私与安全性”的
   正常“仍要打开”流程处理。此包仅有开发 ad-hoc 签名，未签名公证为公开产品。
   不需要关闭 Gatekeeper、清除 quarantine 或修改系统安全设置。
5. 首次使用会显示原生引导。也可在菜单打开“开始使用…”或“设置…”。
   确认 macOS 截图实际保存为文件，并允许访问该截图文件夹。
   手动打开 Google Chrome；在引导里主动检查并允许 Chrome 自动化权限。
   按引导在 Chrome“显示 → 开发者 → 允许来自 Apple 事件的 JavaScript”开启页面连接。
   不需要浏览器扩展，不需要先点一下聊天编辑器，也不需要每日新快捷键。

日常体验
1. 普通入口配置支持 Chrome 中文 ChatGPT 已识别归属的新聊天及已有聊天，保持当前草稿可附加图片。
   历史候选入口仍只用于原准入范围的普通已有对话，不借用普通入口的新来源配置。
2. 按平常 macOS 截图方式保存一张新的系统 PNG，等待它自动出现在原生裂缝中。
3. 点击这张新图一次。严格确认实际上传开始后，微图快速吞噬；独立完成证明到达后，
   后台记录成功。请直接看 ChatGPT 草稿附件，Riftlet 不弹成功 Toast，也不自动发送消息。
4. 无可用目标或没有原点击之前的授权时，图片保留，不会转投其他窗口。
   冷启动第一击仍可能因没有预绑定 ACK 而被安全拒绝；这项体验问题尚未解决。
   若结果待核实或已经进入草稿，不要反复点击或尝试重传。

保留的控制
菜单提供“内部截图历史…”、暂停收录、隐藏裂缝、单张/批量移出可见队列、归档和存储检查。
暂停和隐藏相互独立；移除/归档不删除系统原图，也不删除 ChatGPT 草稿附件。
FIFO 连续点击和后台观察沿用正式 Core/UI；上传开始、最终完成和安全重试仍独立判定。

反馈与建议
从当前运行入口的 Riftlet 菜单打开“反馈与建议…”。
可写问题或建议，保存草稿，关闭再打开，查看本机记录及取消待发送。
诊断默认不附带，只有主动勾选的白名单诊断会被放进这份反馈，可在发送前预览。
准确的接收地址与启用状态见同包 build-info.json；它与编译源码绑定，不含服务密钥。
feedbackEndpointConfigured 为 true 时，“发送反馈”会将你主动填写的正文及勾选的诊断
发送到开发者的私有反馈中心；无需注册。仅配置地址不代表本条反馈已被云端接收。
网络异常时保留原文、反馈身份与待发送状态；本机记录分别显示待发送、云端接收和处理状态。
此前已明确保存为待发送的反馈会沿用原编号自动重试；仅保存为草稿的文字不会自动发送。
尚未发送的反馈可本地取消；已尝试发送的反馈需申请远端删除，完成前不会显示“已删除”。
feedbackEndpointConfigured 为 false 时，按钮显示“保存待发送”，只在本机保存，不上传。
截图、聊天、剪贴板、路径或浏览器资料不会自动加入反馈。

准确支持范围
- 普通入口的源码配置：Google Chrome 中文 ChatGPT，已识别归属的新聊天及已有聊天；
  系统截图与内置截图按各自来源身份校验，不借用合成图片或历史候选的准入证明。
- 历史内部候选入口：Google Chrome 中文 ChatGPT，普通已有对话，仅系统截图。
- 原样、单帧、非交错的 8-bit RGBA PNG，最多 8 MiB、16,777,216 像素。
- 已有真实限定证据：macOS 27.0 (26A428) arm64、Chrome 156.0.8078.73，源码 e421e668。
- 此开发包由 macOS CI 构建；准确源码、架构与构建身份见 build-info.json 和正式 PR #1。
- 上述历史真实证据不自动扩展到普通入口的新聊天或内置来源，也不覆盖 Work、其他浏览器、
  ChatGPT 原生客户端、其他图像格式或所有 OS。新配置仍须准确版本的独立审查与真实验收。

数据与边界
普通入口使用 Riftlet 数据根；历史候选入口沿用原 Riftlet-System-Screenshot-Candidate 数据根。
反馈使用当前入口数据根中的独立 Feedback-v01 数据库；两个入口不会自动合并或搬移历史数据。
不要清库、删除媒体或修改审计；旧 A/D/F 及全部 UNKNOWN 不重传、不清除、不解锁。
不要重传已经输入的 H，不补造 uploadStarted。普通入口能力已经按源码配置，
安全重试与未决多附件继续仍关闭；配置与打包核验均不构成公开发行准入。
此包不创建云资源、不部署服务、不安装浏览器扩展；只使用编译时已审查的反馈接收地址。
